# 漫画管理交互改版

日期：2026-09-14。范围为扩展漫画管理、来源目录导入，以及 MangaCopy 动态图片清单发现。沿用现有本地漫画模型与存储，保留原图、版本和阅读位置。

## 交互

- 作品封面、章节、卷册、可读副本和来源目录均采用网格卡片；搜索、排序和筛选独立于编辑。
- 进入批量选择后显示选择工具，支持 Shift 连选；不再常驻起止条目表单和重复操作栏。
- 下载／补齐、授权、暂停、重试集中到采集中心。章节卡片保留阅读和版本入口。
- 版本选择显示当前选中状态，并在保存后反馈；编辑、归属、关联和清理通过按需弹窗或更多菜单进行。
- 出版套系不再作为常驻新建区域或卷册浏览的前置条件；保留已有数据关系与必要编辑。
- 写入过程禁用重复提交，成功提示可关闭且相同文案可再次触发；错误保留到用户关闭或下一次操作。

## 本地验证入口

在 `apps/extension` 启动 `npm run dev -- --port 5175`，打开 `/tests/library-fixture.html`；目录导入检查追加 `?catalog=1`。此页面只允许独立的 5175 端口，使用原创样本与隔离漫画数据，拒绝在已有非验收漫画库上初始化。

样本包含三部作品、十二章节、两卷、多内容版本、失败／暂停采集状态与五十条来源目录。保存、排序、阅读位置与版本切换使用实际组件和 IndexedDB。样本采集状态为模拟，不证明真实网站下载或原生权限弹窗可用；真实站点结果单独记录。

## 卡片布局统一（2026-09-15）

### 书架字体层级

书架使用现有中文无衬线字体，数量标签叠放在封面左上角，正文依次展示书名、阅读进度、辅助信息，移除原标签行的空位；详情页的章节／卷册卡片沿用原有布局。默认 16px 界面字号下：

| 信息 | 样式 |
| --- | --- |
| 书名 | 18px、700 字重、1.45 行高，固定两行；窄屏为 16px |
| 章节／卷册／副本数量 | 封面左上角，12px、650 字重，半透明深底白字标签；缺封面时仍显示 |
| 阅读进度 | 13px 正文，已读数字用 16px、750 字重与主题色突出 |
| 副本数量 | 12px 常规字重，辅助文字色 |
| 最近阅读 | 11px 标签；日期 12.5px、等宽数字，细分隔线划开信息区；无记录显示“没阅读过” |

最近阅读横卡标题为 19px（窄屏 17px），页码与书架进度使用同样的数字强调。字号随界面文字大小设置缩放，不额外下载字体。已检查桌面、390px 窄屏、长中英文标题、未阅读／缺封面、深色主题及 20px 放大文字；卡片按钮对齐，时间和按钮无横向截断。

### 共用卡片布局

- 先移除旧列表布局、重复的书架行高规则和已废弃的行式卡片样式；书架、章节、卷册、副本、相关作品与插件译本改用共用 `CardBody`。
- 标识固定一行，标题固定两行，说明按预留行展示；空内容保留高度，长中文及无空格英文截断，完整文字保留在提示和可访问名称中。普通卡片保留两行说明，插件译本保留四行，包含处理／失败／失效状态。
- 操作区固定 36px 高、两列等宽；阅读在左、详情在右。没有本地原图时禁用阅读，详情仍可用；批量选择占用相同操作行。相关作品的查看／解除关联也固定在此行。
- 章节、卷册、副本和相关作品统一封面比例与网格；内容版本的计数／当前标记保留固定宽度。书架页预留滚动条空间，防止筛选或切换内容后网格列数跳动。390px 两列，低于 360px 单列。

复现：独立的 5175 端口访问 `/tests/library-fixture.html?cards=1`，补充长短标题、无空格英文、长来源／版本和缺封面样本；`?translations=1` 检查模拟的插件译本状态。只修改该验收库，不需要账户或供应商。样本入口不进入生产扩展。

本轮验证：类型与模块检查通过；漫画管理和目录／译本相关 21 项单元测试通过；Chrome MV3 构建通过。内置 Chromium 在 1440px、390px 下测量卡片高度、内容行和按钮相对坐标，并检查截图：同类卡片一致，缺图和不同状态没有撑高或挤压操作区。320px 书架／译本无横向溢出。已验证缺原图详情入口、批量选择、长版本名筛选、版本切换保存，以及返回书架后继续阅读仍为第 2 页。此轮为本地组件与构建验收，未进行商店发布或真实翻译效果验收。
