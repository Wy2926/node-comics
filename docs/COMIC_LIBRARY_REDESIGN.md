# 漫画管理交互改版

日期：2026-09-14。范围为扩展漫画管理、来源目录导入，以及 MangaCopy 动态图片清单发现。沿用现有本地漫画模型与存储，保留原图、版本和阅读位置。

## 交互

- 作品封面、章节、卷册、可读副本和来源目录均采用网格卡片；搜索、排序和筛选独立于编辑。
- 进入批量选择后显示选择工具，支持 Shift 连选；不再常驻起止条目表单和重复操作栏。
- 下载／补齐、授权、暂停、重试集中到采集中心。章节卡片保留阅读和版本入口。
- 版本选择显示当前选中状态，并在保存后反馈；编辑、归属、关联和清理通过按需弹窗或更多菜单进行。
- 出版套系不再作为常驻新建区域或卷册浏览的前置条件；保留已有数据关系与必要编辑。
- 写入过程禁用重复提交，成功提示可关闭且相同文案可再次触发；错误保留到用户关闭或下一次操作。

## 本地验证入口

在 `apps/extension` 启动 `npm run dev -- --port 5175`，打开 `/tests/library-fixture.html`；目录导入检查追加 `?catalog=1`。此页面只允许独立的 5175 端口，使用原创样本与隔离漫画数据，拒绝在已有非验收漫画库上初始化。

样本包含三部作品、十二章节、两卷、多内容版本、失败／暂停采集状态与五十条来源目录。保存、排序、阅读位置与版本切换使用实际组件和 IndexedDB。样本采集状态为模拟，不证明真实网站下载或原生权限弹窗可用；真实站点结果单独记录。
