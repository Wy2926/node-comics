# 系统设置与请求保护

管理后台“系统设置”维护数据保留期限、翻译提示词、页数默认值及请求预算。仅管理员可读写；API 与工作进程共用数据库配置，保存无需重启。

## LLM 翻译提示词

- `comic_translation_prompt`：单图与整本 PDF / ZIP 共用的漫画正文翻译规则。
- `comic_title_prompt`：漫画名查询的翻译规则。

两项必填，去首尾空白并统一换行后允许 1–8000 个 Unicode 字符；拒绝控制字符（LF、Tab 除外）。无需模板变量。默认文本由 [translation_prompts.py](../backend/app/translation_prompts.py) 维护；后台可恢复推荐到草稿，保存才生效，不自动覆盖管理员配置。

后端固定追加目标语言、逐段 ID、JSON Schema 与“源文本只作数据”约束；可编辑部分仅控制翻译语义和风格。目标语言名称由 [languages.py](../backend/app/languages.py) 维护，单页与整本共用，不增加模型调用。提示词不能补足未提供的上下文。

正文在受理时冻结提示词并纳入缓存身份；同 UUID 重放、自动重试和恢复沿用原快照，手动新建重译使用当前配置。漫画名修改只影响后续缓存未命中的查询。

提示词不向普通客户端或图像节点公开；审计只记摘要与字符数。不要写入密钥或私人原文：规则会发送给 LLM，并随任务保存。每次调用都计入输入预算，过长会增加成本；后台保存不验证真实模型效果。

## 参数及生效规则

| 分组 | 参数 | 初始值 | 含义 |
| --- | --- | --- | --- |
| 结果保留 | 注册账户单图 `image_result_retention_days` | 7 天 | 从任务完成起算；整数范围 1–365，不随读取续期 |
| 数据清理 | 空领取回执 `empty_claim_retention_days` | 1 天 | 从领取请求创建起算；整数范围 1–365 |
| 数据清理 | 已结束领取回执 `completed_claim_retention_days` | 7 天 | 从回执创建及关联任务、租约全部结束起算；整数范围 1–365 |
| 数据清理 | 执行明细 `execution_detail_retention_days` | 90 天 | 终态明细到期压缩为摘要，保留账本和去重身份；整数范围 1–365 |
| 页数权益 | 普通每日页数 `free_daily_pages` | 30 张 | 新建每日额度桶的授予页数，已有桶不回写 |
| 匿名体验 | 每游客每日受理 `guest_daily_limit` | 5 张 | 同一游客身份的新受理常规翻译；整数范围 1–100 |
| 匿名体验 | 每网络每日受理 `guest_network_daily_limit` | 100 张 | 同一 IPv4 地址或 IPv6 /64 前缀的共享预算；整数范围 1–1,000 |
| 匿名体验 | 全站每日受理 `guest_global_daily_limit` | 10,000 张 | 全站匿名访客的新受理常规翻译合计；整数范围 1–100,000 |
| 翻译速率 | 普通用户新翻译图片 | 10 张 / 60 秒 | 全账户跨模式、语言和设备的精确滚动窗口 |
| 翻译速率 | PLUS 新翻译图片 | 100 张 / 60 秒 | 仅新受理翻译计数；重传、重放和结果复用不计数 |
| 上传保护 | 单账户上传并发 | 10 | 一个账户跨 API 副本同时接收或写入存储的上传数量 |
| 上传保护 | 全局上传并发 | 16 | 所有账户共享的上传数量上限；同一上传始终最多接纳一条流 |
| 上传保护 | 接收空闲超时 | 15 秒 | 包含首个字节的等待；空数据块不延长时限 |
| 上传保护 | 接收总超时 | 120 秒 | 持续慢发也不能无限延长的收流期限 |
| 上传保护 | 上传占位有效期 | 45 秒 | 接收和写入存储期间持续续租，进程退出后过期名额可重新使用 |
| 反馈保护 | 每分钟补充额度 | 30 条 | 每账户独立的令牌桶补充速度 |
| 反馈保护 | 突发容量 | 10 条 | 每账户可立即提交的新反馈数量 |
| 反馈保护 | 每日新反馈 | 100 条 | 按 UTC 日期计算，与翻译页数和控制请求保护分开 |

表中是默认初始值；除数据保留周期与提示词外，空库首次配置可由下文列出的环境变量覆盖。页数设置允许 0–1,000,000。每日额度修改不会重写已有桶的授予、已用或预占；运营会员已有段和续期保留原月额度，付费产品仍使用不可变权益版本。

单图期限仅通过数据库配置，保存同时作用于已有结果；缩短可能立即使历史结果不可下载，延长不能恢复已删除文件。范围与清理规则见[存储规范](OBJECT_STORAGE.md#原图与结果清理)。

领取回执及执行明细周期也仅通过数据库配置，现有维护进程分批执行；正文与账本的边界见[数据库执行数据清理](OBJECT_STORAGE.md#数据库执行数据清理)。

匿名预算按 `QUOTA_TIMEZONE` 的自然日统计，独立于注册账户页数。保存新限额后，后续匿名受理使用当前限额与当天已用次数判断；修改不清零计数、不返还失败或取消任务的次数，也不取消已受理任务。同一 UUID 重放、本人有效在途或完成任务复用不再次计次；失败、取消、无字和部分完成仍计次。更换游客 Cookie 不重置网络或全站预算。

单账户上传并发不能高于全局并发，接收空闲超时不能超过总超时。页面和服务端都校验范围。设置保存后供后续请求读取；已接纳的上传继续使用接纳时的超时和续租快照，不因修改设置而中断。降低并发上限不会主动取消已接纳上传，在占用低于新上限前停止接纳新上传。

反馈设置变化不清零已使用的每日计数，也不重新填满令牌桶。相同幂等键与相同内容返回原回执，不重复创建、不消耗新反馈预算；相同键与不同内容仍为 409。不同键即使反馈内容相同，也必须消耗预算。超限返回 429，包含 `Retry-After` 和 JSON 的 `retry_after_seconds`。

环境变量 `FREE_DAILY_PAGES`、`GUEST_DAILY_LIMIT`、`GUEST_NETWORK_DAILY_LIMIT`、`GUEST_GLOBAL_DAILY_LIMIT`、`FREE_IMAGES_PER_MINUTE`、`PLUS_IMAGES_PER_MINUTE`、`UPLOAD_USER_CONCURRENCY`、`UPLOAD_GLOBAL_CONCURRENCY`、`UPLOAD_IDLE_TIMEOUT_SECONDS`、`UPLOAD_BODY_TIMEOUT_SECONDS`、`UPLOAD_INGRESS_LEASE_SECONDS`、`FEEDBACK_REQUESTS_PER_MINUTE`、`FEEDBACK_REQUEST_BURST`、`FEEDBACK_RECEIPTS_PER_DAY` 仅用于首次初始化。系统配置创建后，以数据库为准；重启或不同副本的环境值不会覆盖管理员保存的设置。

## 管理接口

- `GET /v1/admin/system-settings` 返回版本、完整参数、`prompt_defaults` 推荐提示词、最近更新时间及更新管理员。
- `PUT /v1/admin/system-settings` 接受 `{ "expected_version": 1, "values": { ...完整参数... } }`。与读取版本不一致时返回 409 `SYSTEM_SETTINGS_CONFLICT`，避免两名管理员互相覆盖。页面保留草稿，要求重新读取最新版本再保存。
- PUT 必须提交表中全部参数及两个提示词字段；字段以 [RequestLimits](../backend/app/system_settings.py) 为准。成功更新在同一事务中写入操作者和前后值审计（提示词仅摘要），并通知客户端刷新策略。业务回滚时不留下成功审计。
- 普通用户和未登录请求不能读写系统设置；响应不包含任何供应商、数据库或存储凭据。
- 旧配置缺少结果期限、游客预算或提示词时，读取补默认值，不写回、不改版本；完整保存才持久化。未知数据库字段读取时忽略、保存时保留，外部 PUT 的未知字段仍拒绝。

## 数据库与验证

分钟限额修改不清空已受理事件、不取消任务；与日／月页数独立。并发、事务与领取规则见[请求保护](SUBMISSION_SCHEDULING.md)，上传生命周期见[文件存储](OBJECT_STORAGE.md)，发布与页面操作见[部署规范](DEPLOYMENT.md)和[后台说明](ADMIN_CONSOLE.md)。

隔离验证覆盖上传连接池占用、超时/取消/断连、跨请求和跨账户并发、旧令牌保护、存储线程结束前的名额保留、默认连接池并发领取、反馈预算及幂等、管理员权限和配置冲突。正式部署的反向代理、共享文件卷、真实身份服务与容量验收单独验证。

可重复命令（在 `backend` 目录，先注入专用测试实例的 `TEST_REDIS_URL` 和 `TEST_PG_HOST / TEST_PG_PORT / TEST_PG_USER / TEST_PG_PASSWORD`，测试库名称固定为 `nodecomics_concurrency_test`）：

```powershell
$env:RUN_POSTGRES_CONCURRENCY='1'
$env:RUN_SCHEDULER_SCALE='1'
.venv/Scripts/python.exe -m pytest tests -q --tb=short
# 管理页面验收夹具，不读取生产环境文件：
.venv/Scripts/python.exe tests/manual_admin_server.py
```

未启用 PostgreSQL 的运行会跳过相关用例。真实代理、共享卷和身份服务需单独验收；兼容发布顺序见部署规范。
