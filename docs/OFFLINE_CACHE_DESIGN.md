# 整本漫画离线缓存

已适配的网站漫画支持在当前浏览器保留原图。书架发起整本计划，离线中心管理进度，复用现有章节下载队列。原来的“下载原图”入口已移除。

## 范围

**整本 = 同一来源漫画的所有目录、所有话。** 不受目录展开、搜索、排序、当前阅读序列、阅读语言或已读状态影响。

- 默认全部语言；多语言漫画支持复选，缓存所选语言的全部独立来源条目及译组。
- 主线、番外、自定义分类和嵌套目录全部纳入。同一条目出现在多个目录时只缓存一次，不凭标题或话号合并不同条目。
- 关联作品仍是另一本漫画，不递归导入。未知页数、不可读、来源删除等目标保留在计划中，不从分母静默剔除。
- 必须先取得完整目录及完整分组。仅在适配器不支持目录、导入对象本身为独立页面资源时，以其全部页面作为范围；目录准备失败不会把当前已打开章节标为整本。
- 范围在准备完成后固定。目录新增内容显示“有新章节未缓存”，点击“补缓存”才扩大计划。
- 本地文件显示“已保存在本机”，不重复复制；云盘保持按需读取，显示不支持整本缓存。

## 交互

| 位置 | 操作 |
| --- | --- |
| 书架右键菜单 | 缓存整本；多语言漫画显示缓存语言；已有计划定位离线中心对应漫画 |
| 右上角离线缓存按钮 | 打开整页离线中心，角标显示排队、准备中和缓存中的书本数量 |
| 书架卡片 | 不显示任何缓存状态或缓存进度，保留原有阅读进度 |
| 阅读器目录 | 每话和独立语言／译组条目仅在完整保留原图时显示“已缓存” |

直接开始不弹配置或确认，不自动打开阅读器或离线中心。重复点击定位已有计划。离线中心使用整页，一行一部漫画，展示封面缩略图、名称、带图标的来源标签、状态标签、完整章节进度及较大的语言国旗；实际保留体积以“离线占用”独立放在卡片右下方。点击封面或名称继续阅读，不展示具体章节列表和逐页信息。

卡片只直接显示当前主要操作：暂停、继续、重试或补缓存。语言调整、打开来源、取消及清理收进卡片右键／更多菜单。权限或空间不足时主要操作改为对应处理入口，更多菜单仍提供继续缓存。状态标签沿用主题描边与阴影，以底色区分执行、完成及需要处理。

阅读器工具栏及目录顶部不提供缓存按钮。目录标记检查实际保留原图，独立于当前计划和语言选择；未缓存或不完整的话不显示缓存状态，多语言合并话的主条目与展开版本分别判断。“已缓存”放在语言右侧，译组单独位于下一行。

离线中心沿用主题和字号，语言多选使用锚定按钮的非模态气泡下拉列表，列表包含国旗、语言名和对应话数，操作按钮在气泡内；点击外部或 Escape 收起。清除离线内容使用现有对话框确认。离开中心继续执行；从中心阅读后可返回中心，保持正文位置。开始、完成、部分完成及需要处理时显示轻提示，不逐页弹消息。

### 缓存语言

复选框提供全部语言和各语言的去重条目数；单语言隐藏选择器。简繁独立，未标注语言保留为独立选项，不猜测。零选择不能保存或开始。

选择保存在漫画独立的缓存偏好中，不修改阅读语言或翻译目标语言。调整时展示当前与新范围、新增和不再请求的章节数；“应用并补缓存”撤销旧调度并重建计划，复用有效原图，不自动删除已保留的其他语言。

来源明确证明同话关系时，缺少已选语言会单独提示；不回退其他语言，也不把源站缺话计为下载失败。

## 进度与反馈

主进度为本次目标中**原图完整保留的章节数 / 去重目标章节数**。章节完成须满足完整页清单、已知页数一致、当前内容身份有效且所有对应原图存在。普通页缓存命中后必须成功写入保留存储才计数。

- 目录准备中不显示确定百分比；确认范围后显示完整章节比例，不显示当前话、逐页信息、速度或预计剩余时间。
- 部分失败显示“部分已缓存”，失败章节不计完成；单页有限重试后继续后续页面与章节。
- 完成显示“已缓存”，同时保留章节分母、语言范围及源站缺话提示，不暗示作品完结。
- 全书按条目并集统计，不能相加重复分组的数量。
- 进度约每秒更新；缓存不修改已读、阅读位置、最近阅读时间及 NEW 状态。

| 情况 | 处理 |
| --- | --- |
| 暂停 | 停止剩余调度和写入，保留任务和原图；显式继续时补缺 |
| 取消缓存 | 删除整本任务、章节下载任务与对应离线原图；保留漫画、阅读记录和语言偏好，离线中心不保留已停止记录 |
| 页面关闭或重开 | 全计划（包括尚未执行的排队章节）暂停，提示中断，等待继续 |
| 网络中断 | 显示等待网络；同次页面执行内有限重试，用户暂停优先 |
| 权限不足 | 暂停同来源计划，提供扩展权限设置入口 |
| 来源登录、验证或限流 | 暂停同来源计划，提供来源入口；遵守 Retry-After，429 无等待时间时至少等一分钟 |
| 空间不足 | 暂停全部活动计划，提供管理空间入口 |
| 单页或单章失败 | 已完成部分可读；显示部分完成及重试提示，重试仅补缺 |
| 内容变化或原图缺失 | 旧内容不计入完成；重新核验并补缓存 |

错误不显示签名图片地址、凭据或堆栈。缓存原图不触发翻译、上传、导出或额度消费。官方常规译本离线显示同时需要实际送译原图和覆盖文件；只有覆盖缓存不算可离线阅读，服务器不提供永久原图副本。

## 生命周期与存储

执行依赖打开的插件主页面。阅读、回书架、离开离线中心或切换标签页不停止；关闭执行页或浏览器后中断，不承诺后台运行。离线中心持续显示“请保持此插件页打开，可切换到其他标签页”。

同一漫画只允许一个活动计划。跨标签页使用 Web Lock 单宿主及持久化宿主身份；书级和章节 generation 控制执行意图，存储代数阻止暂停、清除、删除及撤权后的迟到写入。目录准备也可取消。取消后保留删除代数，新计划使用递增代数；旧页面的继续、语言调整、暂停或确认删除不能重建已取消任务或影响新计划。

准备阶段取得全书章节目录元数据（标题、链接、语言等），按每批 100 话登记任务，不预先解析每话图片清单或获取原图。实际执行逐话串行：读取当前话的图片清单，逐张补齐原图，再进入下一话。继续或重试时，以保留元数据和对象存在性核验完整章节后直接跳过，不重新读取其原图字节或逐页回写进度；缺页只补缺失部分。暂停和取消可中断目录准备、任务登记及图片获取。

原图复用既有 acquirePage、后台优先级和 downloadStore。与自动读取的可淘汰页缓存分开：普通缓存清理不删除主动保留的离线图。计划和汇总只读元数据，执行保持有限图片窗口。

离线内容仅在离线中心管理，设置不再显示离线原图栏。“取消缓存”在已有离线原图时确认删除影响；“清除离线内容”始终确认漫画名和体积。两者共用清理流程：先撤销执行意图并阻止迟到写入，再删除原图、章节下载任务和整本计划，保留漫画、阅读记录及语言偏好。清理未完成时保留内部清理意图，支持重试及重开页面后继续清理；旧已停止记录通过同一流程回收。移除漫画同时移除计划、缓存偏好和对应原图。旧章节下载记录接入离线中心，不自动恢复其遗留排队任务。数据属于当前浏览器配置，不跨设备同步，不保证卸载或清除扩展数据后保留。

- [书级计划](../apps/extension/src/comics/acquisition/books.ts)、[范围与意图](../apps/extension/src/comics/acquisition/book-model.ts)：完整目录、语言范围、恢复、汇总及清理。

- [离线中心](../apps/extension/src/ui/downloads/BookDownloads.tsx)：按漫画管理进度和语言；阅读器目录独立显示完整缓存标记。
- [队列测试](../apps/extension/tests/book-downloads.test.ts)：范围、重复执行、暂停／清除的迟到写入、撤权、缺页核验、限流、空间不足、旧任务接管及超过 1000 章。
- [浏览器验收](../scripts/verify_book_downloads.mjs)：构建扩展后，以隔离 MV3 配置、合成目录和本地图片服务验证真实 UI、存储、恢复及断网阅读。运行时可设置 PLAYWRIGHT_MODULE 与 TEST_CHROMIUM；截图输出到忽略目录 artifacts/book-downloads。

自动化浏览器验收使用模拟来源，不代表所有真实站点的登录、验证或设备环境均已验证。首版不含多本批量操作、定时更新、整本翻译或关闭插件页后的持续执行。
