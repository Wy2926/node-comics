# 翻译

渠道在 `src/translation/channels/adapters/` 内实现，由注册表组合；阅读器只使用公共能力，不识别具体渠道。官方服务、浏览器本机处理和 MTU 各自管理连接与任务。

- 原图、送译副本、译图分开保存。切换结果、失败重试和返回阅读保持位置。
- 官方请求先冻结 UUID、规范化字节、语言、模型和字体；结果未知时查原请求，不创建新任务盲试。
- 按账户和任务身份隔离缓存；每页失败独立，取消后拒绝迟到结果。
- 保持有限图片窗口、有限预取与并发；大图按需解码，淘汰时释放对象 URL 和位图。
- 官方结果使用 `original`、`overlay-v1` 或协商后的 `overlay-tiles-v1`；合成前验证输入身份、摘要、尺寸与范围。
- 像素算法和结果类型在 `shared/translation-images/`，API 调用在 `apps/extension/src/api.ts`。
- 本机渠道下载前展示模型与字体资源；图片本机处理，识别文本按用户配置发送翻译服务。

`shared/` 是插件自己的代码与数据；官网维护独立副本。协议或字体 ID 变更需同步服务端契约并验证兼容性，普通修复不要求联动发布。

验证使用图像、缓存、渠道与阅读器相关测试；真实模型效果另验。跨仓库编码联调脚本显式设置 `COMICS_COMPUTE_ROOT`，不参与普通构建。
