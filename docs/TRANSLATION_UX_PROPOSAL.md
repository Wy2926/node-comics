日期：2026-09-14。交付状态：核心交互、客户端与反馈 API 已实现；本文保留交互设计依据，当前流程和验证边界见[实现说明](UI_IMPLEMENTATION.md)。

本轮已明确的需求：提前上传后持续翻译，当前阅读优先，清楚标识任务状态与正在看的图片；同一种模式只展示最新效果；可提交反馈、重新翻译；目录采用缩略图列表。未涉及调度的面板尺寸与视觉细节保留设计建议性质，沿用[整体 UI 设计](UI_REDESIGN_PROPOSAL.md)的配色与字号。

## 1. 最短使用路径

**单页：打开漫画 → 点击「翻译本页」或「AI 重绘本页」→ 确认页数权益 → 上传并排队 → 按偏好显示译图。**

**预存：选择本章或页段 → 确认本次最多新建页数 → 保存上传清单 → 服务器持续翻译 → 下次阅读按需取图。**

模式默认采用已保存偏好，初次默认常规翻译；语言默认简体中文或用户已保存的目标语言。模式和语言在顶部翻译面板内调整，确认时读取当前账户权益与服务器队列容量。

手动翻译先匹配账户已有任务与结果；准备期间显示忙碌状态，失败给出可操作原因。已有任务进入查看进度与本人插序，已有可用译图进入查看，不重复受理或结算。新任务的页数上限和权益类型随提交发送给服务器，变化时停止本次新增并明确提示。

首次未登录点击后打开登录，保留漫画、位置、模式和范围；登录回来继续核实范围，再由用户确认上传清单。

任务完成后，画面上方的同一行变为：

```text
译图 · 常规 · 简体中文                         查看原图    译图有问题
```

这是稳定的画面身份标识，始终与当前实际渲染的图片一致。它不会在几秒后消失，也不会只写“成功”让读者猜测是否已切换。进行中信息出现在身份标识旁，只有存在任务时才出现。

底部仅保留页码、可拖动阅读进度条和百分比，桌面 48px、窄屏 46px；翻译按钮移至当前页信息区。首次使用主要工具可见，目录与辅助面板默认收起。沉浸状态下保留贴近页边的小型画面标识，完整控制条按既有方式唤回。

## 3. 预存清单与实时阅读优先级

### 明确本次范围

用户选择单页、当前章节或页段，确认模式、语言、权益和本次最多新建页数。客户端先持久化上传清单与原始幂等请求，再交给服务器受理。选择「有空位时持续补充本次选择」后，尚未上传页面在本机等待；仅补充本次已确认范围，不授权无限扩大的阅读窗口。

### 两种队列与本人插序

- 常规翻译与 AI 重绘分别排队。普通用户每种模式 10 页在途、2 页实时；PLUS 每种模式 500 页在途、10 页实时。上传占位、校验、排队与执行均计入容量，完成或确认终止后释放。
- 客户端按当前阅读页及最近几篇内容生成本人顺序，优先申请最近页面的实时名额；尚未上传的阅读页优先取得下一个上传空位。服务端验证账户、模式、会话、版本和名额，不能排序其他用户任务。
- 实时优先于预存，服务端为预存保留最低处理份额。同级按用户权重公平分配，会员默认权重更高且可配置；空闲时单用户可借用更多执行位，有竞争后按后续阶段重新分配。
- 阅读优先级使用短期租约；后台心跳不能抢走其他设备的前台会话。用户显式接管后才切换控制者；租约到期恢复预存优先级。
- 暂停本机补充停止新增上传；暂停服务器某模式队列停止领取后续阶段，已经开始的阶段自然结束。两种暂停都保留可见状态和恢复入口。
- 已校验任务关闭页面后由服务器继续消费。逐页失败互不阻塞；未知提交保留原请求和原幂等键，不能因刷新页面重新创建一次收费请求。AI 上游结果未知时先核实。

### 自动显示与资源保留

「完成后自动显示译图」只控制阅读展示，不创建翻译任务。有结果的页按需下载，验证解码后原位替换并保持页内相对锚点；后台完成其他页不跳页、不抢焦点。用户明确选择原图后保持原图偏好，直到主动选择译图。

每种模式与语言展示最新成功交付的效果，重译失败时保留已有结果。原图与最终译图存私有 R2，当前无限期保留且未启用自动清理；未来可能清理长期未访问资源。客户端支持图片到期时间为空，仍处理用户主动删除和显式策略失效。临时上传授权与下载签名的有效期不代表图片保留期限。

## 4. 当前画面与任务进度分别表达

| 场景 | 画面身份 | 任务状态 / 动作 |
| --- | --- | --- |
| 尚无译图，任务未开始 | 原图 | 翻译本页；可选择预存本章 |
| 清单已受理，尚未上传或校验 | 原图 | 等待上传／校验原图；不能提前声称服务器正在翻译 |
| 已提交但未执行 | 原图，或已有的最新译图 | 排队中；显示实际画面身份 |
| 第一次翻译中 | 原图 | 正在翻译；成功后按自动显示偏好切换 |
| 译图下载／解码中 | 当前仍在看的原图或译图 | 正在载入新译图，不提前标为新效果已展示 |
| 已经显示结果 | 译图 · 常规 / AI 重绘 · 目标语言 | 查看原图、译图有问题 |
| 用户主动看原图 | 原图 | 已有译图 · 查看译图；任务完成不强制切换 |
| 重新翻译中，有旧的可用结果 | 译图 · 当前模式 · 语言 | 重新翻译中；继续展示当前最新可用效果 |
| 重译失败，有旧结果 | 译图 · 当前模式 · 语言 | 重译失败，仍显示上次效果；查看原因 |
| 首次翻译失败，无旧结果 | 原图 | 翻译失败；查看原因 / 重新翻译 |
| 结果待核实 | 当前实际显示的原图或译图 | 结果待核实；查看进度，禁止普通自动重试 |
| 部分保留原文 | 译图 · 当前模式 · 语言 | 部分文字保留原文；反馈入口；按实际结算说明 |
| 最新结果过期或删除 | 原图，或同一结果的有效本地副本 | 译图过期；不悄悄回退成较早版本 |
| 原图未取得 | 原图待获取 | 重新导入或回来源获取，其他页仍可阅读 |

柔和通过浅底、轻边界和紧凑面积实现，文字保持足够对比。状态文字可持续；不要每页反复弹出大提示。进度按真实完成页数呈现，不给单页图片模型编造百分比。

## 5. 每种模式只展示最新效果

读者界面不出现 v1 / v2 / v3、版本时间线或旧版本选择器。展示键为 **页面 × 模式 × 目标语言**，每个键只有一个当前效果；不同模式、语言不相互覆盖。切换模式或语言只查找对应效果，不自动触发付费任务。

“最新”具体指最近一次成功交付、未撤销的结果：

- 新请求排队、处理中或失败，都不是可展示的新效果；旧的当前结果继续作为最新已交付结果。
- 新结果成功交付且客户端可解码后，更新当前效果指针；自动显示依照用户偏好执行。
- 更新排序采用明确的生成序号／创建顺序，不能只按完成时间；较早请求迟到不能覆盖后发请求的成功结果。
- 当前结果过期或被删后，不自动寻找历史更老的服务器结果冒充“最新”。如果当前结果在本机仍有可用副本，明确继续使用该副本。
- 阅读器、缩略图状态、翻译记录的“阅读译图”都解析到同一当前效果。审计记录可以保留任务事件与原有资产保留策略，但不向读者提供旧效果切换；此设计不要求物理删除已有版本。

这取代整体草案上一版的“已有版本选择”与“默认完成后手动查看”。

## 6. 反馈与重新翻译

“译图有问题”是当前译图身份行上的次级文字入口。打开一个轻面板：

```text
这页哪里不太对？
海风来信 · 第 42 页 · 常规翻译 · 简体中文

[漏译] [意思不对] [排版不清] [画面变化] [其他]
补充说明（选填，最多 500 字）

提交反馈
─────────────────────────────────────────────
想换一个效果？  重新翻译本页 · 确认 1 页权益
```

- 问题类型可多选，补充说明选填；至少选一项或填写说明才能提交。
- 反馈与当前实际看到的结果绑定。在打开反馈面板时固定漫画页、模式、语言、任务 ID 和结果身份；新结果在后台完成不改变反馈对象。
- 提交反馈不触发翻译、不消耗翻译页数。默认不附加新截图或漫画正文；已有结果仅按原授权关联，额外图片须由用户明确选择。离线或失败保留草稿并明确未提交。
- 成功后就地显示“反馈已提交”，保留“重新翻译本页”入口。重复点击依靠提交 ID 去重，不生成重复反馈。
- 重新翻译也可直接进行，无需先提交反馈。轻确认显示当前页、模式、目标语言及最多 1 页权益；通过提交清单指定原任务与重新生成，不包含未来页面的授权。
- 有相同模式和语言的进行中请求时，改为查看该请求；避免重复点击创建多个重译。状态未知时先核实；核实期限结束后再次创建重绘需明确确认原请求可能已产生费用。
- 重译期间保留最新已交付结果；完成后替换，失败保留当前结果和清楚的原因。原图随时可查看。
- 反馈说明不直接变成不受约束的模型指令；是否将结构化问题用于后续生成需要独立实现与验证，也不承诺重试必然改善质量。

反馈 API 已实现并按账户隔离；模拟草图和合成结果只用于交互验证，不代表真实供应商翻译效果。

## 7. 目录改为缩略图列表

采用单列纵向列表，每行 **页图缩略图 + 页码 + 翻译状态**，整行可点击。桌面抽屉约 260–300px，缩略图约 64 × 88px，保持图片比例并留白，不能裁掉对识别页面有用的内容。当前页使用主题色边线、浅底以及“正在阅读”文字；状态不覆盖在画面上。

```text
章节页面                                      收起

[ 页图缩略图 ]  第 40 页
                已有译图

[ 页图缩略图 ]  第 41 页
                已有译图

[ 页图缩略图 ]  第 42 页    正在阅读
                正在翻译

[ 页图缩略图 ]  第 43 页
                排队中
```

默认采用稳定的原图缩略图，旁边的状态对应当前模式和语言；译图更新不使整个列表持续闪动。打开目录定位到当前页附近。点击跳页后手机收起目录，桌面可保持打开；选页、切换图片都保存阅读锚点。

长列表虚拟化，仅加载可见范围附近的低分辨率缩略图；缺图显示中性占位与“原图待获取”。批量翻译另有“选择页面”入口，进入后才出现复选框与范围选择，不让普通阅读目录承担批量管理工具栏。

本轮交互草图初始展开目录，便于评审缩略图与状态；可以点击底部入口收起。草图用附近 5 页和前后分组模拟目录窗口，正式产品采用上述可滚动的虚拟列表，默认收起。画面由构图示意组成，不用于评估实际翻译质量。

## 8. 数据与后续验收

| 能力 | 已有基础 | 设计落地需要补充 |
| --- | --- | --- |
| 持久化预存与实时阅读 | 新提交清单、独立模式队列、当前阅读插序 | 核实确认范围、2/10 实时名额、10/500 在途容量、跨设备会话和逐页恢复 |
| 自动查看 | 本地原图、译图和位置恢复 | `autoShowTranslation` 与手动原图优先状态；解码完成前后保持锚点；后台页不抢焦点 |
| 当前最新效果 | Job 的模式、语言、版本与输出有效性 | 稳定的每页当前结果投影、生成顺序与迟到保护；删除或过期时不隐式回退 |
| 用户反馈 | 任务与输出资产已有身份 | 按用户隔离的反馈接口：问题类型、限长说明、固定任务／结果身份、提交去重键、提交状态；默认不新增图片上传 |
| 重新翻译 | 新清单指定原任务、模式和语言 | 重译状态与当前展示结果独立；反馈不自动重译；权益及未知费用重新确认 |
| 缩略图目录 | 本地页图、页序与任务状态 | 本地缩略图缓存、有限窗口列表、当前页定位和模式／语言状态聚合 |

后续实现重点检查：

1. 初次读者能明确确认当前页或预存范围；阅读插序不扩大本次授权，默认不自行新建收费任务。
2. 已确认清单持续补充、重复点击、已有结果复用、模式独立暂停、跨设备接管及容量争用均不会超额或重复结算。
3. 原图／译图身份与实际图像一致；任务正在重译时仍能明确指出当前看到的是已有译图。
4. 自动显示不改变阅读位置，不干扰用户主动原图偏好、缩放拖动和后台其他页。
5. 同一页同一模式同一语言无旧版本选择器；迟到结果不能覆盖更新结果；过期不悄悄回退。
6. 反馈提交固定到真正被反馈的结果，失败保留内容；反馈与重译是独立操作。
7. 缩略图列表可辨认当前页与翻译状态，大章节不一次解码所有页；320px 宽和放大文字下操作仍可用。
