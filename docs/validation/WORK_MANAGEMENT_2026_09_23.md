# 作品管理与导入验收（2026-09-23）

> 历史记录：此处的旧管理模型和入口已被移除，不是当前功能或可重复执行命令。当前行为及验证见[单来源验收](SIMPLE_READING_2026_09_23.md)。

本轮以新版 `Work → ReadingUnit → Document` 为数据基础，按[交互恢复决策](../SIMPLE_COMIC_READING_DESIGN.md)恢复作品整理能力。旧版共享卡片的封面比例、类型标签、标题空间、信息行和阅读按钮保留；条目管理收进“更多”，批量选择与调整顺序由用户主动开启。

## 实现范围

- 作品标题、作者、别名、简介及封面；章节／卷册类型与正文／番外分类；版本名称、语言和版本说明。
- 内容分类、关键词与已读筛选、阅读顺序和名称排序、批量已读／未读、单元首选版本及同作品内归属修正。
- 明确打开的版本优先于首选版本；书架继续阅读恢复真实有效位置；各版本位置独立保存。
- 详情按作品 ID 独立加载当前作品元数据，编辑导致书架排序变化时不会关闭详情。超过 1000 个单元或 100 个版本仍可管理；页面描述符和图片保持按需读取。
- 导入明确区分新建／加入已有作品，全库搜索与分页；新建只有确认导入才落库，选择已有单元时沿用其分类。详情内“添加内容／其他版本”预选当前归属，外部拖入不会沿用已取消的旧目标。
- 编辑与关联命令做事务校验；批量删除核验确认时的单元归属，防止误删已在其他标签页移动的版本；旧异步阅读或分页结果不能覆盖当前页面。
- 清理 23 个已确认的空源码、测试或文档目录。未清理用户书架、源文件、授权信息或无关构建产物。
