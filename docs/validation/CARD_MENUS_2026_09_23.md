# 书架、详情卡片与右键菜单验收（2026-09-23）

已完成本地代码与 Chrome MV3 构建，未提交、推送或发布。交互规则见[作品管理设计](../WORK_MANAGEMENT_UX.md)。

## 本次变更

- 书架卡片右键提供查看内容、添加内容、编辑作品和移除作品；详情卡片右键提供版本与来源、编辑条目、已读切换，移除省略号按钮。菜单支持键盘、触屏长按、边缘避让、外部点击、滚动和 Escape 关闭。
- 书架、作品概览和详情单元显示来源标签。驱动提供文件来源名称，网站定义提供站点名称，通用网页按域名区分；同来源的多个版本去重，多来源显示具体数量，悬停显示名称列表。
- 书架按邻近卡片的作品索引遍历来源引用，覆盖超出首批单元和版本的追加内容；来源统计不读取页面描述符、源文件字节或请求网站／云盘。详情复用完整作品元数据。
- 详情卡片封面由横向改为 3:4；内容信息移到封面标签，移除文件格式标签，未读／阅读中／已读使用文字、图标和配色区分。标题和阅读按钮保留在下方。
- 顶部资料与操作左右分区；来源、单元、版本和已读数改为图标与数值分层的统计块。右侧使用三点菜单，添加内容、编辑作品进入菜单，最近阅读显示真实时间。
- 首页与详情（含编辑弹框）复用自定义下拉框，窄屏菜单避让滚动条。首页排序移到最右侧；作品数量使用账户头像同款的自适应宽度徽章，放在“我的漫画”旁。
- 书架取消分页，保留全库轻量作品索引用于总数、搜索与排序。只挂载可视卡片与上下各两行；卡片按需读取元数据、加载封面并在卸载时释放，滚动不累积卡片。详情返回恢复滚动位置。目录导入的已导入判断改为独立索引查询，不依赖当前窗口。
- 新文案补齐全部 16 种界面语言。既有删除确认和独立版本阅读位置保留。

## 验证结果

在 `apps/extension` 执行：

- `npm run check`：TypeScript、199 个模块的边界、环依赖及可达性检查通过。
- `npm test`：59 个文件、616 项通过；已有规模测试文件／用例各跳过 1 项。
- `npm run build`：Chrome MV3 构建成功，产物位于 `.output/chrome-mv3`。

应用层回归新增：注册来源名优先于账号展示名、超出 100 个版本的来源统计、删除后数量更新、通用网站按域名区分且同站版本去重；轻量书架索引不读取文档／页面，卡片按请求加载；目录导入的已导入查询独立于书架窗口。

`scripts/verify_work_management.mjs` 使用 Chrome for Testing 141.0.7390.37、全新隔离 profile 和生成的 CBZ。13 组检查通过、页面异常 0。覆盖右键与键盘导航、Escape 焦点恢复、屏幕边缘菜单、模拟触屏长按不误触阅读、单源／多源、失败版本提示、编辑、批量整理、归属修正、漫画第 2 页续读、真实最近阅读时间、三种阅读状态、自定义下拉框及 390px 窄屏。浏览器网站来源为隔离目录夹具，仅验证展示，不代表真实网站接入或翻译效果验收。

1001 部作品的隔离书架中，顶部挂载 25 张卡片，滚动底部挂载 16 张，390px 窄屏挂载 10 张。检查全库搜索、排序、窗口外作品编辑、返回滚动恢复、四位数数量徽章与导入全库查询。该结果验证挂载数量有界，未将其等同于浏览器堆内存基准。
