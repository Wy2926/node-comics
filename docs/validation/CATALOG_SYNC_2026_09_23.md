# 网站目录自动同步与更新徽章

日期：2026-09-23。状态：代码与本地构建完成；使用隔离 Chromium 和合成来源页面验证，不代表真实源站当日可用性。尚未公开发布或部署。

## 已实现行为

- 持久记录上次检查及成功同步时间，仅在距上次检查满 12 小时后检查；打开插件不重置此间隔。目前仅 MangaCopy／拷贝漫画声明支持目录更新；其余网站、本地与云盘不参与。
- 对比稳定来源条目 ID，新增可阅读条目时显示 NEW。首次完整目录建立基线，不显示更新；重复检查、改名和重排不增加更新数量。
- 卡片右上角使用放射形、星光装饰的 SVG NEW 徽章，叠在卡片上并伸出封面。来源标签左上，阅读时间左下；删除封面页数标签，继续保存实际阅读位置。
- 只有当前漫画图片成功解码并显示后才确认本次更新。查看目录、加载失败或预加载其他漫画均不清除。确认携带读取时的修订号，之后到达的新更新不被旧确认清除。
- 同步标题、顺序、分类和新增条目；不下载新章节图片，不更换已有内容身份、缓存、译图与页锚点。源站移除的条目隐藏于普通目录，但已有数据和当前阅读位置保留。
- 目录未完整加载／来源出错时保留旧目录，12 小时后再检查；再次打开插件不会提前检查。当前没有手动强制更新入口。已删除漫画、来源权限变化和过期执行租约拒绝迟到结果。

## 后台与适配契约

`SourceDefinition.catalogSync.intervalMinutes` 为显式支持声明，MangaCopy 当前设为 720。页面解析仍完全由该站适配器负责；公共后台使用非活动标签读取完整目录，单次发现最多等待 20 秒，完成或失败时释放仍属于原来源的标签页。用户已导航到其他资源的标签页不会被关闭。

`Comic.catalogSync` 持久保存上次尝试时间、上次成功同步时间、下次检查时间和执行租约；`catalogUpdates` 保存新增数量及确认修订号。检查前登记两分钟恢复 alarm，确保 service worker 在完成回调前终止后仍会重新唤醒以清理遗留标签；重新请求仍受已持久化的 12 小时间隔约束。后台每批有界串行处理，剩余漫画由后续 alarm 继续；关闭阅读器不影响后台同步，浏览器关闭期间暂停，启动时补查。Chrome/Firefox 清单增加 `alarms` 权限，不新增源站域名权限。

目录写入在同一 IndexedDB 事务内合并，并通过已有广播通知书架与当前阅读目录。没有新表、旧库迁移或远端漫画上传。

## 可复现检查

在仓库根目录运行：

```powershell
npm --prefix apps/extension run check
npm --prefix apps/extension test
npm --prefix apps/extension run build

$env:PLAYWRIGHT_MODULE = '<已安装 playwright 模块的绝对路径>'
$env:TEST_CHROMIUM = '<可加载解压扩展的 Chromium 可执行文件绝对路径>'
node scripts/verify_catalog_sync.mjs
```

浏览器脚本还要求 Python 和 `cryptography`（生成仅用于本机夹具的临时 TLS 证书）。脚本新建临时扩展副本与浏览器 profile，通过 DNS 映射将 MangaCopy 请求限定到本机，拦截产品 API，不读取个人浏览器资料、不调用翻译模型。

单元测试覆盖首次基线、新增去重、目录改名／移除、旧快照拒绝、删除竞态、修订确认、重新打开不提前检查、12 小时间隔、失败后间隔保留、跨执行器租约及过期恢复。来源运行时测试覆盖不完整等待、跨作品导航、超时清理及遗留标签恢复；消息路由测试验证网页无法发起后台全库检查。

浏览器证据输出到忽略目录 `artifacts/catalog-sync/`：`results.json`、`updated-covers.png`、`synced-directory.png`、`failed-check-preserves-directory.png`、`background-update.png`、`live-directory-preserves-position.png`、`failed-reading.png` 和 `badge-selection.png`。实际 alarm 验证通过调整隔离测试数据的到期时间触发，12 小时边界由可控时钟单元测试覆盖，没有等待真实 12 小时。

本轮结果：类型与 194 个模块边界检查通过；631 项单元测试通过，1 项既有测试跳过；Chrome MV3 构建成功。Chromium 141、1440 × 1000 下的 9 项隔离浏览器检查通过，页面运行错误为 0；已查看封面徽章、动态目录及阅读位置、失败阅读和批量选择截图。测试日志含既有 `node-unrar-js` 缺少 source map 文件警告，不影响本轮检查结果。未重新验证真实源站或执行真实翻译。
