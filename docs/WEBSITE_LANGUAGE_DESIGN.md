# 官网语言选择

官网支持 17 种语言，语言由 URL 决定：简体中文使用根路径，其余语言使用 `zh-tw`、`en`、`ja`、`ko`、`fr`、`es`、`pt-br`、`de`、`it`、`ru`、`pl`、`uk`、`tr`、`vi`、`id`、`ar` 前缀。各语言的正文、账户、图片翻译和政策独立维护；阿拉伯语使用 RTL 排版，金额、代码及邮箱保持独立的从左向右方向。官网语言不改变插件支持范围，运行与验证见[官网 README](../backend/website/README.md)。

## 浏览器语言提示

- 公开页面按浏览器语言列表顺序匹配首个支持项；不支持的语言跳过，全部不支持时不提示。地区变体匹配基础语言，葡萄牙语对应巴西葡萄牙语。中文脚本优先：Hans 使用简中，Hant 使用繁中；无脚本的 TW/HK/MO 使用繁中，其余中文使用简中。
- 浏览器首选语言与当前语言不同，且没有有效手动偏好时，显示可关闭的轻量提示。页面不会自动跳转，也不抢焦点；点击切换后保留当前文章、查询参数和锚点。
- 翻译工作台、账户、授权回调、支付返回、卸载反馈和 404 页面不显示提示，避免打断进行中的流程。
- 手动切换（语言菜单或提示链接）保存白名单 Cookie `nc-site-locale`：`Path=/; Max-Age=31536000; SameSite=Lax`，HTTPS 加 `Secure`，不设 Domain，不含用户标识。有效手动偏好只抑制建议，不强制改变明确 URL。
- 关闭提示只在当前标签页会话内记忆该建议语言。Cookie 或会话存储不可用时，普通语言链接和当前页面仍可使用。其他标签页不自动跳转；插件界面语言独立保存。

## 路由与 SEO

语言菜单保留可抓取链接并切换到同一内容。公开固定语言页输出自身 canonical、17 个互相对应的 hreflang 与简中 `x-default`，并进入 sitemap。HTML 不按浏览器语言、Cookie 或 IP 替换正文；提示在浏览器本地判断，不增加网络请求。

OIDC 回调仍为精确的 `/auth/callback/`；登录保存并恢复当前语言的账户或翻译路径。支付渠道继续使用固定同源返回入口，成功页不发放权益。账户、身份、支付、工作台及卸载页面维持 noindex/no-store，不进入 sitemap。

验证覆盖全部语言、地区与中文脚本匹配、浏览器优先顺序、手动偏好、关闭提示、存储不可用、同页面切换及私有流程抑制；构建检查全部语言页面、链接、canonical、hreflang 和 sitemap。浏览器验证不证明真实身份登录或付款已完成。
