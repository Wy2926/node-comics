# 官网语言偏好方案（待实现）

当前官网按 URL 选择语言，简体中文使用根路径，其余语言带前缀；尚未存储语言偏好。以下是保留的设计决策，不代表代码或线上已实施。当前运行与路由见[官网 README](../backend/website/README.md)。

## 选择与路由

无语言入口按“有效手动偏好 → 浏览器语言列表 → 英语”选择；明确语言 URL 始终展示其语言，不被偏好强制跳走，也不覆写保存的选择。登录、退出和账户切换保留本浏览器语言。

| 路由 | 计划行为 |
| --- | --- |
| `/`、`/account/`、`/payment/success/` | 协商后 302 到对应语言路径；私有、不缓存，`Vary: Accept-Language, Cookie` |
| `/<locale>/...` | 五语均有明确前缀：zh-cn、zh-tw、en、ja、ko；稳定输出对应语言完整 HTML |
| `/auth/callback/` | 保留精确 OIDC 回调；完成校验后返回保存的站内目标，不参加语言协商 |
| 原无前缀中文内容页 | 确定性单次 301 到 `/zh-cn/...`；根路径与支付返回入口除外 |

支付渠道继续使用固定同源返回入口，不把语言或身份写入支付 URL。失败、取消或客户门户返回不展示支付成功；成功页不发放权益。

## 匹配、记忆与 SEO

- 服务端按 `Accept-Language` 权重和原始顺序有界匹配，忽略 q=0、非法和不支持项；不按 IP 或爬虫身份猜测。zh-Hant 及无脚本的 TW/HK/MO 用繁中，zh-Hans 与其他 zh 用简中，明确脚本优先；en/ja/ko 接受地区变体。
- 只有主动切换才写白名单 Cookie `nc-site-locale`：`Path=/; Max-Age=31536000; SameSite=Lax; Secure`，不设 Domain，不含用户标识。浏览器检测结果不永久保存，不额外维护 localStorage；Cookie 禁用时普通语言链接仍能导航。
- 菜单保留可抓取的链接并切换到同一内容。已打开页面不随别的标签页偏好改变而跳转，插件语言独立保存，不跨 origin 读取网站 Cookie。
- 明确语言页提供自身 canonical、双向 hreflang 与对应 sitemap；首页 x-default 指向根，其他内容指向英语。账户、身份回调、支付成功页 noindex，不进入 sitemap。
- CDN 排除中立入口、账户和支付页面；公开固定语言页按 URL 缓存，不按 Cookie 替换正文。不能据这些设计承诺收录或排名。

实施需覆盖五语／不支持项、权重／非法标签、繁简脚本优先、手动偏好、直接语言链接、Cookie 禁用、OIDC 回调、支付返回、无请求头访问及 CDN 不串语言。同步修改服务端入口、菜单、中文路由、内部链接、SEO 和测试；不得将待实施方案写成当前功能。
