# 翻译接口与阅读恢复契约

本文为现行接口。官方常规翻译交付 `overlay-v1` 覆盖文件，超长结果经协商交付 `overlay-tiles-v1` WebP 分块包；全部文件经中心鉴权直读。中心原图只保留到任务终态，不提供原图恢复；计算与存储分别见[集群架构](TRANSLATION_CLUSTER_DESIGN.md)和[存储规范](OBJECT_STORAGE.md)。

本文约束 **NodeLane 官方渠道**的后端 API 与客户端恢复行为。客户端渠道抽象、MTU 直传协议及缓存边界见[客户端翻译渠道](TRANSLATION_CHANNELS.md)；本地渠道不要求实现本文的账号、权益或持久任务协议。

插件与官网按权益选择正文模型的规则见[模型选择规范](TRANSLATION_MODEL_SELECTION_DESIGN.md)。可选 `model_id` 省略或为 `null` 时保留默认分流及旧请求摘要；显式选择须由服务端按权益校验，不能静默换模。

采用逐图翻译资源，机器契约见 [OpenAPI](../contracts/openapi.json)。客户端页面库使用 `node-comics-reading-v2-*`；原图使用 `original-v2-static-srgb` 渲染身份，固定 144 dpi 的 PDF 使用 `pdf-v3-static-srgb`，隔离旧缩放缓存、页面摘要与本地送译操作并保留书架和阅读进度。官方请求使用独立的 `translation-requests-overlay-v1` 库及带 `overlay-v1` 的账户 scope。升级与数据库基线遵循[部署规范](DEPLOYMENT.md)，不兼容旧资产下载协议。

## 1. 翻译流程

### 官网图片工作台

官网与插件复用 `backend/shared/translation-images` 的缩放、压缩、摘要和合成实现：保留高分辨率原文件，生成短边不超过 1800 的送译副本；需缩小或大于 1 MiB 时单次 WebP 0.9 编码，送译单边超过 16383 时改用 JPEG 0.3，有损压缩不额外缩小尺寸，透明区域铺白底。JPEG 编码单边按实现上限 65500 处理，而非格式字段上限 65535；超过时，无需缩放或规范化的合法原图跳过可选压缩，必须处理则报尺寸错误，不回退 PNG。同尺寸且输入无需额外规范化时，无体积收益或可选编码超过输出预算则保留合法原字节。选图允许单边最多 100000、不设独立总像素限制；32 MiB 文件限制与本地历史预算仍有效。选图与 Worker 均在像素解码前读取有界图片头；新送译副本遵守 API capabilities 的尺寸与字节限制，按需 Worker 串行处理。

注册用户调用现有 Bearer `/v1/translations`；游客调用同结构 Cookie `/v1/guest/translations`，均要求 `X-Translation-Protocol: overlay-v1`。游客额外使用 `X-Guest-Request: 1`，新 UUID 携带 `X-Turnstile-Token`（action=`guest_translate`）；`POST /v1/guest/session` 的 token 对应 `guest_session`。服务端校验 Turnstile hostname/action，不把前端成功当作准入。身份与限额见[会员额度](MEMBERSHIP_AND_QUOTAS.md#官网匿名体验)。

受理／上传前冻结本地 UUID、实际输入与结果格式；可选 `resultFormat` 字段随记录保存，旧记录缺字段表示普通覆盖，无需修改 IndexedDB 表结构。刷新和失联后先 GET 原 UUID，仅确认 404 才以同 UUID 提交原描述；恢复不按当前分块能力重选格式，`needs_input` 重传原字节。已冻结的本地送译副本缺失时明确失败，不重新编码并改写原摘要。SSE 退避核实，未知结果不自动重调。普通／分块覆盖均合成并保存完整译图，再次查看直接读本地；写盘失败仍可立即下载。明确重试／重译创建新 UUID，请求体使用 `retry_of`／`regenerate_of` 及可选 `model_id`，由服务端继承结果格式，不把传输失败当作重译。

提交请求、接收并保存译图分别显示本地进度；“同步已暂停”只描述客户端停止同步，不表示后端任务暂停。页面隐藏或断网后停止订阅，回到前台且网络恢复时核实原 UUID；用户主动暂停后由用户恢复。验证使用固定浮层，不占工作台布局；新匿名会话与新翻译分别取得各自 action 的 token，已有任务恢复不重复验证。

```mermaid
sequenceDiagram
  participant C as 客户端
  participant A as 翻译 API
  participant W as 持久任务与执行节点
  C->>C: 保存请求 UUID 与图片描述
  C->>A: PUT /v1/translations/{id}
  A-->>C: 翻译快照
  opt state = needs_input
    C->>A: PUT /v1/translations/{id}/input（原图字节）
    A->>W: 自动校验并排队
  end
  C->>A: GET /v1/translations/events?ids=…（SSE）
  A-->>C: snapshot：首次快照与后续状态变化
  A-->>C: end：本批完成，关闭连接
  C->>A: GET result.artifact.path（Bearer 鉴权）
  A-->>C: 覆盖文件
  C->>C: 校验原图与结果描述，原生尺寸合成并显示
```

同一在途任务已收到输入时无需重复上传；本人完成结果命中直接返回成功快照，不要求中心仍有原图。客户端只维护逐图 UUID，无需阅读会话或上传完成确认；结果地址随快照返回。

## 2. 页面身份与请求身份

- 本地 `targetKey` 为页面上下文与模式的 SHA-256，固定 64 个十六进制字符。这个本地键不进入翻译请求。
- 每次新的翻译意图生成标准 UUID，公开 `id` 固定 36 字符；发送前把 UUID 与完整业务输入保存到 IndexedDB。账户、内容、模式、语言分别隔离。
- 同一账户、同一 UUID 永久绑定相同业务输入。重复 PUT 返回原资源；换图、换模式、换语言、改变显式模型或重试来源返回冲突。任务不携带阅读优先级。
- 网络失败、刷新、扩展重启或回包丢失均继续使用原 UUID。先 GET 核实；明确未受理时可以重放原 PUT。不得通过生成新 UUID 自动重试状态未知的任务。
- 多个 UUID 指向相同的本人任务或结果时，服务端复用已有工作，不重复创建计算任务或扣量。删除后的旧 UUID 保留撤销回执，不能使被删除访问复活。

### 账户内复用

`Job` 保存执行和冻结结果，`TranslationRequest` 保存账户 UUID、请求摘要、Job 关系及撤销墓碑，`Asset` 保存输入与产物描述。匹配键包含送译 SHA-256、模式、语言、有效配置、规范化及结果版本，查询始终限制账户；图片摘要不赋予跨账户权限。

受理按 scheduler → user 顺序加锁，先核实原 UUID，再查本人在途与完成结果，未命中才创建任务和预占。命中不新增执行、分钟计数或页数预占，也不刷新生成时间；同 UUID 不受后来默认配置改变影响。显式重译创建新任务，保留旧结果；不同账户分别计算和结算，不共享原图或译文。

原图终态删除后，成功快照、本人复用、结果下载与译文详情仍有效。撤销一个 UUID 不影响其他有效本人引用，最后引用撤销后的回收见[存储规范](OBJECT_STORAGE.md#原图与结果清理)。

## 3. 创建与上传

```http
PUT /v1/translations/84ca7300-156d-46e8-952f-c2a65a447e72
Authorization: Bearer …
Content-Type: application/json
X-Translation-Protocol: overlay-v1

{
  "image": {
    "sha256": "<实际送译字节的 SHA-256，64 个十六进制字符>",
    "byte_size": 123456,
    "content_type": "image/png",
    "normalization_version": 1
  },
  "mode": "classic",
  "target_language": "zh-Hans"
}
```

能力响应必须声明 `result_protocol=overlay-v1`。全部 `/v1/translations` 业务路由都要求 `X-Translation-Protocol: overlay-v1`，包括创建、上传、单项／批量／历史查询、SSE、下载、取消、删除、反馈和详情；CORS OPTIONS 预检除外。缺少或不匹配时在读取请求体前返回 409 `CLIENT_UPGRADE_REQUIRED`，包含 `update_url=https://comics.nodelane.net/download/`；不能只保护创建而让旧客户端读取覆盖文件。

送译前统一静态首帧、EXIF 方向与 sRGB 色彩语义。插件来源页的普通静态图片保留原字节，带 EXIF/ICC/动画等语义的输入转换为静态 PNG。官网需 WebP 或 JPEG 编码时，由该画布步骤同时完成规范化，跳过中间的全尺寸 PNG；无需有损编码时，带元数据的普通尺寸输入仍转换为静态 PNG。阅读原图不因翻译而缩小。

官方渠道在创建请求前按 `min(1, 1800 / 短边)` 等比例缩小送译副本，尺寸四舍五入，不放大小图。需要缩小、原文件超过 1 MiB，或 AVIF 必须转换为服务支持的静态格式时，仅执行一次 WebP 编码（`quality=0.90`）；输出单边超过 WebP 的 16383 格式上限时，改用 JPEG（`quality=0.30`），透明区域铺白底，不因压缩进一步缩小尺寸，也不分拆计算任务。JPEG 编码单边最多 65500；超出时，仅无需缩放或规范化且仍符合中心能力的原图可跳过可选压缩，必须处理则报尺寸错误，新请求不回退 PNG。编码后读取有界 JPEG 头核验实际宽高，拒绝静默裁剪，不再次解码整图。不追求硬性 5 MB 目标，不循环降质量。无需缩小且不超过 1 MiB 的已规范化 PNG／JPEG／WebP 输入直接复用原字节；同尺寸重编码没有节省字节且输入无需额外规范化时，也保留原文件，避免无收益的有损压缩。AVIF 必须采用合规送译副本，即使编码后更大也不能退回 AVIF 原字节。原图始终不改写。摘要、大小和尺寸绑定实际送译字节；本地另外保存来源摘要用于页面匹配，不能把送译摘要覆盖到原图身份上。新编码策略为 `short-edge-1800-webp90-jpeg30-v2`；已有 `short-edge-1800-webp90-v1` 请求按冻结策略恢复旧 WebP／长图 PNG 字节，重试不切换编码策略。旧请求缺少缓存且冻结尺寸无法安全重建时，以 `SOURCE_CHANGED` 停止自动补传，不改变冻结摘要或自动创建新 UUID。缩放与编码在 Worker 内执行；扩展 service worker 直接使用自身后台线程，像素处理跨上下文串行，并复用同一锁限制结果合成。上传不占用像素处理锁。

送译尺寸与结果格式必须根据真实图片身份计算，不能使用目录或阅读布局的占位尺寸。尚未取得身份时先读取原文件，PNG／JPEG／WebP 复用有界图片头取得宽高，AVIF 使用原生解码尺寸；随后再检查服务能力和执行编码。已有真实身份的小图继续直接复用描述，不增加读取或解码。

中心统一校验实际输入字节与尺寸，默认最多 128 MiB、单边 100000，不设独立总像素上限；字节上限是传输安全边界，不是压缩目标。能力响应保留数值字段 `max_pixels`，其值由 `max_dimension²` 推导，供已有客户端读取，不另设面积准入规则。插件来源获取、原图保存与阅读、译图接收与合成不设单图字节、像素或边长上限；翻译入口生成的送译副本按中心能力提前检查，上传限制不参与来源读取和原图规范化。节点不另设图片字节、像素或单边准入上限，仅核对中心元数据、摘要、格式和规范化；资源并发、缓存总预算与格式整体读取预算仍有效，实际解码能力由浏览器与运行资源决定。

协议头与 `result_protocol=overlay-v1` 保留。普通请求省略 `result_format` 或使用 `overlay-v1`，其请求摘要、缓存键与单 WebP 交付沿用原规则。仅当中心 `representations` 声明 `overlay-tiles-v1` 时，插件和官网为送译单边超过 16383 的常规任务冻结 `result_format=overlay-tiles-v1`；不支持时在读取像素和创建远端任务前报错。中心仅在有启用且心跳有效的分块节点时公布该能力，分块任务只分配给声明该能力的节点。切块发生在整页检测、OCR、抹字和完整排版之后，不裁断文字框，不增加文本调用或页数结算。

发布顺序为中心、节点、插件／官网；中心与节点校验职责、数据库升级须按[计算协议](COMPUTE_PROTOCOL.md)及[部署规范](DEPLOYMENT.md)处理。普通翻译持续使用原交付路径。旧节点在格式协议上可领取普通任务，不能领取分块任务；新节点不能先向尚不接受 `result_formats` 注册字段的旧中心注册。旧插件继续读取自己的普通结果，但不能读取新版分块结果或在降级后恢复新版送译副本。新客户端仍遵守旧中心报告的较小准入范围。来源摘要、编码策略和冻结尺寸只保存在客户端本地；已有 UUID 恢复和下载不改变结果格式。此兼容性不包含缺少 overlay-v1 协议头的更早客户端。官网选图的文件与本地存储预算独立于插件阅读原图。

`mode` 仅为 `classic`。客户端不传书目、页码、客户端页键、会员策略或扣费上限。后端先核实重复请求、本人任务与完成结果，再检查分钟预算和会员额度；Redis 原子预占分钟次数，数据库将任务受理、页数预占与 UUID 回执在同一事务中提交。异常时短期次数可保守保留至过期，不重复扣页数，见[请求保护](SUBMISSION_SCHEDULING.md)。

为兼容已有 overlay-v1 插件，创建、重试与重译请求仍接受已弃用的 `priority: "current" | "prefetch"`，校验后忽略，不持久化、不参与调度或请求摘要。同一 UUID 增删或改变该字段仍返回原资源，不新增任务或预占；其他未知字段继续返回 422。新插件不发送此字段，已有 overlay-v1 插件无需随调度简化同步更新。

返回 `needs_input` 时，向同一资源的 `/input` 子路径发送已绑定摘要的实际送译字节。服务端限制实际收流大小、摘要、格式和可解码尺寸，原子写入中心任务私有临时文件后自动进入持久校验与执行，不需要第二次确认。重传不会重复创建任务或收费；输入过期、取消及原图不可用返回明确错误。

内部上传保护仍有期限和并发限制，崩溃恢复可核实已发布的任务输入文件；它不是客户端必须维护的阅读会话。中心只检查文件长度、摘要、结构和元数据，常规输入的完整解码与像素校验由计算节点在 OCR／文本调用前完成；坏图明确失败，不自动换 UUID 或重复扣费。校验和常规流水线由后端继续完成，不依赖扩展 service worker 常驻。

## 4. 状态与结果

| `state` | 含义 |
| --- | --- |
| `needs_input` | 尚缺原图字节 |
| `queued` | 已受理，等待校验或执行 |
| `running` | 正在翻译 |
| `succeeded` | 可交付结果，包括部分结果或无字原图 |
| `failed` | 失败、取消或结果已不可用；具体原因看 `error` |
| `needs_attention` | 上游结果未知，等待核实 |

快照包含 `id`、`state`、`execution_resolved`、`mode`、`target_language`、`image_sha256`、时间、`result` 与 `error`。公开 ID 始终是当前用户的请求 UUID，不泄露来源任务 ID，也不返回原图／译图资产 ID 或签名地址。

成功的 `result` 包含以下冻结描述：

- `kind=translated|partial|no_text`、`representation=overlay-v1|overlay-tiles-v1|full-image-v1|original`。
- `input_sha256`、`normalization_version=1`、整页 `width/height`、`quality_flags`。
- 有文件时，`artifact={sha256,byte_size,mime,path}`，其中 `path` 固定为当前 UUID 的 `/v1/translations/{id}/result`。
- 单文件覆盖另含整数 `bbox={x,y,width,height}` 和 `composite=source-atop`；文件为裁剪到变化范围的无损 RGBA WebP，透明像素代表保留原图。
- 分块覆盖不带 bbox，带 `composite=source-atop` 与 `application/vnd.nodelane.overlay-tiles` 文件。文件包含有界清单和连续 WebP 二进制块，每块带坐标、尺寸、字节数及摘要；整包只下载一次。格式与校验见[计算协议](COMPUTE_PROTOCOL.md#webp-分块包)。协商分块的任务若最终变化 bbox 能装入一个 WebP，仍可交付普通覆盖；无变化仍返回 original。
- `original` 不带文件、bbox 或 composite。`kind=no_text` 表示无文字；`kind=translated` 表示确认翻译成功但没有可见变化。二者都不下载图片，不因滚动自动重译。

扩展受信上下文向配置的中心 origin 携带 Bearer 和协议头 GET 读取 artifact，初始地址禁止外部 origin、其他 UUID 或查询签名，允许服务通过 HTTP 重定向交付结果；浏览器原生跨 origin 跳转移除 Authorization，令牌不进入来源页面。下载限制字节数和 MIME，公共 `materializeResult(result, original)` 统一核验 artifact 摘要，以及送译原图摘要、规范化版本、整页与覆盖尺寸。阅读器、原位翻译和导出共用此路径：按原生像素使用 `source-atop` 覆盖，最后由显示层缩放，保留原图 alpha 和阅读位置。分块包额外核验每块摘要、尺寸、非重叠范围与完整长度，逐块解码后释放；普通覆盖复用已经解码的补丁，由外层统一释放。

完整译图正常路径只编码一次：单边不超过 16383 时用 WebP 0.95；更长且不透明的图片用 JPEG 0.95，透明长图保留 PNG。JPEG 原图无需扫描 alpha，其他长图分段检测，不铺底、不缩小合成尺寸。有损编码减少存储和传输，但不承诺逐像素无损；原图、云端无损覆盖及冻结的送译字节不变。原生编码仅在单边不超过 65500、整页不超过 64×1024×1024 像素时使用，额外 RGBA 画布理论上限 256 MiB（不含解码图与编码器）；这是工作集预算，不是图片准入限制。JPEG 输出须核验头部实际尺寸；超出编码上限、原生编码失败或尺寸变化时，使用现有分带 PNG 合成保留完整像素。

超过原生编码工作集、画布不可用或编码失败时，复用小画布逐行 PNG 路径；合成条带最多 4194304 像素、RGBA 行缓冲约 16 MiB，另需原图解码与当前块内存，不额外创建整页画布。保留现有 PNG 编码，不新增逐像素 JavaScript 滤波；旧输入与原图规范化的编码字节不变，保证冻结摘要可恢复。分块仅改变结果编码和首次合成，整页模型计算不变，完整缓存命中跳过解码与合成；真实模型耗时、峰值内存及压缩率需独立验证。

IndexedDB 保存结果描述与校验后的完整译图，使用实际图片 MIME；旧 PNG 缓存继续直接使用，不批量重编码。阅读器、原位翻译和导出命中完整译图缓存时直接读取，不再恢复原图、校验覆盖文件或合成。持久译图受用户缓存预算限制，内存最多保留四页并受字节预算限制。完整译图缓存缺失时才重新下载同一结果并合成；原图独立保存于来源页缓存／主动离线存储，找不到时从同一来源恢复并核验摘要。恢复失败明确显示原图不可用，不能向中心取永久副本或自动重新扣费翻译。

缩小输入的覆盖结果始终在送译尺寸合成，不放大覆盖层到阅读原图。完整译图缓存缺失时优先读临时送译副本；缓存已淘汰或写入失败则从原图按冻结尺寸重新生成，并严格核对送译摘要，不假定跨浏览器版本的编码字节一致。摘要不符只报恢复失败，不自动重译。临时副本的缓存规则见[存储规范](OBJECT_STORAGE.md#插件临时送译副本)。

同一执行上下文的运行时与图片显示端共享最近 128 个快照，直接使用 SSE 描述；已有描述不追加 access 或签名查询。下载失败保留成功任务，只重试同一 UUID 的文件读取，不重调模型。

阅读器将任务成功、完整译图缓存就绪和实际显示分开：读取与解码期间继续保留原图及对应状态，实际显示元素加载后才撤下提示并启用该译图的反馈。长图提示在所属图片范围内保持视口可见，不改变阅读位置。预解码超过 120 秒显示可重试错误；显示层重试只重新加载已有图片，不创建翻译请求。`no_text` 不新增图内提示，也不自动重译；用户可通过右侧“重新翻译”按钮显式重译当前页。

## 5. 查询与恢复

- `GET /v1/translations/{id}`：查询一个本人请求及其冻结结果描述。
- `GET /v1/translations?ids=<逗号分隔 UUID>`：最多 32 个请求的批量快照，返回 `{items, missing_ids}`，用于刷新恢复和结果不确定时核实。未找到的 ID 与终态失败分开表示，不暴露其他账户数据。
- `GET /v1/translations/events?ids=<逗号分隔 UUID>`：同样最多 32 个本人 UUID，返回 `text/event-stream`。首个 `snapshot` 事件包含完整批量快照，之后只在内容变化时推送；`end` 的 `reason=complete` 表示本批无活动任务，`reason=reconnect` 表示应重新鉴权连接。客户端用流式 fetch 的 Bearer 头鉴权，令牌不放入 URL。
- SSE 使用数据库提交通知唤醒，合并短时间内的通知；等待时不持有数据库连接。20 秒注释心跳不查库，60 秒核实一次持久状态以补偿通知丢失。连接最多 295 秒且不越过令牌有效期，使用独立 Redis 请求预算与 300 秒并发租约；同一账户跨 API 实例合计默认最多 4 条，受 `translation_request_concurrency` 控制，超过上限返回 429 和 `Retry-After`。正常结束或客户端断开即释放，代理禁止缓冲响应。
- `ETag` / `If-None-Match`：普通快照未变化时立即返回 304；HTTP 快照查询不挂起等待。状态等待统一使用 SSE，通知只是唤醒提示，数据库是最终状态，不保存事件游标。
- `GET /v1/translations?offset=0&limit=50`：私有分页历史。插件不新增翻译记录页，也不通过历史接口恢复当前阅读。

每个客户端协调器最多保持一个 SSE 订阅，阅读器与原位翻译都在连续等待中复用此连接。部分页完成时保留订阅供剩余页面使用；阅读窗口或新增 UUID 改变订阅时才重建。无活动任务、隐藏、暂停、断网、离开页面、账户或渠道切换均中止订阅；连续 45 秒未收到数据或心跳则释放无响应连接。刷新后按已保存 UUID 批量核实未完成／结果不确定的请求，不能先取回整个账户历史；已成功的本地回执与完整译图直接恢复，不因重新进入窗口核实远端。已知撤销／过期结果仍拒绝读取，缓存缺失时走当前 UUID 的鉴权下载。普通控制请求与批量快照限时 30 秒，超时保留原 UUID；该期限不套用于 SSE 或原图上传。断流使用原 UUID 重连，网络故障指数退避并遵守 `Retry-After`，不持续进行 PUT/GET 循环。

协议切换不复用旧输入引用或旧结果缓存。新请求库没有当前页记录时，只读取旧库中的最小 UUID 与页面身份；当前页旧 UUID，以及同账户的旧未知／不确定请求，仅用 GET 核实。明确未找到才可自动发起新请求；已明确结束的旧页需要用户手动重新翻译。仍为 needs_input、queued、running、needs_attention 或网络核实失败时，不新建、不补传。旧不确定请求收到 `TRANSLATION_UNAVAILABLE` 时，只有 `execution_resolved=true` 才能解除未知保护；字段缺失或为 false 均继续阻止新建。该字段默认为 false，仅用于已撤销或不可用请求的执行证明：本人任务须已明确终态、额度已结算或释放，且无进行中或未核实的供应商调用；旧共享授权墓碑只使用迁移时冻结的完成证据，不查询他人的任务或费用。解除保护不恢复旧结果，同页仍须手动发起新 UUID；手动核实不重放旧 PUT、原图或旧 retry_of 描述。该检查按账户进行，不能因规范化后摘要变化而绕过。

配置、额度、订阅信息和用量统计在同一执行上下文内按 API 地址与登录会话共享 5 分钟内存缓存，并合并进行中的相同请求；令牌续期沿用会话缓存，退出后新会话不能读取旧账户缓存。`capabilities` 已含额度，不紧接着重复请求 `entitlements`。缓存只按需过期，不设置刷新定时器；普通点击、重试和页面获焦复用缓存。账户用量仅在进入页面、切换范围或明确刷新时读取；明确刷新权益与支付返回可强制更新，支付同步结果写回缓存。缓存展示不替代服务端受理时的权限与额度检查。

## 6. 失败重试与重新翻译

显式重试使用新的 UUID 和 `{ "retry_of": "<旧请求 UUID>" }`；只适用于已失败或取消的任务。已成功结果的显式重新翻译使用新的 UUID 和 `{ "regenerate_of": "<旧请求 UUID>" }`。两者均从来源请求继承冻结输入及结果格式，不因当前节点能力或默认值变化改为其他格式。

阅读器右侧“重新翻译”不依赖译图反馈入口，支持无文字终态、失败／取消和已显示结果。无文字终态使用 `regenerate_of`，不重新命中原来的 `no_text`。提交期间禁用重复点击；在途、结果待核实、渠道禁用或不可重试状态不能发起新任务。译图读取／解码失败仍走原图片重载入口，不转成模型重译。

例外是已确认的错误送译尺寸：用户显式重试时，只有原图已取得真实身份、来源摘要与旧请求相同，且旧编码尺寸不符合该原图的等比例缩放规则，才重新准备送译副本并以新 UUID 提交普通图片请求，不再继承错误输入。旧请求、结果及原图保留；正常冻结输入仍走 `retry_of`／`regenerate_of`，自动恢复与在途／未知请求不触发此修正。

状态未知时先核实原 UUID；自动滚动、状态查询和下载重试均不能创建新任务。明确终态后由用户主动重新翻译，新的 UUID 独立受理与计量。

`DELETE /v1/translations/{id}` 撤销当前 UUID 的访问，最后一个有效引用消失后按存储规则回收结果。`POST /v1/translations/{id}/cancel` 取消可取消任务；反馈与常规结果详情使用同一 UUID 的 `/feedback`、`/classic` 子路径。漫画与页面关系由客户端保存，不再提供独立文件页匹配或绑定接口。

## 7. 阅读触发与优先级

新漫画默认原图。用户选择翻译／AI 或明确打开译本后，才申请当前页与后三页；首次或远跳时当前页立即触发，后续页延后 150ms 预取。图片阅读器的滚动窗口：当前图顶部已滚过 `max(0, min(显示高度 / 3, 显示高度 - 视口高度))` 时，额外补一页，总窗口最多五页；可放入一屏的短图无需滚动即补位。每个实际当前页只扩一次，不移动阅读锚点，也不按已预取页递归扩张。前进到邻页继续补位，同页尾部扩张不重启 150ms。跨页滚动合并 80ms、最长 200ms，快速跳页仅保留最新待提交窗口。结果切换保持阅读位置，各页独立完成，失败不互相阻塞。

标签页翻译复用上述滚动合并时序和屏外预取名额，但窗口确定后以三个并发读取原图，不等待首张读完或额外的首张预取延迟。可见图片集合独立于最多五张的执行批次；双页或多切片同屏时分批补齐，不按 DOM 相邻关系漏选或撤销另一侧译图。显示保留与执行规则见[网页翻译](IN_PAGE_TRANSLATION.md#使用与识别)，来源读取并发不改变翻译渠道并发、单图请求幂等和服务端准入。

客户端逐图准备、恢复本地回执并提交，当前页优先；每次提交保留完整已准备窗口，不等整个批次的原图全部读取。读取前后检查窗口是否仍有效，旧窗口尚未开始的尾部不再读取，网页已离开的在途来源读取立即取消。逐图状态与显示不等待整个执行批次，已有本地译图不受新图准入退避影响。翻页不向中心更新优先级。中心按任务阶段就绪顺序领取。已受理的旧窗口请求继续完成；客户端隐藏或暂停时停止新增请求。

## 8. 限频、额度与安全

普通／付费会员（Lite、PLUS）每滚动 60 秒最多新增 10／100 张翻译图片，跨模式、语言、设备合计。实际预占购买常规页数的任务使用该额度包的会员服务档位、小时限制与优先级，但仍逐页结算；耗尽、过期或撤销后新任务回到普通权益，不影响已受理快照。已有原图的新翻译也计数；重传、UUID 重放、本人在途复用、完成结果复用不计数。取消和失败不退还分钟次数。免费每日额度、有限／不限量订阅、购买额度和赠送按[会员规则](MEMBERSHIP_AND_QUOTAS.md)处理，不由客户端预判队列容量。

账户权益的 `plan` 表示实际会员身份，`service_plan` 表示下一张常规任务的服务档位，购买额度独立显示 `purchase_quota` 汇总；订阅有效时购买余额仍可见。客户端不根据会员名称决定扣量，也不把额度包显示成无限订阅。购买记录通过私有游标分页接口读取，阅读主链路不下载历史购买桶。

`IMAGE_RATE_LIMITED` 为图片滚动分钟或套餐小时限制；小时拒绝附 `window_seconds=3600`，分钟拒绝省略该字段并沿用滚动 60 秒规则。`REQUEST_RATE_LIMITED` 为独立 HTTP 保护，均返回 429 和 `Retry-After`。客户端保留最新待提交窗口，按期限恢复，任务完成不能提前解除退避。额度不足只影响对应图片，图内提供升级入口，常规额度只在账户页展示。

图片授权、请求及结果复用按用户隔离，仅复用本人在途工作和结果，遵循[账户内复用](#账户内复用)。摘要不是跨账户访问凭据。中心原图在终态提交后立即清理，缺失清理可补偿；最终结果按[存储规范](OBJECT_STORAGE.md)保留。供应商成本与用户页数独立计量。
