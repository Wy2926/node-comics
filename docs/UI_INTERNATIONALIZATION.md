# 界面国际化

2026-09-20：代码已实现，完成本地检查与浏览器界面验收；未部署官网、未发布应用商店。

## 语言与行为

界面支持简体中文、繁體中文、English、日本語、Français、Español、Português (Brasil)、Deutsch、Italiano、Русский、Polski、Українська、Türkçe、Tiếng Việt、Bahasa Indonesia，共 15 种。语言名称按各语种原文显示。

外观与设置提供“界面语言”，默认跟随浏览器；无法匹配时使用英文。手动选择保存在本机，与漫画翻译目标语言独立。已有的韩语漫画翻译选项继续保留，不属于本次界面语言列表。

切换会更新阅读器、弹窗、设置、状态标签、日期与插件自有的网页工具条。React 订阅语言变化，不通过重新挂载阅读器切换语言。网页正文、漫画内容、用户标题和来源信息不属于界面字典。服务端或第三方返回的原始诊断文字可能保留其原语言。

## 字典维护

- 唯一文案源：`apps/extension/src/i18n/dictionaries/<locale>.json`，每语种一份完整字典。
- 普通文案以中文源文为键，品牌及商店字段使用 `brand.*`、`store.*`。`msg()` 提供类型约束与纯文本参数替换，参数使用 `{0}`、`{1}`，译文必须保留相同参数。
- `runtime.ts` 管理当前字典和订阅；`load.ts` 加载打包的本地 JSON、缓存与失败重试，并阻止较早的异步切换覆盖最新选择。失败时保留当前语言。
- `background.ts` 接收设置变化，更新右键菜单并通知网页中的插件组件；`content.ts` 只接受当前扩展发送的语言消息，不改变源网页语言。
- `store-locales.ts` 在 Vite/WXT 配置加载时生成 `public/i18n/` 和 `public/_locales/`，生成目录不提交。修改 JSON 后重启开发服务，或运行 `npm run check` 重新生成资源，再刷新页面。
- manifest 通过 `__MSG_*__` 引用名称、简介及工具栏标题，`default_locale` 为 `en`。Chrome 安装信息采用浏览器的语言，不随应用内手动偏好改变。

所有语种已提供完整字典并检查键与占位符一致。译文以机器辅助翻译为初稿，品牌、主要操作和漫画术语经过人工调整；尚未完成全部语种的母语校对。运行时不调用外部翻译接口。

## 卡片布局

书架、章节、卷册和副本卡片通过封面打开详情，移除重复的详情按钮；相关作品也通过封面或标题进入。保留阅读、选择、解除关联等不同用途的操作。卡片按钮占满可用宽度，文字允许换行，高度按内容增长，避免英文等长文案被双列固定高度挤出。

## 验证与复现

在 `apps/extension` 目录运行：

```powershell
npm run check
npm test
npm run build
npm run build:web
```

界面字典测试覆盖 15 种语种的键、参数与商店长度限制，语言匹配、偏好持久化、动态状态标签、源站类型解析、诊断分类、纯文本替换，以及异步切换顺序与加载失败重试。

本轮结果：类型与模块检查通过；31 个测试文件、320 项测试通过；扩展及网页构建通过。扩展产物校验确认 15 份字典与源文件内容一致、15 份 Chrome 元数据齐全。网页构建保留大于 500 kB 的分块体积提示，不影响构建完成。

浏览器验收使用 Vite 页面：设置页逐一切换 15 种语言，检查页面语言、标题与横向溢出；英文偏好刷新后恢复，漫画翻译目标语言保持原值。卡片验收在 Chrome 的隔离样本页运行：

```powershell
npm run dev -- --port 5175
# http://127.0.0.1:5175/tests/library-fixture.html?cards#settings
```

样本自带隔离来源检查，仅使用合成漫画管理数据与仓库原创图片，阻止外部请求。检查英文及德文大字号的章节、副本按钮边界与截图，验证书架封面 → 章节封面 → 副本封面的详情入口；无本地图片时阅读按钮仍禁用、封面仍可管理副本。

Chrome 扩展管理页面受到浏览器自动化安全策略限制，未进行已安装扩展的重新加载验收；普通 Chrome 页面交互、构建包元数据和自动化测试分别验证，不将它们表述为商店发布或已安装扩展完整验收。
