# 界面国际化

2026-09-24：完成插件字典覆盖审计与未使用条目清理，修复主要页面漏接；未发布插件。完整发现及逐文件清单见[本轮审计](UI_I18N_AUDIT_2026_09_24.md)。

## 语言与行为

界面支持简体中文、繁體中文、English、日本語、한국어、Français、Español、Português (Brasil)、Deutsch、Italiano、Русский、Polski、Українська、Türkçe、Tiếng Việt、Bahasa Indonesia，共 16 种。语言名称按各语种原文显示。

外观与设置提供“界面语言”，默认跟随浏览器；无法匹配时使用英文。手动选择保存在本机，与漫画翻译目标语言独立。

切换会更新阅读器、弹窗、设置、状态标签、日期与插件自有的网页工具条。React 订阅语言变化，不通过重新挂载阅读器切换语言。网页正文、漫画内容、用户标题和来源信息不属于界面字典。服务端或第三方返回的原始诊断文字可能保留其原语言。

## 字典维护

- 唯一文案源：`apps/extension/src/i18n/dictionaries/<locale>.json`，每语种一份字典。全部 16 种语言均在使用。
- 普通文案以中文源文为键，品牌及商店字段使用 `brand.*`、`store.*`。`msg()` 提供类型约束与纯文本参数替换，参数使用 `{0}`、`{1}`，译文必须保留相同参数。
- 动态文案使用有限字符串联合类型或类型受约束的映射；不要将任意字符串强制转换成 `MessageKey`。外部文本不能当作翻译键。
- `runtime.ts` 管理当前字典和订阅；`load.ts` 加载打包的本地 JSON、缓存与失败重试，并阻止较早的异步切换覆盖最新选择。失败时保留当前语言。
- `background.ts` 接收设置变化，更新右键菜单并通知网页中的插件组件；`content.ts` 只接受当前扩展发送的语言消息，不改变源网页语言。
- `store-locales.ts` 在 Vite/WXT 配置加载时生成 `public/i18n/` 和 `public/_locales/`。前者不提交；后者为仓库内商店元数据，按源字典生成。修改 JSON 后重启开发服务，或运行 `npm run check` 重新生成资源，再刷新页面。
- manifest 通过 `__MSG_*__` 引用名称、简介及工具栏标题，`default_locale` 为 `en`。Chrome 安装信息采用浏览器的语言，不随应用内手动偏好改变。

清理后每语种 705 键，生产调用的键和占位符覆盖完整。但 **63 个常用键在 14 个非简中／英文语种中仍为英文占位文案**，底层来源、解析、存储等模块也存在硬编码提示；不能将字典结构完整表述为全界面完整本地化。候选位置与逐键内容见审计报告。译文尚未完成全部语种的母语校对，运行时不调用外部翻译接口。

## 验证与复现

在 `apps/extension` 目录运行：

```powershell
npm run check:i18n   # 缺键、未使用键、参数及 TSX 中文硬编码
npm run audit:i18n   # JSON：上述结果、硬编码候选、与英文一致的键
npm run check       # 类型、模块和字典检查
npm test
npm run build
```

静态检查扫描生产 TS/TSX，追踪翻译函数符号、别名、有限联合类型的动态键和嵌套调用；保留品牌及商店元数据，测试引用不算生产使用。硬编码扫描是候选清单，不是语义完备的文案提取器；第三方返回文案、用户内容和任意字符串拼装需要单独判断。

字典测试覆盖 16 个语种的键、非空值、参数与商店长度限制，以及语言匹配、偏好持久化、动态状态标签、诊断分类、纯文本替换、异步切换顺序与加载失败重试。使用审计测试验证动态引用不会误删、测试专用键不能掩盖废弃条目、强制转换不能掩盖不确定键、调用参数缺失会报错。

本轮验证：类型和模块检查通过；扩展构建通过；16 份打包字典、16 份 Chrome 元数据与源字典逐项一致。全量测试结果为 80 个文件通过、1 个跳过，835 项通过、1 项跳过。全量测试发现原有后台路由夹具缺少 `chrome.tabs.remove`，已补齐该模拟及关闭标签断言；未修改 Drive 业务流程。依赖 `node-unrar-js` 仍有缺少 sourcemap 的警告，不影响测试通过。

浏览器在独立本地端口 5198、内置 Chromium 的 1440×1000 桌面视口验证：中文切换德语，缓存预算文案及选项、网站导入标题／按钮／说明、刷新后的语言保留，漫画翻译目标语言保持简体中文。检查截图确认修改的长文案正常显示；使用保留域名 `https://example.test/comic` 验证导入失败后按钮可再次操作，同时记录尚未国际化的底层错误提示。单元测试覆盖语言资源加载失败和重试。本轮未重验阅读位置恢复，未执行真实网站导入、翻译请求或已安装扩展全流程；构建验证不等同商店发布。
