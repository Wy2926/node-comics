# 漫画发现

主导航「发现」使用 AniList 公共漫画资料，帮助用户选择作品，再衔接已有[网站搜索](COMIC_SEARCH_DESIGN.md)查找可读来源。启动默认仍为「我的漫画」；首次进入发现才请求资料，无需 AniList 账号或令牌。

## 使用交互

- 默认趋势榜，可切换人气、高分、新作。公开查询限漫画与单篇，排除成人条目；新作按发行日期倒序并排除未来发行，明确选择「未发行」时允许查看待发行作品。
- 页面直接展示封面墙，不设大标题栏或独立搜索面板。榜单采用文字切换；点搜索入口展开行内输入，按 Enter 提交，无确认按钮；失焦或 Escape 后收起，保留已提交条件，丢弃未提交草稿。点筛选入口展开题材、连载状态、年份、地区、形式。切换榜单保留条件，条件可逐项删除或清空；搜索名称与筛选分别清除。
- 每页最多 24 条，滚动接近列表底部时自动加载下一页，不提供加载更多按钮。请求未完成、失败、打开详情或离开发现页时暂停触发，到末页停止。卡片封面外展示名称；评分、状态在封面顶部，年份与题材在封面底部渐变层。缺失字段省略、缺失封面占位，不承诺网站正文可用性。
- 设置中的「翻译书名与简介」开关默认开启，偏好保存在本机；发现页不再提供独立开关。开启后只翻译当前可见卡片的书名，打开详情自动翻译书名与简介。关闭后停止自动翻译，详情仍保留书名、简介各自的手动翻译入口及已完成结果的原文／译文切换；手动翻译一个字段不触发其他字段或卡片。目标语言始终使用页面当前显示语言；界面设置为跟随浏览器时使用已解析的浏览器语言，不单独设置文字目标语言。等待时展示「翻译中」，失败保留原文并可重试，限流遵守服务端冷却时间；译文完成后可查看原文／译文。手机端书名翻译操作紧邻年份数字，缺失年份仍可操作；桌面保留状态与漫画形式旁的原位置。简介的翻译状态、原文切换与展开／收起控制共享正文上方的一行，预留滚动条宽度，桌面展开不改变这行的位置，手机窄屏可换行。原文切换和「在 AniList 查看」使用带小图标的轻量文字操作，悬停显示强调色与细下划线，键盘聚焦保留清晰提示。查看原文不发起请求，不改变作品身份、别名或搜索种子。关闭开关取消自动在途请求；离开发现、滚出视口、进入来源搜索或切换界面语言取消对应在途请求，迟到结果不覆盖当前内容。手动触发仅限当前字段及语言，不因切换语言自动翻译新内容。
- 作品数量与榜单切换同一行，右侧提供搜索、筛选与刷新，不额外设置统计行或数据源徽标。详情左栏展示大封面，右栏顶部为标题与右上角大评分；评分放在带星芒、排线和硬阴影的漫画 SVG 贴纸上，年份配日历图标并保留大号数字。连载状态、漫画形式和题材采用切角纸签，别名采用对话气泡纸签；题材使用专用 SVG 插图，例如奇幻魔法帽、冒险地图、恋爱爱心和科幻行星，未知题材回退书签图形。所有图形沿用共享漫画调色板，文字保持可访问并可换行。创作者、简介与阅读入口依次排列；别名按需展开。右栏按标题、评分、年份、正文、辅助文字分级，字号、控件与封面遮罩复用共享令牌。
- 点击作品打开原生模态详情，桌面窗口尺寸上限为 1240 × 920px，并受视口留白限制。桌面仅简介与别名的共用区域滚动；封面、标题、评分、年份、标签、创作者与底部操作区保持固定，展开不改变窗口尺寸。手机详情整体滚动，简介与别名按内容自然撑高，底部操作及出处随之下移，不覆盖后续内容；手机标题与评分分列，评分保持在标题区域右上角，不因长标题换到下一行。评分上方不显示数据源文字，出处保留在底部；连载状态右侧展示来源返回的漫画形式。展开简介和外链操作不发起网站搜索。点「查找阅读来源」在同一弹窗内切换到现有搜索工作区；带入名称，别名按钮只修改输入。网站选择、直接／翻译名称搜索、候选确认、导入失败与继续阅读沿用搜索规范。
- AniList ID 只标识作品资料，不能作为可读目录或书架身份。只有来源搜索候选的真实来源身份可以判断已有漫画；不同网站仍独立导入。
- 发现列表、详情与来源结果各自保留本次页面会话和滚动位置。从阅读器「返回发现」恢复来源结果；关闭弹窗回到原卡片焦点。页面刷新后重新建立发现会话。
- 翻页失败保留已有卡片，在列表底部提示并由用户重试失败页，不反复自动请求；首次加载和刷新失败在顶部提示，作品详情独立重试。过期缓存可以展示，失败时明确提示。限流依服务端 `Retry-After` 显示倒计时；请求取消或被新筛选替代后，迟到结果不能覆盖当前页面。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `src/discovery/types.ts` | 作品资料、筛选与只读 provider 契约；不引用来源、书架或 UI |
| `src/discovery/anilist.ts` | GraphQL 字段／枚举转换、响应校验、公共 HTTP、超时与限流；不携带 NodeLane token 或源站凭据 |
| `src/discovery/session.ts` | 请求取消、迟到隔离、分页去重、页内有界缓存；不导入 React、持久化或导入服务 |
| `src/ui/discovery/` | 页面、筛选、详情、提示和焦点／位置恢复；以 `renderSearch` 接收搜索工作区，不解析网站协议或写入书架 |
| `src/text-translation/` | 独立文字翻译适配器契约、注册与有界会话；UI 只调用公共入口，不依赖图片翻译、账户或来源协议 |
| `src/ui/comic-search/` | 复用搜索会话，提供 page／sheet／embedded 三种显示；可选别名是通用搜索输入，不识别 AniList |
| `src/App.tsx` | 导航及注入现有导入动作；检查操作所属视图仍有效后打开阅读器 |

客户端仅按需加载列表和选中作品详情。列表缓存最多 20 页、有效期 5 分钟，详情缓存最多 40 项，均仅驻留当前页面内存；不建立 AniList 镜像库。外部简介与译文始终作为文本渲染，链接与图片地址由 provider 校验。视觉沿用[共享令牌](POPUP_AND_THEME.md)，界面文案遵循[国际化规范](UI_INTERNATIONALIZATION.md)。已知题材在筛选、已选条件、卡片与详情中跟随界面语言，由 UI 层的受类型约束映射统一翻译；筛选值、会话缓存与图标匹配保留原始题材值，未知题材回退原文。原始作品名、简介、别名与创作者资料不改写。

当前内置 Google Translate 无密钥适配器，使用 `translate.googleapis.com/translate_a/single` 的匿名 `client=gtx` 文字接口。仅在自动翻译设置开启或用户在详情主动翻译时，将对应公开书名／简介通过 POST 正文发送给 Google，不发送账户 token、Cookie、来源 URL 或正文图片；无需 NodeLane 登录，不计图片翻译页数。此匿名接口不是有可用性承诺的 Cloud Translation API，可能发生访问限制、限流或格式变化，失败沿用原文。适配器只负责本站文字协议，不识别 AniList；新增文字服务通过注册表接入，不改网站适配契约。

文字会话最多 2 个字段并发、40 个等待／执行任务，按服务、目标语言与完整原文复用相同请求。成功缓存仅保留当前发现页内存，最多 120 条且键值合计最多 512,000 个 UTF-16 单元；关闭视图取消请求，销毁页面清空缓存。长简介按不超过 4,001 个 UTF-16 单元的片段顺序翻译（输入上限 16,000），保留 Unicode 与段落分隔，不截断全文；每段 15 秒超时、响应上限 512 KiB。只按视口请求，不预译整个榜单，不自动重试失败字段。

公开查询认证规则见 [AniList Authentication](https://docs.anilist.co/guide/auth/)，商业使用按 [AniList Terms of Use](https://docs.anilist.co/guide/terms-of-use)处理；当前实现不包含个人书单授权或同步。

验证命令及浏览器条件见[脚本入口](../scripts/README.md)。`verify_discovery.mjs` 验证生产 MV3 入口与隔离 HTTP 夹具；`--live` 仅访问公开 AniList 列表／详情，不验证真实漫画网站导入或翻译效果。
