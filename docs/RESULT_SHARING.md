# 账户内结果匹配与复用

翻译只在同一账户内复用，图片摘要不赋予跨账户权限。公开接口见[翻译契约](READING_TRANSLATION_CONTRACT.md)，文件生命周期见[存储规范](OBJECT_STORAGE.md)。

## 请求与结果

- `jobs` 保存实际受理的任务、冻结结果描述及产物关联；命中本人在途任务或完成结果时，不新建执行、分钟计数或额度预占，生成时间也不刷新。
- `translation_requests` 用账户和 UUID 关联本人 Job，同时保存请求摘要与撤销墓碑。多个有效 UUID 可以指向同一 Job，公开响应始终使用当前请求 UUID。
- `assets` 保存输入描述和结果文件描述。不存在额外的结果副本、共享访问授权或文件页匹配记录。
- 输入描述与结果描述独立于原图文件。原图终态删除后，本人命中、成功快照、结果下载和译文详情仍然可用。

## 匹配与并发

匹配键包含送译 SHA-256、模式、语言、有效配置及规范化/结果版本；查询始终限制账户。按 scheduler → user 顺序加锁，先核实原 UUID，再查本人在途与完成结果，未命中才受理和预占。

同 UUID 严格校验受理摘要，不受后来默认配置变化影响；不同内容不能覆盖既有 UUID。显式重译生成新任务和新结果，保留旧结果。不同账户相同页面分别计算和结算，不共享临时原图、译文或访问授权。

## 读取与撤销

成功快照携带 `overlay-v1`、`full-image-v1` 或 `original` 描述。覆盖层由客户端用同摘要原图合成，完整结果直接显示，无字不下载。结果通过中心鉴权流式返回，不签发下载地址。

`DELETE /v1/translations/{id}` 撤销本人 UUID。其他有效本人引用继续可读；最后一个有效引用撤销后回收结果文件，保留 UUID 墓碑和结算证据。撤销的 UUID 不复活。

下载失败不改变任务成功状态，不自动重调供应商。缺失文件返回 `RESULT_UNAVAILABLE`，按备份恢复；原图缺失由客户端来源或本地缓存恢复。

## 验证

隔离测试覆盖 UUID 重放、同账户命中、跨账户拒绝、并发只受理一次、终态原图删除、最后引用回收、下载失败不重扣及无字复用。SQLite 与真实 PostgreSQL/Redis 分别验证状态与并发；真实模型及浏览器显示单独验收。
