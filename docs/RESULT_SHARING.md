# 译图共享与匹配

原图按内容去重，译图按有效配置共享，访问授权按用户隔离。公开接口见[翻译契约](READING_TRANSLATION_CONTRACT.md)。

## 存储与权限

- `jobs` 只记录实际受理的翻译。显式重译建立新任务，保留旧结果；缓存命中不创建任务、执行阶段、分钟准入事件或额度账本，也不进入管理后台真实任务列表。
- `translation_results` 每次真实生成完成登记一条，包括无字结果；主键为生成任务 ID，记录内容匹配键与真实生成完成时间。重复完成通知不重复登记，核实成功的重绘也在同一交付事务登记。
- `result_accesses` 每个用户、每个生成版本最多一条，保存自己的图片授权引用与版本。没有供应商配置、执行阶段或扣费记录。
- `translation_requests` 以账户和请求 UUID 为复合主键，通过互斥外键指向真实任务或结果授权。重复 UUID 严格校验业务摘要；公开响应始终返回请求者的 UUID，不泄露生成者私有任务 ID。
- 图片对象按内容全局去重；本人的同内容、同类型、同父图有效 Asset 授权复用。用户删除只撤销其授权，共享对象不删除。其他用户已有有效授权时，该版本仍可作为共享来源；所有来源都失效时不能命中。

同一内容被 N 个新用户复用，新增的是必要的私有结果授权、图片授权及请求回执，不是 N 份完整任务。结果条数随真实生成次数增长。再次明确请求有效共享版本可更新本人已失效的结果授权；原已删除 Asset 不复活，旧地址与旧撤销 UUID 仍然失效。

## 匹配与并发

使用原图字节 SHA-256、模式、语言及当前有效配置版本生成匹配键。`translation_results(cache_key, generated_at, id)` 索引按真实生成时间查找版本；SQL 验证是否存在有效来源，不把所有用户授权展开后排序。

按 scheduler → user 顺序取得锁，核实原 UUID、本人任务与完成结果，校验匹配键、原图、译图和删除／到期状态。命中后原子写授权和请求；未命中才建立真实任务、分钟事件与页数预占。当前配置变化不会改变原 UUID 的受理身份，也不能使旧配置结果成为新配置命中。

读取原图先通过用户＋内容索引查本人授权，再查有效共享原图。匹配、快照与签名查询不访问 R2；批量快照和历史先批量加载关联元数据，避免逐条查询。上传验证、执行器取图与下载仍按对象存储契约访问实际字节。

## 阅读接口

缓存命中返回与普通生成相同的翻译快照：`id` 为本人请求 UUID，`state=succeeded`，`result` 提供私有资产和短期下载地址。无需让客户端辨别“真实任务”和“缓存别名任务”。批量状态、文件匹配、反馈和显式重译都使用公开翻译 UUID；反馈后台仍可关联实际生成任务供诊断。

本人有效结果优先复用；其他用户匹配全局结果时按真实生成时间选择。新增授权或重放请求不刷新共享版本的生成时间，旧译图不会因近期复用而挤掉新译图。

## 验证

使用[后端隔离测试](../backend/README.md#验证)以及[翻译契约验证入口](READING_TRANSLATION_CONTRACT.md#9-验证入口)。覆盖多用户命中后的行数、无额外任务或账本、私有 UUID 隔离、文件恢复／反馈／重译、删除生成者后其他授权继续共享、旧 UUID 不复活、生成时间排序及批量查询开销。

SQLite 与显式启用的 PostgreSQL 套件分别验证；供应商调用使用隔离模拟。模拟检查不替代真实图片效果、R2 接入或生产性能测量。
