# 跨语言漫画搜索

从网站作品页、书架或阅读器发起「寻找其他语言」，获取目标语言的常用漫画名，再由用户选中的适配网站独立搜索。候选按到达顺序显示，用户核对后打开来源或导入阅读。适配隔离遵循[网站适配](SITE_ADAPTERS.md)，每本漫画仍绑定单一来源，见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md)。

## 入口与交互

| 入口 | 行为与标题来源 |
| --- | --- |
| 网站 | 「导入/管理漫画」旁的次要按钮；插件弹窗也提供入口。在新扩展页打开面板，保留源网页。标题来自本站 `describeWork()` 或可信目录；无法确认作品名时留空手填，不能把章节标题或通用 `document.title` 当作品名 |
| 书架 | 卡片更多／右键菜单的「寻找其他语言」，使用 `Comic.title`；本地／云盘漫画也可查找 |
| 阅读器 | 阅读设置的操作区提供入口，页面未就绪时仍可打开阅读设置查找。使用所属漫画标题；记录位置后收起阅读设置、打开面板，Reader 保持挂载，关闭后焦点回到阅读设置按钮 |

三个入口共用 `ComicSearchPanel`。桌面采用右侧 720 px 抽屉，窄窗自适应全宽；使用现有主题令牌、Select、按钮、描边和封面组件。面板为原生模态 dialog，背景不可交互，阅读快捷键暂停；关闭后恢复焦点和阅读位置。语言下拉的 Escape 先关闭下拉，面板 Escape 关闭面板。

面板依次包含：

1. 原作品名称、来源和可用封面。名称可修正，仅用于本次查找，不修改书架资料。
2. 「名称目标语言」和「翻译名称并搜索」。优先取本机上次名称目标语言，否则取图像翻译目标语言；名称语言独立保存，不更改图像翻译设置。该语言只用于获取漫画名称，不限制网站或结果。打开面板不自动调用名称或搜索服务。
3. 可编辑的「搜索名称」。点击主按钮获取常用名称，随后自动查所选站点；手填 Enter／搜索按钮直接查询，输入过程中不联网。可明确选择「使用原名搜索」。名称 API 返回其他语言时说明实际名称语言，仍使用该名称搜索。
4. 可展开的网站范围；所有实现搜索的站点默认选中，可逐站取消。未实现搜索的站点单独列出，不依据主要语言或搜索结果语言排除网站。
5. 各站独立状态、已返回数与失败数。任何站返回即可操作其结果；停止不丢失已有候选。每站可重试、加载更多或打开源站处理登录／验证。浏览器撤销访问权限时，面板统一提示到扩展设置允许访问所有网站，不提供逐站授权按钮。
6. 按到达顺序追加的结果卡片：封面、标题、作者、来源、网站实际提供的语言和可选源站最新说明。未提供语言时不显示语言标签或占位；不按语言筛选结果。「打开来源」与「导入并阅读」可立即使用，不等待其他站；按网站查看属于本地筛选，不重新请求。

结果仅为搜索候选，不自动确认跨站同作，不展示模型推测概率。没有封面或作者时显示占位说明；没有语言时省略语言，不用名称语言或站点主要语言补齐。分页由用户逐站触发，不自动读取所有结果或候选完整目录。

同来源作品已在书架时「继续阅读」，当前来源标明「当前漫画」。新来源导入为独立漫画，不替换原来源、不迁移章节或阅读进度。导入失败在候选卡片中显示，原列表保留。

## 语言语义

搜索只按名称查询；名称目标语言只传给名称 API，不传给站点搜索。网站列表、服务端请求和聚合结果均不按语言筛选。`SourceSite.primaryLanguages` 仍仅供网站列表展示。

- `SourceSearchHit.contentLanguages` 可选，仅来自网站实际提供的信息。源站代码由适配器转换为 BCP 47，公共层校验格式，不根据目标语言、标题或站点主要语言推断。
- 语言数组缺失或为空时卡片不显示语言；有值则如实展示，包括不同于名称目标语言的值。
- 搜索导入沿用普通阅读设置及每本漫画已有的内容语言偏好，不把名称目标语言写入正文偏好，不因为章节语言不同阻止导入。目录仍可手动选择内容语言偏好；已有漫画的偏好与进度保留。

## 公共契约与依赖

类型的唯一规范在 [search.ts](../apps/extension/src/sources/contracts/search.ts)、[work.ts](../apps/extension/src/sources/contracts/work.ts)、[network.ts](../apps/extension/src/sources/contracts/network.ts)。

站点在 `definition.ts` 的具体 `SourceSite` 上可选声明 `search`，只声明必要 `requestOrigins`；`network.ts` 可选实现 `search(request, context)`，请求包含站点、名称和可选游标，复用现有静态注册体系。无搜索能力不影响导入、原位翻译或目录更新。搜索返回有界候选页与不透明游标，不返回或伪造完整 `SourceCatalogSnapshot`。

公共层校验候选作品 URL、适配器归属、`catalogId`、文本长度、可选语言标签和数量，并补入 `sourceId/siteId/key`。候选 key 序列化为 `[sourceId,catalogId]`：同适配器镜像可去重，不按标题合并不同站点。游标绑定会话、站点和关键词，10 分钟有效；新轮／销毁释放旧游标。

```text
站内按钮 / Popup / Library / Reader
  → SearchSeed → ComicSearchPanel
  → ComicSearchSession
      ├ title-resolver → Api.translateComicTitle
      └ sources 公共入口 → search runtime → 本站 network.search
  → importSearchResult → 原有目录导入与阅读应用服务
```

| 模块 | 职责 |
| --- | --- |
| `comics/application/search/` | 名称校验与解析、单轮状态、3站并发、逐站结果、分页、重试、取消及代际隔离；搜索权限与整页超时交来源运行时负责 |
| `ui/comic-search/` | 订阅会话、共享面板、独立错误与懒加载封面，不解析站点协议 |
| `sources/core/search.ts` | 能力／请求／候选及可选语言标签校验 |
| `sources/runtime/search.ts` | 搜索权限与整页超时、游标、候选封面凭据、取消和搜索错误映射 |
| `sources/runtime/http.ts` | 目录、正文和搜索共用的有界 HTTP 传输、逐请求权限／地址校验及通用传输错误，不依赖搜索业务 |
| `sources/sites/<id>/` | 本站搜索URL、协议、字段、分页和可选语言信息；不调用Chrome、UI或仓库 |
| `sources/runtime/search-entry.ts` | 来源标签页校验与短期一次性上下文；标题不放地址栏 |
| `comics/application/search-import.ts` | 候选导入及沿用普通续读，不写入名称语言偏好 |

网页按钮只发送打开意图。后台核对同扩展 sender、顶层 tab、来源 URL 与适配器身份，再获取轻量作品信息；不为获取名称抓整套目录。上下文保存在受信 `storage.session`，5 分钟有效、最多 8 个，通过扩展同源 Web Lock 一次性消费，URL 只携带随机句柄。导航变化、畸形／过期数据拒绝；消费后的迟到结果不能覆盖后来的导航或查找意图。章节没有可靠作品信息时允许手填。

网站访问由插件配置统一声明必需 HTTP／HTTPS 全站权限，规则见[网站适配](SITE_ADAPTERS.md#必须保持的约束)。搜索不会申请额外授权；本站 `requestOrigins` 仅限定本次操作可请求的地址范围。每次 HTTP 请求重新检查浏览器当前访问权限和声明范围并拒绝重定向，不开隐藏源站采集标签页。Cookie／令牌不上传到名称服务。

`readSearchCover` 只接受本运行时校验、登记过的候选，复用现有取图和请求头管线。可见卡片才加载封面，独立限制 3 并发；封面请求以来源身份和图片 URL 为准，补充作者等信息不触发重下。144 px WebP 缩略图最多缓存100张，旧查询不再引用的图片及时释放。图片权限不足时保留占位，文字结果正常使用。已导入作品摘要封面复用书架缩略图。

## 名称与会话生命周期

`POST /v1/comic-titles/translate` 接收 `{name,target_language}`，返回 `{name,target_language}` 或两个字段均为 `null`；返回语言是实际名称语言，可能英语回退。没有别名列表、作者或跨站作品ID。请求需要登录，不消耗翻译页数。

输入漫画名去空白后按 Unicode 码点计数，限制 1–60 并拒绝控制字符；不截断标题。返回名称不能套用60字输入上限，下发站点统一检查1–160字的产品查询预算，超长则允许编辑。名称找不到时等待手填／明确用原名，不自动无休止重试。

同原名和请求名称语言在面板会话内复用一次结果；单站重试、翻页、展示筛选不再查名称。`401` 提供登录与手填；`422` 就地修正；`429` 遵守 `Retry-After`，手填仍可用。`COMIC_TITLE_BUSY/PENDING` 有 `Retry-After` 时最多自动重试一次。真实模型效果不由模拟响应证明。

最多3站同时执行，每站1请求；来源运行时统一执行单站单页15秒预算，最多50候选，HTTP响应上限8 MiB。应用层不重复计时或预查搜索权限。一个慢站或失败不阻塞其他站。总状态与各站状态分离，不等待全部返回才显示；轮次与每站attempt共同拒绝迟到响应，AbortSignal贯穿名称与搜索。分页游标过期后单站重试从首页重新取得游标，已有候选保留并按身份去重。

修改名称目标语言、原名或站点选择取消旧轮并清除旧结果；搜索名称在提交时开始新轮。关闭／停止取消在途请求并拒绝迟到结果。结果可留在当前页面内存，同条件重开显示上次时间并等待用户重搜。刷新页面、切换作品、账户或API清除会话，不建立持久搜索历史。取消名称HTTP只能停止等待，不能承诺撤销已开始的后端模型计算。

## 当前适配与验证

当前可搜索：DM5、瓜子漫画、MangaCopy（含已声明镜像）与 MangaDex。各自查询编码、空结果、分页、字段和真实 HTTP 复跑入口见站点 README；其他站仍可作为查找起点。MangaDex只按名称搜索，并展示实际章节语言列表；没有返回语言的站点省略语言标签。

- `npm --prefix apps/extension run check`：类型、依赖边界、能力一致性与字典。
- `npm --prefix apps/extension test`：语言、候选／游标／权限、会话并发／取消、API回退、作品种子与多语言导入回归。
- `node scripts/verify_comic_search.mjs`：构建后的隔离MV3界面，源站与名称使用fixtures；覆盖入口、渐进结果、键盘、主题、导入和位置恢复。环境准备见[脚本说明](../scripts/README.md)。
- 站点 `tests/verify-search-http.mjs`：真实公共HTTP查询与分页；不调用名称模型、不证明浏览器安装权限与撤权行为、真实模型译名或跨站同作识别效果。

原型和验收截图保存在忽略的 `artifacts/`，不进入生产构建。浏览器安装权限、手动限制网站访问与恢复需要单独验收，隔离夹具不能证明 Firefox 等目标浏览器的实际行为。
