# 网站适配

站点位于 `apps/extension/src/sources/sites/<站点>/`，同协议复用 `shared/`。具体解析、URL 和限制以该站代码及测试为准。

- `definition.ts`：纯元数据、URL 识别和能力声明；不引用浏览器运行时。
- `network.ts`、`search.ts`：目录、分页与名称搜索；使用公共请求上下文。
- `page.ts`：页面识别与导入入口；`image.ts`：站点专属取图策略。
- 注册表统一发现模块。公共层不导入具体站点、不按站点 ID 分支。
- 只有验证过完整目录才声明完整发现、导入或自动更新能力；分页失败不能当作完整结果。
- 取图复用公共传输，保留 Referer、取消、超时与大小限制；源站凭据留在浏览器。
- 网站目录只读；一本漫画绑定一个来源，失败重试与刷新保持阅读位置。

新增适配先补本地协议夹具，再按需要验证真实网站。运行 `npm run check` 和相关站点测试；模拟通过不代表源站登录或反爬验证通过。

官网使用插件导出的发布快照，更新方式见[插件 README](../apps/extension/README.md)。
