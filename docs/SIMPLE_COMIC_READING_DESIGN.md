# 单来源漫画与直接阅读

当前单来源产品契约；存储与权限实现见[来源架构](COMIC_SOURCE_ARCHITECTURE.md)，验证入口见[脚本说明](../scripts/README.md)。

## 产品边界

用户打开漫画即可阅读。一本漫画只绑定一个确定的来源资源；标题、封面、目录与页序来自该资源，插件只记录阅读位置。没有资料编辑、内容编目和版本选择。

- 本地仅支持 CBZ／ZIP、CBR／RAR、PDF、未加密 MOBI／EPUB。每个文件独立成书。
- 当前云盘驱动为 Google Drive，支持 CBZ／ZIP、未加密 MOBI 按需读取；MOBI 格式限制与本地一致，不扩大到其他格式或供应商。
- 远程书库支持多个 OPDS 连接。配置服务地址和授权后浏览，点开出版物直接阅读；支持范围和安全限制见[来源架构](COMIC_SOURCE_ARCHITECTURE.md#远程书库与-opds)。不导入整个远端目录。
- 本地与云盘均不支持单张图片、多张散图或图片集合导入。漫画容器内的图片仍可解析阅读。
- 网站必须有随插件发布的专用适配器，并明确声明可导入。未适配网页、任意图片地址、右键图片均不能加入书架。
- 通用网页的原位翻译仍可使用；它不创建漫画、不提供图片选择或导入功能。

## 来源身份与重复导入

| 来源 | 一本漫画的身份 |
| --- | --- |
| 本地文件 | 已保存的完整文件内容摘要与大小；改文件名再导入仍复用原记录 |
| Google Drive | 连接账户与固定 file ID；不为去重下载整包 |
| 网站 | 适配器 ID 与其证明的漫画资源键；无作品目录的专用单页站点按页面资源识别 |
| 远程书库 | 独立连接与稳定出版物 ID；不按标题或 ISBN 跨连接合并 |

不同文件、不同云盘文件和不同站点分别成卡，即使标题相同也不合并。CDN 图片地址是取图机制，不构成另一来源。网站阅读页只有在适配器能证明所属目录时才与该目录共用一本漫画。关联作品只作为来源链接，不自动导入。

重复打开复用漫画与阅读位置。同一图片的字节和有效翻译结果仍可按摘要复用，但不共享书架归属。

## 导入与书架

“导入漫画”直接打开文件选择器，拖放使用同一自动队列；旁边的“云盘”菜单进入已接入的文件选择器。没有来源选择弹窗、归属表单或导入前确认。

“远程书库”独立管理连接并按需浏览，首次打开才加入“我的漫画”。可以切换多个服务器或账户，但一本漫画仍只绑定一个连接的出版物。只有必须先保存完整文件的资源需要下载确认，完成后在离线中心开始阅读。返回远程书库保留目录、搜索和滚动位置。

- 单本：完整文件保存并建立索引后直接打开。不会等待全本图片解码或翻译。重复文件直接续读。
- 多本：逐份自动导入、各自成卡，留在书架。紧凑进度可展开查看失败、重试、暂停或停止剩余文件；一个失败不阻塞其他文件。
- 不支持、损坏、DRM 或空间不足会显示明确原因，不生成空漫画。关闭页面后没有复制完成的 File 需要重选；已保存的文件通过导入日志恢复索引。
- 准备期间若用户已经打开其他漫画，完成后不抢占阅读器。
- 云盘选择完成后自动登记引用与索引；单选直接读，多选留在书架。云盘账户的 OAuth 同意仅在需要时出现；不支持的远端格式提示下载后本地导入。

书架保留搜索与最近阅读排序。卡片封面左上角显示来源，左下角显示本机保存的最近阅读时间，未读漫画显示“还没阅读”；不展示页数位置标签，实际阅读位置继续保存。点击封面或标题直接开始／继续阅读，卡片底部只保留标题。更新徽章叠在卡片右上角，可伸出封面边缘。右键、长按或聚焦卡片按钮后按 Shift+F10 打开菜单，提供开始／继续阅读、[寻找其他语言](COMIC_SEARCH_DESIGN.md)、适用的打开来源、导出与移除漫画；目录导航保留在阅读器内，不另设卡片目录弹框。没有编辑与版本计数。返回书架保留搜索、排序和滚动位置。

本地与云盘文件保持首页封面。网站可选提供专门作品封面，现有适配站点均支持：优先展示，随目录更新，不被正文覆盖；未提供时沿用首页封面。加载失败可重试，不阻止阅读；浏览器撤销网站访问时提示在扩展设置恢复全站访问，不逐站弹授权。

“批量管理”支持勾选、全选当前搜索结果、取消选择与批量移除。选择覆盖尚未渲染的卡片，搜索或排序不丢失已有选择；确认框显示所选数量与漫画名称。逐本移除沿用单本的记录与引用释放，单项失败不阻塞其他项，失败项可重试。离线任务统一在离线中心管理。设置中的本机资料、独立缓存与云盘账户使用同一宽度和卡片样式。

桌面与手机共用组件和阅读流程；布局条件、浏览器能力与真机验收边界见[共享视觉规范](POPUP_AND_THEME.md#手机布局与浏览器能力)。

## 网站与只读目录

已适配阅读页点击“开始阅读”后加入书架并打开当前内容，完整目录稍后读取，不阻塞当前图片。作品链接导入后直接阅读：已有记录恢复上次位置，首次使用适配器声明的默认入口所在话，否则按来源顺序打开首个可阅读章节；具体章节链接保留该发布条目的明确选择。普通导入不增加“选择开始阅读的位置”页面；空目录或所有条目不可读时显示明确原因。

支持目录进度的站点可在首批章节确认后开始阅读，后续目录在后台补齐；未加载的章节不展示为已确认。目录面板显示加载状态，失败或关闭浏览器后保留已加载章节及当前位置，并提供“继续加载目录”。补齐目录不重开当前章节、不移动当前页、不把首次剩余章节显示为新增更新；完整目录仍由来源最终校验。

核心只理解稳定条目、顺序和导航，网站的分类可以是不确定的标签或有界树形分组：

- `SourceEntry` 提供稳定 ID、URL、标题、顺序、原始标签与可选 `sequenceId`、内容语言及来源证明的阅读位置键；来源明确不可读的发布条目不参与自动选择。
- `SourceGroup` 提供 ID、标题、`entryIds` 和可选 `parentId`。同一条目可以在多组出现，但只保存一份进度。
- `SourceCatalogSnapshot` 可提供 `defaultEntryId`，公共层在该条目所属话中选择适合的语言；缺失时沿用源目录顺序，不通过标题猜默认入口。
- 自定义分类原样只读显示，不映射为核心的 chapter／volume／main／extra 类型。条目、组引用、URL、深度和数量在公共层校验。
- MangaCopy 仅按源站 `default` 分组标识确定默认入口；其余分组 ID、名称和原始标签从页面动态读取。“同人漫画”“其他系列”等属于当前漫画 URL 的条目仍可阅读，不按分类名称判定为关联作品。站点解析与样本见[MangaCopy 说明](../apps/extension/src/sources/sites/mangacopy/README.md)。
- 连续阅读只沿适配器声明的同一序列前进。分类顺序不等于阅读顺序；不能跨到其他组的替代阅读序列或关联作品。
- 多语言属于同一本来源漫画，具体发布条目分别保存图片与进度。目录按来源证明的同话关系合并，一话一行，展示话标题、选用语言与阅读状态；点击主行直接阅读，独立箭头展开“语言 · 翻译组”候选，只有一个条目时不显示箭头。目录数量按话计算，不再提供内容语言筛选。
- 同一话优先沿用有效的手动选择；其余按本漫画内容语言偏好（未设置则用翻译目标语言）、英语、源目录顺序中的第一个可读条目选择。同语言多个翻译组也按源顺序选择。语言匹配兼容地区标签并区分文字体系，例如繁中目标匹配 `zh-HK`，简体中文不混为繁体中文。每话独立决策，某话回退英语不会影响下一话优先目标语言。已选条目被源站移除时自动使用本话其余可读候选；整话不可读时保留明确状态，不跳过该话继续到后续章节。未选候选不参与预加载与翻译。
- 明确点选候选后恢复该条目自己的位置，首次阅读从第一页开始。手动选择按话保存在本机，不覆盖其他话的自动规则。修改内容语言偏好或翻译目标语言不替换当前条目或移动当前页，后续尚未手动指定的话应用新规则。目录可恢复“跟随翻译目标”。通过[跨语言搜索](COMIC_SEARCH_DESIGN.md)导入沿用普通阅读流程，不把名称翻译语言保存为正文偏好；已有漫画的偏好及进度保留。
- 目录支持展开、搜索、升降序查看和跳转。长目录按每批 200 话显示，滚动接近底部时自动追加下一批。搜索覆盖各语言标题与翻译组，结果按话合并并显示匹配候选。升降序只是显示偏好，不写回来源顺序。
- 打开目录、切换章节、切换排序或清除搜索时，自动显示当前章节、展开其来源分组并定位到列表中部；超过首批条目也能直接定位。只滚动目录，不改变正文位置或焦点，状态刷新保留用户手动浏览目录的位置。页面缩略图同样保持当前页可见。

新增适配器随插件发布，由静态通配约定收集。目录不接收可执行脚本、站点 HTML 或动态编辑 schema。已匹配站点失败时不回退为任意网页抓图。

### 网站更新与自动同步

- 持久记录上次检查与成功同步时间，每 12 小时检查书架中所有已到期且声明支持目录更新的漫画；再次打开插件不提前发起网站请求。支持范围以各适配器的 `catalogSync` 声明为准。
- 自动同步完整目录的新增、标题、分类和顺序。新增可阅读条目时，仅在卡片右上角显示伸出封面的 SVG NEW 徽章；首次完整目录作为基线，改名、重排和关联作品变化不误报新增。
- 进入阅读并成功显示当前漫画图片后清除该次提示。查看目录、加载失败和后台预加载其他漫画不会清除；之后到达的新更新独立保留。
- 同步只处理目录，不下载新章节图片。保留已有页身份、译图、缓存和阅读位置；源站移除的条目退出自动选择，目录保留当前条目或整话失效时的明确状态，已有内容和当前位置仍保留。
- 浏览器后台通过 alarm 唤醒并逐个检查，持久记录检查时间与执行租约；关闭阅读器不终止任务。浏览器关闭期间不运行，重新启动后补查已到期项目。失败／不完整目录保留上次结果，下次检查仍需满足 12 小时间隔，重新打开不提前请求；完整目录没有手动强制更新入口，首次目录尚未完成时可手动继续加载。

目录同步由公共应用层调度，站点只提供读取能力；验证使用 `scripts/verify_catalog_sync.mjs` 和各站点脚本。

## 阅读与恢复

图片漫画默认原图。桌面阅读器首次使用铺满宽度、50% 比例缩放，不依赖图片长宽比例或等待图片尺寸；手机紧凑布局保持适应窗口、100%，首次取得真实图片尺寸且高度至少为宽度三倍时，按条漫使用铺满宽度、100%。查看方式、图片适应方式与比例缩放在本机按漫画保存，同一本漫画各章节共用，漫画之间互不影响。初始设置只用于尚无保存设置的漫画，手动选择、重新打开或切换章节不再自动覆盖。单页与连续模式的缩放范围为 40%–200%，每次调整 10%；重新打开、刷新或跳转章节恢复该漫画的比例，切换原图／译图保留比例。旧记录缺少适应方式或缩放时使用适应窗口、100%，无效字段独立回退，存储失败仍可在当前阅读器调整。EPUB 的文字排版与字号不受图片默认比例影响。保留阅读布局、方向、跳页、全屏、原图对照、语言与翻译。

用户设置中的阅读布局和方向是全局默认。阅读器内选择布局或方向只保存本漫画的覆盖值，复用查看方式、适应方式与缩放的同一条本机记录，同一本漫画跨章节、重新打开和刷新沿用，其他漫画不受影响。布局与方向独立继承：字段缺失或无效时使用当前全局默认，打开漫画、保存其他查看设置不会固化继承值；显式选择即使与当前全局默认相同，也视为本漫画覆盖。布局选择“默认”只清除布局覆盖，保留该漫画的方向、原译选择和缩放。修改全局默认不会批量改写漫画记录，未覆盖的漫画跟随新默认，已覆盖的漫画保持选择。EPUB 复用这些设置；有效布局为双页时仅以单页展示，不将回退值写回漫画记录或全局默认。

图片阅读提供连续、单页与双页布局。单页保留工具栏页码和跳转，正文底部不再为页数或末尾提示占位。布局与方向独立：无论修改全局默认、选择本漫画布局或用快捷键切换，均不顺带更改方向；未设置本漫画方向时继续继承全局默认，已有方向覆盖原样保留。双页将封面单独显示，后续相邻竖页两张一组，横向跨页图与最后落单页单独显示；从右向左与从左向右均沿用当前选择。上一页／下一页和翻页快捷键按整组移动，左右箭头跟随阅读方向。直接跳页仍保存实际选择的页身份，例如跳到第 3 页显示第 2、3 页，但页码和恢复位置仍是第 3 页。

图片画布和翻页动画快照不预留装饰性内边距，适屏计算使用实际阅读视口的全部宽高；连续模式铺满宽度时贴合两侧，单页与双页等比适屏时至少填满一个方向。图片与窗口长宽比不同形成的留白、原译对照之间的间隔、章节分隔、非沉浸工具占位与设备安全区仍按各自规则保留。

双页将完整一组等比适应可用窗口，窄屏和短窗口也不需要为看全图片而横向或纵向滚动；原译图并排对照同样按整组总宽度适配。整组适屏为临时缩放的 100% 下限，可用滚轮以指针位置为中心放大至 400%，或使用缩放控件／快捷键；放大后用鼠标主键或单指拖动查看局部，边界限制在图片范围。放大期间不触发滑动和分区点击翻页，缩回 100% 恢复；工具栏／快捷键翻页与直接跳页复位临时缩放。临时缩放和平移不改变页面布局尺寸、不增加图片读取或解码窗口、不写入阅读位置，也不修改单页／连续的比例与适应方式。切换布局、方向、对照、页组、章节或窗口尺寸时恢复适屏；原图／译图及增强替换保持当前局部视野。重新打开仍恢复页身份并整组适屏。

单页与双页支持鼠标主键拖动、手机单指横滑，以及按钮／快捷键的横向轮播式翻页。当前页／组跟随拖动，最大移动窗口宽度的 40%，避免尚未准备邻页时整屏被拖空。达到距离或快速滑动阈值后立即导航，新页面身份提交后让旧页和新页同步滑动 240ms，不把拖动后的旧图突然放回中心。翻页不等待图片、译图或对照图就绪，也不显示翻页准备浮层；未就绪或失败的图片沿用页内加载／重试状态，后台继续读取，不锁住后续导航。短拖与无前后页的边界拖动回弹，不首尾循环。从左向右阅读时左滑向后翻，从右向左阅读时右滑向后翻。页面身份提交后，新的按钮、快捷键、边缘点击或横滑可打断尚未结束的入场动画，立即响应当前操作；等待页面身份提交和正在进行的拖动／回弹期间不排队累积翻页。打断时释放旧快照，不把跳过的入场页面补记为已读；数字跳页、目录定位与恢复直接定位，不沿途播放动画。

图片与 EPUB 阅读进度条拖动时仅在控件内预览目标页码／百分比，松手后提交一次跳转；方向键、Home／End 与 PageUp／PageDown 连按时在松键后提交。直接输入页码仍在完成编辑后跳转。Escape、触摸取消、失焦、页面隐藏或章节变化放弃未提交预览，不改变正文、读取窗口、翻译目标或保存位置。辅助技术直接修改进度值时仍可立即跳转。

单页与双页的左右各 25% 为分区点击翻页区，中间 50% 保留工具栏显隐开关；连续模式仍在正文轻点切换工具。左右点击分别翻向物理左／右页，并按阅读方向映射前后页；可翻页时鼠标显示方向光标和上一页／下一页提示。没有目标页或双页放大时，边缘点击不翻页也不切换工具。手势仅在明显横向移动后锁定，长图保留纵向原生滚动；单页放大、并排对照等造成横向溢出时保留原生横向查看，不用边缘拖动强制翻页。按钮、链接、输入框和文本选择不触发翻页，拖动结束不会误触工具栏显隐。双指、浏览器缩放、取消、失焦、隐藏、窗口尺寸或查看方式改变会中止手势和动画；离开阅读器后不得执行迟到翻页。遵守系统“减少动态效果”设置，跳过过场动画但保留手势导航。

翻页同步保留上一组的纯视觉快照及其图片 URL 引用，不等待快照重新解码，不重新读取源图，不复制 Blob，不挂载另一套阅读状态。快照不可交互、不参与无障碍阅读、几何锚点、翻译目标或已读证据，完成／取消即移除并释放引用。静止时仍只有当前显示窗口；过渡时最多额外保留上一组，可见图片单页最多两张、双页最多四张、双页对照最多八张，不含替换候选的短暂解码，实际解码内存取决于图片尺寸及浏览器缓存。完全入场后才补记动画期间加载成功的当前页和检查已读，尚未加载成功的页面仍须等实际显示后记录；取消则立即显示已导航到的页面，直接跳页不会给被丢弃的页补记已读。

图片型单文件使用页面缩略图，EPUB 使用原书目录和文档位置；网站可展示来源目录和当前页面。目录没有重排、删除、修改名称或版本操作。原图加载不设固定单页字节、像素或边长上限，只校验有效图片，由浏览器实际解码；不因翻译缩小阅读原图。连续阅读提前加载和预解码现有最多 11 页虚拟窗口，不按累计原图像素拒绝窗口内图片。远离窗口时取消读取并释放图片 URL；单页静止时仅显示和解码当前页，双页最多两页（对照最多四张图片），不一次加载全部图片。三种布局共用下节的屏外字节预读取。开启翻译时，双页中的两页都进入当前翻译目标；一页失败不阻塞另一页或翻页。

连续阅读的章节高度前缀和最大宽度按当前三章元数据与显示尺寸计算；滚动跨页和局部图片加载状态更新复用这些几何数据，章节描述或显示尺寸变化时重算。翻译目标和可见页直接从相应范围取得，避免每次状态刷新扫描整章。只缓存当前章节窗口的尺寸数据，不复制图片字节或扩大解码窗口。位置恢复比较章节起点与当前页几何变化，而不是把当前页身份改变当作布局变化；明确跳页仍恢复锚点，原生滚动不重放上一帧位置。隐藏的自定义滚动条跳过轨道布局测量，阅读器保留原生滚动。

译图压缩字节内存缓存按每个扩展上下文最多 24 张、512 MiB 保留；网页原图暂存按每个翻译会话相同预算保留，上传后主动释放，超出预算可从来源恢复。译图单张超出预算仍允许临时保留最近一张，不影响读取准入。译图在有效缓存代次匹配时优先复用内存，返回前再次核验删除代次；内存命中只更新内存访问顺序，不额外读取磁盘 Blob 或更新磁盘访问时间，未命中时沿用持久缓存和已有结果读取。以上是保留预算，不是浏览器可用内存承诺；11 张 4000×6000 图片的单份 RGBA 理论约 1007 MiB，并排约翻倍，浏览器可自行淘汰像素。持久缓存预算和像素合成串行规则不变。

连续、单页和双页共用同一图片显示组件。原图独立读取，不等待译图引用登记、远程结果下载或增强缓存查询；新进入的页面也可先显示原图。译图与增强复用现有读取、缓存和租约，实际显示就绪后才原位替换，迟到原图不得覆盖已显示的译图／增强；译图读取或解码失败保留原图，重试只读取已有结果，不重新翻译。已有可直接显示的增强结果时跳过不必要的父图读取。首次显示结果尚未就绪时，当前页原图与目标图可以并行准备，单个图片组件最多准备原图、当前目标及已取得的增强 Blob 三项；这是避免空白等待的有限开销，不扩大显示／处理窗口或添加请求池。替换、离页与取消时释放不再需要的请求及 URL。

图片优先使用 `decode()` 预解码；遇到 `EncodingError` 时，复用同一 URL 按原生 `load/error` 与有效尺寸确认加载，不把浏览器预解码缓存不足直接判为图片损坏。候选图片通过实际显示元素的加载检查后才替换旧图和显示身份，随后释放旧 URL；失败仍保留可读旧图并逐页提示，取消或过期回调不得更新显示状态。回退不缩小原图、不自动重新翻译，也不承诺突破浏览器实际内存能力。

图片阅读进度保存漫画、条目、当前内容身份、页锚点与页内偏移。正常滚动防抖保存；切到后台、刷新离开页面或卸载阅读器前，立即提交尚未保存的最后一次滚动锚点，不重新测量已卸载的页面，不把初始化恢复位置写成零，也不重复提交已保存的位置。只有清单完整、全部页成功显示且读到末尾才记录已读；部分清单和加载失败不会误记读完。

来源内容变化后先准备有效索引，再替换当前内容身份。网站发现变化会提示重新载入；用户明确载入后回到当前内容第一页并说明。云盘重新选择同一文件且快照发生变化也只替换当前内容，不保留历史版本。不能把旧页码、旧任务或旧译图套用到新字节上。

图片加载失败时，在该页错误处直接提供重试图片和重新载入所属章节；未获得图片引用时只提供章节重载。章节发现失败在阅读界面直接显示原因和重载入口，源站内容同时提供“返回来源网页”，不要求进入阅读设置。重载期间禁用重复操作；单图重试保持位置，章节重新载入沿用上述内容重建规则，失败不清除已有页面和位置。

### 共用图片预读取

连续、单页和双页共用 `ReaderImagePrefetch`、读取优先级、取消和租约交接，只由 `nextImagePages` 按布局选择范围。显示解码与字节预读分离；预读不创建 Image、Blob URL 或隐藏阅读页，不增加设置，不改变 EPUB、翻译／增强窗口或整本离线缓存。

| 布局 | 显示／解码窗口 | 窗口外字节预读 |
| --- | --- | --- |
| 连续 | 现有最多 11 页 | 最后一个已挂载章节窗口之后最多 2 页，可延续至已准备的下一话开头 |
| 单页 | 当前 1 页 | 下一页，章尾为下一话首页，最多 1 页 |
| 双页 | 当前整组，最多 2 页 | 下一整组，章尾为下一话独立封面，最多 2 页 |

- 双页复用 `pageSpreads`／`spreadAt`，封面、横图与落单页单独成组；跳到组内第二页仍从组末尾预读，尺寸更新后重新计算。RTL 只影响摆放和操作方向，不反转来源顺序。
- 单页／双页在当前完整清单的最后 3 页开始准备下一话目录，复用 `ChapterResourceWindow` 与原有章节发现入口；连续阅读沿用现有前／当前／后三话元数据窗口。只准备已经选定阅读序列的直接下一项，不遍历全书、不跳过不可读话、不猜测不完整清单、不递归准备下一话之后的章节。
- 下一话页面描述准备好后，其开头接入同一字节队列；单页／双页不会因此挂载下一话 DOM、扩大翻译／增强窗口或改变位置。连续阅读可用下一话首页补足跨章的两页预算；双页不将两话拼成一组，下一话封面仍独立显示。回翻复用已有缓存，不新增前后双向常驻窗口。
- 目录任务离开资源窗口、隐藏或关闭时取消；迟到结果不得更新当前阅读状态。后台失败不弹窗打断当前话，进入该话时可转为前台重试并沿用错误提示与缓存阅读；正在准备的话成为当前话时接管同一任务，不重复发现。
- 当前窗口各页已取得自己的原图租约、原图读取明确失败或已有实际显示的可读图片，且翻页结束、窗口稳定 150ms 后启动；不等待译图／增强下载、解码或实际显示。对照原图按自己的读取状态判断，不借用译图失败冒充原图已接管。每个阅读器串行预读最多一个在途任务；同一窗口不因渲染重复计时，失败静默且只尝试一次，不影响前台正常读取和重试。
- 统一使用 `acquireImage` → `acquirePage`，不直接访问站点。预读优先级为 `prefetch`，前台为 `current`，来源服务总并发仍为 2。前台加入相同页时复用任务，并提升尚未启动的队列项，不抢占已经运行的来源工作。
- 预读页进入显示窗口后，保留其租约直到前台取得原图租约、原图读取失败或已有可读结果显示，再释放预读引用；不能在挂载时凭译图引用存在就提前释放。前台获取仍执行页面身份与来源访问校验；内存命中不绕过撤权。原位导入的 `inline-original:` 已有本地字节，前台可再次读本地缓存，但不会重复请求源站。
- 每个阅读器额外保留的预读 Blob 合计最多 64 MiB、最多两页，读取后发现超预算则释放并停止剩余窗口预读；不限制当前页或缩小原图。预算不是网络传输、来源规范化、当前解码图片或动画快照的峰值上限；来源物化仍可能解码。相较连续阅读原有窗口，只增加最多两页的低优先级字节准备；收益是将来源等待提前，开销是有限的网络／解析工作与压缩字节保留，不额外常驻下一组像素。
- 原图预读不触发翻译、增强、收费任务、结果下载或合成，不扩大已有 4–5 页处理目标。译图继续使用现有缓存和读取规则，不能把原图预读命中说成译图也已准备好。
- 范围使用完整页面引用，包含条目、内容、页与渲染版本，并逐页记录内容／授权代次。正常跨话保持同一阅读会话，下一话首图的预读引用保留到前台接管；同一引用的身份变化则单独失效，不能复用旧授权。阅读上下文变化、离开窗口、隐藏或关闭时取消并释放不用的引用。取消只影响自身消费者，迟到回调不能恢复资源或更新阅读状态。
- 预读不改变页码、滚动锚点、已显示记录、阅读统计、书架更新提示或已读完成。字节就绪不等于显示就绪，最终仍由 `ReaderPicture` 的实际显示元素确认。

单元测试覆盖三布局范围、跨话租约交接、目录取消与失败重试、队列提权与共享、访问复验、预算和生命周期；隔离浏览器夹具覆盖下一话初始未发现时的准备、读取与状态隔离，以及慢加载期间旧图保留、同步过渡、手势、对照、窗口边界和 URL 回收。夹具缓存读不是源站网络测量；真实来源延迟、浏览器峰值内存和手机真机效果需独立验收，运行入口见[脚本说明](../scripts/README.md)。

## 数据、缓存与下载

模型、数据库、缓存引用、来源撤权和迟到写入保护统一见[来源与缓存架构](COMIC_SOURCE_ARCHITECTURE.md)。清普通缓存不删除完整源文件或主动下载，移除漫画不删除源站／云盘文件或服务端其他有效结果。

漫画卡片菜单提供[整本离线缓存](OFFLINE_CACHE_DESIGN.md)与[当前章节／整个章节目录导出](COMIC_EXPORT_DESIGN.md)，离线中心管理缓存任务。导出只使用原图或有效译图，不自动启动翻译，也不跨漫画批量导出。普通缓存命中不等于完整离线。

真实站点、Google OAuth、模型效果与部署分别验收；命令见[脚本入口](../scripts/README.md)。
