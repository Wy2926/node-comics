# 单来源漫画与直接阅读

当前单来源产品契约；存储与权限实现见[来源架构](COMIC_SOURCE_ARCHITECTURE.md)，验证入口见[脚本说明](../scripts/README.md)。

## 产品边界

用户打开漫画即可阅读。一本漫画只绑定一个确定的来源资源；标题、封面、目录与页序来自该资源，插件只记录阅读位置。没有资料编辑、内容编目和版本选择。

- 本地仅支持 CBZ／ZIP、CBR／RAR、PDF、未加密 MOBI。每个文件独立成书。
- 当前云盘驱动为 Google Drive，仅支持 CBZ／ZIP 按需读取；不扩大到其他格式或供应商。
- 本地与云盘均不支持单张图片、多张散图或图片集合导入。漫画容器内的图片仍可解析阅读。
- 网站必须有随插件发布的专用适配器，并明确声明可导入。未适配网页、任意图片地址、右键图片均不能加入书架。
- 通用网页的原位翻译仍可使用；它不创建漫画、不提供图片选择或导入功能。
- 不兼容旧库或旧管理逻辑；无迁移、双写、旧接口别名和数据回退。

## 来源身份与重复导入

| 来源 | 一本漫画的身份 |
| --- | --- |
| 本地文件 | 已保存的完整文件内容摘要与大小；改文件名再导入仍复用原记录 |
| Google Drive | 连接账户与固定 file ID；不为去重下载整包 |
| 网站 | 适配器 ID 与其证明的漫画资源键；无作品目录的专用单页站点按页面资源识别 |

不同文件、不同云盘文件和不同站点分别成卡，即使标题相同也不合并。CDN 图片地址是取图机制，不构成另一来源。网站阅读页只有在适配器能证明所属目录时才与该目录共用一本漫画。关联作品只作为来源链接，不自动导入。

重复打开复用漫画与阅读位置。同一图片的字节和有效翻译结果仍可按摘要复用，但不共享书架归属。

## 导入与书架

“导入漫画”直接打开文件选择器，拖放使用同一自动队列；旁边的“云盘”菜单进入已接入的文件选择器。没有来源选择弹窗、归属表单或导入前确认。

- 单本：完整文件保存并建立索引后直接打开。不会等待全本图片解码或翻译。重复文件直接续读。
- 多本：逐份自动导入、各自成卡，留在书架。紧凑进度可展开查看失败、重试、暂停或停止剩余文件；一个失败不阻塞其他文件。
- 不支持、损坏、DRM 或空间不足会显示明确原因，不生成空漫画。关闭页面后没有复制完成的 File 需要重选；已保存的文件通过导入日志恢复索引。
- 准备期间若用户已经打开其他漫画，完成后不抢占阅读器。
- 云盘选择完成后自动登记引用与索引；单选直接读，多选留在书架。授权仅在需要时出现；不支持的远端格式提示下载后本地导入。

书架保留搜索与最近阅读排序。卡片封面左上角显示来源，左下角显示本机保存的最近阅读时间，未读漫画显示“还没阅读”；不展示页数位置标签，实际阅读位置继续保存。卡片保留标题和开始／继续阅读。更新徽章叠在卡片右上角，可伸出封面边缘。右键与更多菜单提供开始／继续阅读、适用的打开来源、导出与移除漫画；移除卡片目录菜单及对应弹框，目录导航保留在阅读器内。没有编辑与版本计数。返回书架保留搜索、排序和滚动位置。

“批量管理”支持勾选、全选当前搜索结果、取消选择与批量移除。选择覆盖尚未渲染的卡片，搜索或排序不丢失已有选择；确认框显示所选数量与漫画名称。逐本移除沿用单本的记录与引用释放，单项失败不阻塞其他项，失败项可重试。书架顶部不再显示下载管理区块。设置中的本机资料、独立缓存与云盘账户使用同一宽度和卡片样式，不提供“管理漫画”“管理下载”快捷按钮。

界面兼容与验收以桌面浏览器为目标，窄屏不属于项目兼容范围。

## 网站与只读目录

已适配阅读页点击“开始阅读”后加入书架并打开当前内容，完整目录稍后读取，不阻塞当前图片。作品目录首次使用适配器声明的默认入口；没有可靠默认入口时在页面内显示只读目录供读者选择，不使用弹框，不要求确认导入或预先勾选全部内容。

核心只理解稳定条目、顺序和导航，网站的分类可以是不确定的标签或有界树形分组：

- `SourceEntry` 提供稳定 ID、URL、标题、顺序、原始标签与可选 `sequenceId`。
- `SourceGroup` 提供 ID、标题、`entryIds` 和可选 `parentId`。同一条目可以在多组出现，但只保存一份进度。
- `SourceCatalogSnapshot` 可提供 `defaultEntryId`；缺失不通过标题猜默认入口。
- 自定义分类原样只读显示，不映射为核心的 chapter／volume／main／extra 类型。条目、组引用、URL、深度和数量在公共层校验。
- MangaCopy 仅按源站 `default` 分组标识确定默认入口；其余分组 ID、名称和原始标签从页面动态读取。“同人漫画”“其他系列”等属于当前漫画 URL 的条目仍可阅读，不按分类名称判定为关联作品。站点解析与样本见[MangaCopy 说明](../apps/extension/src/sources/sites/mangacopy/README.md)。
- 连续阅读只沿适配器声明的同一序列前进。分类顺序不等于阅读顺序；不能跨到其他组的替代阅读序列或关联作品。
- 目录支持展开、搜索、升降序查看和跳转。升降序只是显示偏好，不写回来源顺序。

新增适配器需随插件发布并注册。目录不接收可执行脚本、站点 HTML 或动态编辑 schema。已匹配站点失败时不回退为任意网页抓图。

### 网站更新与自动同步

- 持久记录上次检查与成功同步时间，每 12 小时检查书架中所有已到期且声明支持目录更新的漫画；再次打开插件不提前发起网站请求。当前为 MangaCopy／拷贝漫画和 Comix，能力以适配器声明为准。
- 自动同步完整目录的新增、标题、分类和顺序。新增可阅读条目时，仅在卡片右上角显示伸出封面的 SVG NEW 徽章；首次完整目录作为基线，改名、重排和关联作品变化不误报新增。
- 进入阅读并成功显示当前漫画图片后清除该次提示。查看目录、加载失败和后台预加载其他漫画不会清除；之后到达的新更新独立保留。
- 同步只处理目录，不下载新章节图片。保留已有页身份、译图、缓存和阅读位置；源站移除的条目退出普通目录，已有内容和当前位置仍保留。
- 浏览器后台通过 alarm 唤醒并逐个检查，持久记录检查时间与执行租约；关闭阅读器不终止任务。浏览器关闭期间不运行，重新启动后补查已到期项目。失败／不完整目录保留上次结果，下次检查仍需满足 12 小时间隔，重新打开不提前请求；当前没有手动强制更新入口。

目录同步由公共应用层调度，站点只提供读取能力；验证使用 `scripts/verify_catalog_sync.mjs` 和各站点脚本。

## 阅读与恢复

新漫画默认原图；查看方式在本机按漫画保存。保留阅读布局、方向、适宽／适窗、跳页、全屏、原图对照、语言与常规／AI 翻译。

单文件只有页面缩略图；网站可展示来源目录和当前页面。目录没有重排、删除、修改名称或版本操作。图片加载与解码保持有限窗口，不因简化模型一次加载全部图片。

进度保存漫画、条目、当前内容身份、页锚点与页内偏移。只有清单完整、全部页成功显示且读到末尾才记录已读；部分清单和加载失败不会误记读完。

来源内容变化后先准备有效索引，再替换当前内容身份。网站发现变化会提示重新载入；用户明确载入后回到当前内容第一页并说明。云盘重新选择同一文件且快照发生变化也只替换当前内容，不保留历史版本。不能把旧页码、旧任务或旧译图套用到新字节上。

## 数据、缓存与下载

模型、数据库、缓存引用、来源撤权和迟到写入保护统一见[来源与缓存架构](COMIC_SOURCE_ARCHITECTURE.md)。清普通缓存不删除完整源文件或主动下载，移除漫画不删除源站／云盘文件或共享 R2。

阅读设置可下载当前网站内容的原图、保存当前图片或导出当前内容。导出使用既有原图／有效译图规则，不自动启动翻译；不选择其他来源或版本。下载状态仍区分完整与部分，普通缓存命中不等于完整离线。

## 后续边界

当前没有跨条目批量导出、远程分发适配器或新的云盘供应商。已预留来源只读导航的扩展能力；这些后续能力不能重新引入漫画资料管理或多来源关系。

真实站点与 Google OAuth 的在线验收、翻译模型效果、发布和部署分别记录，不能用本轮隔离夹具结果代替。复验命令见[脚本入口](../scripts/README.md)；真实 Google 授权与站点覆盖范围分别见连接页和各站点 README。
