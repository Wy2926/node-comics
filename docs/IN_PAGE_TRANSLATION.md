# 网页内漫画翻译

已实现扩展右键 **翻译当前页面**、Popup 的 **翻译当前标签页**，以及 Popup／设置共用的 **标签页自动翻译** 开关。用户留在原网站，翻译完成后原位显示译图；原有“在 Node Comics 中阅读 / 翻译”单图导入入口保留。

## 使用与识别

- 在阅读器登录并设置默认模式、目标语言，然后在普通 HTTP / HTTPS 网页右键启动。首次使用时，浏览器申请可选网站权限，以便读取不同域名的图片 CDN。未启动的网页不注入此功能。
- 自动翻译默认关闭；开启并授权后，当前网页和之后激活、刷新或导航的网页会自动启动。隐藏标签页不新增翻译，切换过去后才按阅读窗口处理。关闭开关会停止自动启动的会话并恢复原图；手动启动仍可继续，已提交的服务端任务不取消。网页内手动暂停、原图选择或关闭不会被同页激活事件覆盖。权限撤销后自动关闭该设置，详见 [Popup 与共享视觉令牌](POPUP_AND_THEME.md)。
- 按实际显示的 CSS 尺寸筛选 `<img>` / `<picture>`：宽至少 240 px、高至少 180 px、面积至少 100,000 px²、宽高比不超过 2.8。隐藏图、未加载图片、自然尺寸不足 80 px 的占位图不参加翻译。
- 尺寸规则是候选筛选，不是漫画语义分类；大尺寸照片也可能进入候选。长条漫画不限制高宽比。
- 支持 HTTP / HTTPS 图片、当前页面生成的 Blob 图片和常见栅格 data 图片。懒加载、新增图片、`srcset` 变化及动态换图会重新检查。每次扫描最多识别 1,500 张候选，不主动滚动、翻页或触发网站采集。
- 按阅读窗口处理当前图片和后三张，滚动时合并扫描与请求，隐藏标签页停止新增处理。译图解码限制在当前附近最多五张；离远或隐藏后释放显示资源，返回时优先读取本地译图缓存。

底部小控件提供暂停、恢复原图、设置和关闭。“暂停”停止新增本地处理，保留已显示译图；“恢复原图”恢复原网站画面并停止新增本地处理，“显示译图”继续。已交给服务端的任务仍由服务端执行。失败、登录、升级提示显示在对应图片内，单图失败不阻塞其他图片。

## 与阅读器一致的状态

- 使用同一个账号、服务地址、模式和目标语言；阅读器修改语言、切换账号或退出登录，会同步到已启用的网页，并先清除旧范围的译图。
- 按图片 SHA-256 通过阅读计划接口匹配并绑定已有任务和最新有效结果；无需先把网页图片加入书架，也不另行请求匹配或队列接口。网页产生的任务通过原有账号状态同步进入阅读器，导入相同图片时可以继续复用。
- 复用 `TranslationCoordinator`、`pageTranslation`、`translationState` 和实时优先级规则。新增翻译遵守跨模式、语言和设备合计滚动 60 秒普通最多 10 张／PLUS 100 张；重复请求与直接复用完成结果不计数。插件不查询队列作准入预判，额度不足时在图内显示升级入口。
- 精确提交内容和幂等键保存在扩展 IndexedDB；服务端负责持久任务。service worker 重启后可以用原请求恢复，不把后台常驻作为任务完成条件。失败与已取消任务需要显式重试；结果未知不生成新的重绘请求。
- 失败的重新翻译继续保留之前有效的译图；结果下载失败提供重新读取入口。
- 网页与阅读器的图内错误统一显示短提示，例如“连接失败 · 重试”；完整原因放在悬停提示中。点击后立即显示“重试中…”，阅读器重试会刷新服务配置并跳过网络退避；已完成译图的加载失败只重新下载。

## 译图缓存与逐页加载

- 网页翻译和内置阅读器共用 [`library/result-cache.ts`](../apps/extension/src/library/result-cache.ts)。缓存键包含服务 origin、账号、任务／结果 ID 和输出资产 ID，保存到现有 IndexedDB `blobs`，不保存签名下载地址。有效性由调用方的任务状态和账号范围约束；已知撤销或过期结果不能通过缓存加载。
- 同一运行上下文合并在途下载，不同扩展标签页／service worker 通过 Web Locks 协调并在锁内重查缓存。缓存命中不请求 `/v1/images/{id}/access` 或 R2；未命中才获取授权并下载。模式、语言和结果版本通过服务端结果身份区分，不按原图 URL 复用译图。
- `NC_INLINE_TICK/WAIT/LEASE` 只返回状态与结果标识；内容脚本按当前页优先，以两个并发执行单图 `NC_INLINE_IMAGE` 请求。每张完成后独立解码显示，不等待其他下载或原图上传，也不再把四张译图合成一个 Base64 响应。下载或解码失败的重试只走单图读取入口，不进入手动重译；翻译任务失败仍使用原有显式重试流程。
- Blob URL 和解码图片只是显示资源。恢复原图、滚出窗口、隐藏标签页、关闭或刷新网页会释放显示引用，IndexedDB 译图仍可复用。新结果、账号／语言切换、页面换图和过时异步响应会重新校验身份，不能覆盖当前图片。
- 网页下载的新译图遵守现有本地缓存预算，更新访问顺序；缓存清理复用“清理译图”。预算清理保护离线副本和待上传原图。缓存被清理、浏览器回收存储或新结果未缓存时仍需要下载；本地缓存不改变服务端翻译幂等、额度或 R2 的长期保留规则。

本次同时移除旧消息的 `known` 字段、状态响应中的译图 `data` 字段、整批图片字节累计限制和阅读器独立的下载 Map。状态应用改为同步处理，已完成页面不再计算随后被丢弃的翻译状态；验收脚本移除未使用变量与旧翻译记录列表接口夹具。共享缓存、图片／canvas 显示实现、上传恢复和独立验收脚本仍有实际调用，不删除这些文件。

## 页面与数据边界

译图先下载并解码，再以 CSS `content` 替换原图片的显示。原来的 `src`、`srcset`、`picture` 来源、链接、事件和 DOM 归属保持不变。原图自然尺寸用于约束替换后的比例，保持响应式布局；恢复只撤销扩展仍持有的属性，不覆盖网站后续修改。

控件使用隔离 Shadow DOM，浮层主体不拦截网页点击。离开页面、同文档导航或关闭功能会撤销旧显示；自动开关开启时，新页面按新范围启动，否则需要手动启动。网站换图后立即撤销旧结果，再按新内容匹配。

账号凭据仅保存在可信扩展上下文。网页内容脚本无权读取登录存储，后台消息限定到用户启用的标签页、文档 ID 和导航实例，阅读窗口最多四张图片；单图读取另外校验已绑定的页面和精确结果标识，不接受任意资产 ID。源图请求不携带源站 Cookie；临时原图为上传恢复保留，确认不再待上传后移除。单图响应的原始图片字节限制为 40 MB。

这是通用网页图片入口，支持站点适配器明确提供的 canvas 漫画（如 Comic PASH）；浏览器内部页、扩展商店、跨域 iframe、通用 canvas 和 CSS 背景图不属于通用识别范围。需要源站 Cookie 或特殊防盗链才能重新取到的 HTTP 图片可能获取失败；显示操作失败时保留原图和可重试原因。

Chrome 权限与存储行为依据：[activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[跨域网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[扩展存储访问级别](https://developer.chrome.com/docs/extensions/reference/api/storage)。

## 验证

从 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。

仓库根目录的 `scripts/verify_inline_translation.mjs` 使用本机 Playwright / Chromium、独立临时扩展配置和模拟 API，生成无隐私的示例图片与截图。需要设置 `PLAYWRIGHT_MODULE` 为已安装的 Playwright 模块路径；若默认 Chromium 不可用，设置 `CHROMIUM_PATH` 为 Chromium 可执行文件。运行：

```powershell
node scripts/verify_inline_translation.mjs
```

产物写入已忽略的 `artifacts/inline-validation/<run-id>/`。验收在真实 MV3 扩展内执行实际注册的菜单回调；临时配置预授予可选权限，因此不覆盖操作系统原生右键菜单和首次权限弹窗。模拟 API 验证请求、SHA-256 上传、状态和 UI，不代表真实图片模型效果或公开部署验收。

阅读器重试验收复用上述 Playwright / Chromium 环境变量。先运行 `npm --prefix apps/extension run dev -- --port 5176`，再在仓库根目录运行 `node scripts/verify_reader_retry.mjs`。脚本使用隔离账号和模拟 API，覆盖即时反馈、重复点击保护、原位恢复、仅重试下载、首次断网与网络恢复，截图和结果写入 `artifacts/reader-retry-validation/`。
