# 网页内漫画翻译

提供扩展右键 **翻译当前页面**、Popup 的 **翻译当前标签页**，以及 Popup／设置共用的 **标签页自动翻译** 开关。图片右键的 **翻译图片** 只翻译所选原图；右键和 Popup 的 **划图翻译** 可手动截取当前可见范围内的一部分画面。翻译标签页和开始划图均可通过浏览器原生快捷键直接启动，无需打开 Popup；暂停、切换原译图和关闭使用页面内组合键。统一入口与配置规则见[快捷键](POPUP_AND_THEME.md#快捷键)。用户留在原网站查看结果；这些入口均不创建漫画，只有专用网站适配器可提供导入阅读。

## 使用与识别

- 在阅读器选择[翻译渠道](TRANSLATION_CHANNELS.md)与目标语言，然后在普通 HTTP / HTTPS 网页右键启动常规翻译。官方渠道需要登录，MTU 使用渠道设置中连接的服务。网站访问在安装配置中统一声明，遵循[公共权限规则](SITE_ADAPTERS.md#必须保持的约束)，使用时不再申请；读取图片 CDN 时仍检查浏览器当前访问权限。未启动的网页仅有轻量快捷键入口，不注入识图与翻译模块、不扫描图片。
- 自动翻译默认关闭；开启且具备网站访问权限时，当前网页和之后激活、刷新或导航的网页会自动启动。隐藏标签页不新增翻译，切换过去后才按阅读窗口处理。关闭开关会停止自动启动的会话并恢复原图；手动启动仍可继续，已提交的服务端任务不取消。网页内手动暂停、原图选择或关闭不会被同页激活事件覆盖。权限撤销后自动关闭该设置，详见 [Popup 与共享视觉令牌](POPUP_AND_THEME.md)。
- 未适配网站按实际显示的 CSS 尺寸筛选 `<img>` / `<picture>` / `<canvas>`：宽至少 240 px、高至少 180 px、面积至少 100,000 px²、宽高比不超过 2.8。隐藏图、未加载图片、原生尺寸不足 80 px 的占位图不参加通用筛选。
- 通用 canvas 仅处理当前视口内最多四张可读画布，按原生尺寸读取 PNG；透明、纯色等待画布及跨域污染画布不送译。开启网页翻译后，在前台每 500 ms 对这些画布采样 32×32 缩略像素，稳定至少 250 ms 后才识别；重绘后撤销旧译图并匹配新输入，不需要网站改变 DOM。采样适用于静态漫画页，不保证捕获所有细小像素变化。隐藏页面停止采样，关闭会话清理观察器；未开启翻译的页面不采样。通用漫画导入仍只发现 HTTP(S) 图片。
- [ComicWalker](../apps/extension/src/sources/sites/comicwalker/README.md) 使用专用正文页序与章节绑定，在当前页附近识别源站已画好的屏外 canvas，复用同一稳定像素检测和公共阅读窗口，实现下一页预翻；不主动翻页，不把等待画布或整章送译。通用 canvas 的视口限制保持不变。
- MangaCopy、Comix、DM5、NAVER、Comic PASH 按各自正文容器识别图片或画布；Sunday Webry、Comic DAYS 显式复用 GigaViewer 引擎，按正文元数据绑定已加载页槽，受污染的 `baku` 展示画布经公共 HTTP 原图读取和还原后送译。正文短切片也可翻译；共同检查加载状态和可见性。目录、广告、推荐图、未知引擎格式和站点等待状态不回退到通用大图扫描。引擎边界见[网站适配](SITE_ADAPTERS.md#必须保持的约束)。
- 通用尺寸规则是候选筛选，不是漫画语义分类；大尺寸照片也可能进入候选。长条漫画不限制高宽比。
- 支持 HTTP / HTTPS 图片、当前页面生成的 Blob 图片和常见栅格 data 图片。懒加载、新增图片、`srcset` 变化及动态换图会重新检查。每次扫描最多识别 1,500 张候选，不主动滚动、翻页或触发网站采集。
- 当前可见图片按屏幕位置及阅读方向排序，不要求 DOM 相邻；双页、网格及一页多切片全部进入可见集合。屏外只在[统一阅读窗口](READING_TRANSLATION_CONTRACT.md#7-阅读触发与优先级)的四／五张名额有余量时按位置预取，不因切片完成而继续向整章扩张。可见集合与执行批次分离：每批最多五张，完成、无文字或失败项让出名额，继续处理剩余可见图片；单图失败不阻塞其他图片，失败重译仍需显式操作。滚动时合并扫描与请求，隐藏标签页停止新增处理。
- 同屏可见译图全部保留，附近屏外图片只使用十一张显示窗口的剩余名额；可见切片超过十一张时仅为仍可见的部分扩展显示数量，不扩大执行批次或传输并发。DOM 重排不改变显示归属；离远或隐藏后释放显示资源，返回时优先读取本地译图缓存。
- 新识别的阅读窗口图片立即显示“准备翻译…”，不等待后台初始化、原图读取或任务提交；仅在图片可见时展示。后台响应后由真实状态接管，已完成和无文字结果不因滚动重新显示准备提示；切换翻译配置时重新提示。

底部小控件提供暂停、恢复原图、设置和关闭。“暂停”停止新增本地处理，保留已显示译图；“恢复原图”恢复原网站画面并停止新增本地处理，“显示译图”继续。已交给服务端的任务仍由服务端执行。失败、登录、升级提示显示在对应图片内，单图失败不阻塞其他图片。

## 指定图片翻译

- 在普通 HTTP / HTTPS 标签页中，对顶层页面内已加载的图片右键选择 **翻译图片**，沿用当前渠道、目标语言与常规翻译。支持 HTTP(S)、同页面 Blob 和常见栅格 data 图片；发送原图，不截取屏幕，也不受整页通用识图的大图尺寸筛选限制。跨域 iframe、CSS 背景图、canvas 及浏览器禁止注入的页面不属于此入口。
- 只绑定右键选中的具体图片；同 URL 的其他元素、邻图和滚动后出现的图片均不送译。再次选择另一张图片会替换当前选择；开启整页翻译或划图翻译会切换到对应范围。已提交的服务端任务仍继续执行。
- 原位显示、原图切换、失败重试和缓存复用沿用整图流程，保持图片属性与页面位置。图片换源、原生尺寸变化或元素移除时撤销旧显示，不自动翻译新内容；需要重新右键选择。后台重启后仍核验保存的单图绑定，不扩大处理范围。
- 未启动翻译时，常驻入口只记录用户真实右键事件中的图片引用，不扫描图片、不读取像素或提交任务。加载／更新扩展前已打开的网页需刷新以启用这个入口。

## 划图翻译

- 仅用户手动启动，不受自动整页翻译开关触发。普通 HTTP / HTTPS 标签页中拖动矩形选区，松开左键后自动截图并提交翻译，不弹确认或截图预览；尚未松手时按右键或 Esc 取消，不截图、不上传。原图预览按用户打开时读取，不阻塞自动提交。处理时选区显示不拦截网页操作的动态边框，完成后只在原选区显示译图。一次只保留当前标签页的一块选区，不自动滚动、拼接长截图、识别全部图片或扩展到选区外。浏览器内部页、扩展商店及禁止注入的页面不能使用。
- 捕获的是当前可见像素，不是源图片的原生分辨率；区域里的文字、背景和其他可见内容都属于截图。浏览器获得的可见视口截图只作为受信扩展上下文中的短暂中间数据，按真实截图与视口尺寸比例向内取整裁剪，只保存并发送选区像素。页面滚动、缩放、导航或活动标签页在捕获期间变化时拒绝旧截图。移动端式双指缩放的视口偏移尚不支持，需恢复正常视口后框选。
- 复用当前翻译渠道、目标语言和常规翻译流水线，不新增后端裁剪协议。官方渠道每个裁片是一张独立图片，沿用本人结果复用、分钟／小时准入及成功页结算；不按面积减免或把选区自动拆成多个任务。MTU 使用已配置的服务与其上传限制，不消费官方额度。页面 URL、裁剪坐标和定位信息不上传到翻译服务。
- 能可靠定位到同一静态图片时，在隔离的覆盖层内将译图贴回选区，随该图片滚动或同尺寸的位置变化；不替换完整原图，不改写 `src`、`srcset` 或原图片 DOM。图片及非根祖先的恒等变换不影响定位；实际旋转、缩放、动画及根元素变换不强行覆盖。无关页面更新不使图片选区失效；滚出视口或被遮挡时暂时隐藏，重新可见后恢复。图片换源、显示尺寸或影响像素的样式改变会停止原位覆盖并保留预览，不能把旧译图贴到新的内容上。一般静态画面仅在原视口与页面布局仍一致时覆盖；跨域 iframe、canvas、视频及无法可靠跟踪的动态区域仅显示独立预览。
- 结果显示为选区大小，范围外保持原样；“恢复原图”、隐藏或关闭预览不等于取消服务端任务。失效选区的预览被手动关闭后，后续滚动或无关页面更新不重新打开它。重新框选、明确关闭、导航／刷新和切换整页翻译会清理当前选区输入及显示；切入划图时，旧整页翻译尚在鉴权、排队或准备中的请求失效，已提交的后端任务仍继续。新文档不能自动把上一文档的选区结果重新覆盖回来。
- service worker 重启后，同一文档按本地保存的选区、输入字节和原 UUID 核实任务；未知结果不自动重新提交新 UUID，不通过重新截图补传旧请求。选区输入必须在提交前成功持久保存，写入失败停在本地。截图输入和完整译图缓存的保留边界见[文件存储](OBJECT_STORAGE.md#划图翻译临时选区)。

## 与阅读器一致的状态

- 整图翻译使用与阅读器相同的渠道、模式和目标语言；划图入口固定常规翻译。切换渠道或语言会清除旧范围的显示。仅官方渠道响应官方账号变化，MTU 不受 NodeLane 登录状态影响。
- 按图片 SHA-256，通过逐图翻译 UUID 契约匹配已有任务与有效结果；无需先把网页图片加入书架，也不另行请求匹配或队列接口。导入相同图片时按当前账户和有效结果继续复用。
- 公共层仅调用 `ChannelRuntime` 与 `pageTranslation`；官方协调器及权益规则封装在官方适配器。官方新增翻译遵守服务端返回的分钟与小时限额，额度不足时显示升级入口；插件不查询队列作准入预判。MTU 不消费官方额度。
- 官方保存精确提交内容和幂等键，依靠服务端持久任务恢复。MTU 由非激活扩展标签页承载长请求，service worker 重启仅查询本地回执；宿主中断不能自动重放 HTTP。失败需要显式重试，结果未知不能自动生成新请求。
- 失败的重新翻译继续保留之前有效的译图；结果下载失败提供重新读取入口。
- 网页与阅读器的图内错误统一显示短提示，例如“连接失败 · 重试”；完整原因放在悬停提示中。点击后立即显示“重试中…”，阅读器重试会刷新服务配置并跳过网络退避；已完成译图的加载失败只重新下载。

## 译图缓存与逐页加载

- 网页翻译和内置阅读器共用 [`storage/translations/results.ts`](../apps/extension/src/storage/translations/results.ts)。缓存键包含渠道作用域及任务／结果标识，持久缓存保存完整译图，命中后直接读取；具体规则见[翻译契约](READING_TRANSLATION_CONTRACT.md#4-状态与结果)。官方作用域包含服务与账号，MTU 包含配置 ID 与修订。已知撤销或过期结果不能通过缓存加载。
- 同一运行上下文合并在途下载，不同扩展标签页／service worker 通过 Web Locks 协调并在锁内重查缓存。缓存命中不发图片 HTTP；未命中按已有快照的当前 UUID artifact.path 鉴权下载，没有 R2 或签名刷新。模式、语言和结果版本通过服务端结果身份区分，不按原图 URL 复用译图。
- `NC_INLINE_TICK/WAIT` 只返回状态与结果标识；内容脚本按当前页优先，以两个并发通过 `NC_INLINE_RESULT` 端口发送单图 `NC_INLINE_IMAGE` 请求。页面持有的 Blob／canvas 原图反向使用 `NC_INLINE_SOURCE` 端口。两者复用每块 512 KiB、接收后拉取下一块的传输，不构造整图 Base64 或在单条扩展消息中携带完整图片；接收端组装 Blob 后独立解码显示。
- 每个标签页最多两个结果传输，页面最多两个原图传输；每块交付前后重新核验当前图片／结果身份，取消、断开及页面失效释放传输引用。准备限时 120 秒、每块限时 30 秒，准备期间的心跳只保持后台存活，不延长超时。官方下载或解码失败只重新读取；MTU 本地结果缺失会明确提供“重新翻译”，不自动调用服务。
- Blob URL 和解码图片只是显示资源。恢复原图、滚出窗口、隐藏标签页、关闭或刷新网页会释放显示引用，IndexedDB 中的完整译图可直接重新显示。新结果、账号／语言切换、页面换图和过时异步响应会重新校验身份，不能覆盖当前图片。
- 网页下载的新译图遵守本地缓存预算；缓存清理复用“清理译图”，保留源文件和阅读位置。官方缓存缺失可重新下载，MTU 缺失需用户手动重译。本地缓存不改变官方服务端翻译幂等、额度或[文件保留规则](OBJECT_STORAGE.md)。

## 页面与数据边界

官方结果优先读取完整译图缓存；缓存缺失时，覆盖文件经统一 `materializeResult` 核验并以原生尺寸、整数坐标、`source-atop` 合成后缓存，再以 CSS `content` 替换原图片的显示。MTU 完整结果使用相同显示入口。canvas 使用不拦截点击的相邻译图覆盖层，跟随原画布位置、尺寸与变换，不修改网站画布像素；扩展自身的覆盖图不参加通用识别。原来的 `src`、`srcset`、`picture` 来源、链接、事件和 DOM 归属保持不变。原图自然尺寸用于约束替换后的比例，保持响应式布局；恢复只撤销扩展仍持有的属性，不覆盖网站后续修改。

控件使用隔离 Shadow DOM，浮层主体不拦截网页点击。离开页面、同文档导航或关闭功能会撤销旧显示；自动开关开启时，新页面按新范围启动，否则需要手动启动。网站换图后立即撤销旧结果，再按新内容匹配。

账号凭据仅保存在可信扩展上下文。网页内容脚本无权读取登录存储，后台消息限定到用户启用的标签页、文档 ID 和导航实例，单次整图执行消息最多五张图片，可见集合不按批次上限截断，划图每个标签页仅一块选区；单图读取另外校验已绑定的页面和精确结果标识，不接受任意文件路径或其他 UUID。源站 Cookie 仅由浏览器在授权来源请求中使用，不上传给翻译后端；官方原图同时用于上传恢复与覆盖合成，上传后继续保留于来源页缓存和有限内存；需要合成且原图已淘汰时，只从当前来源恢复并核验送译摘要。完整译图缓存可独立读取；需要合成时原图缺失明确失败，不从服务器恢复永久副本，不重调模型。来源读取、页面采集与单图响应不设固定字节、像素或边长上限；图片必须可由浏览器解码，送译副本在翻译入口按渠道能力检查上传限制。

整图入口支持通用网页图片、可读静态 canvas 漫画和站点适配器明确提供的 canvas 漫画（如 Comic PASH）；浏览器内部页、扩展商店、跨域 iframe 和 CSS 背景图不属于自动识别范围。受浏览器跨域保护或无法导出当前像素的画布无法自动读取。手动划图可以捕获普通网页中这些画面的可见部分，但不能因此保证可靠的原位定位，动态表面按上述预览规则处理。登录失效或特殊来源限制可能导致 HTTP 图片获取失败；显示操作失败时保留原图和可重试原因。

公共读取与请求头规则见[图片读取](IMAGE_ACCESS.md)。Chrome 权限与存储行为依据：[activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[跨域网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[扩展存储访问级别](https://developer.chrome.com/docs/extensions/reference/api/storage)。

## 验证

从 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。

指定图片的浏览器验收设置 `INLINE_SITE_ONLY=image`，覆盖小图、同 URL 精确选择、无邻图预取、原图切换与位置保持、失败单图重试、换源撤销及整页模式恢复；脚本使用真实右键事件后派发已注册的菜单回调，未自动操作系统原生菜单弹层。

划图入口的浏览器验收需覆盖 Popup／右键启动、拖动中右键／Esc 取消、松手自动提交及处理边框、不同 DPR／桌面缩放、只上传选区像素、范围外画面不变、恒等变换图片覆盖、滚动与同尺寸位移跟随、无关页面更新不失效，以及换源／尺寸变化后仅预览。另验证捕获时切换标签页、写盘失败、上传回包丢失、service worker 重启恢复、重新框选／关闭后的旧响应隔离与同账户重复请求不重复结算。模拟 API 与合成图片只能证明交互和协议，不能替代真实网页截图质量、模型效果与实际性能测量。

仓库根目录的 `scripts/verify_inline_translation.mjs` 使用本机 Playwright / Chromium、独立临时扩展配置和模拟 API，默认生成无隐私的示例图片与截图。需要设置 `PLAYWRIGHT_MODULE` 为已安装的 Playwright 模块路径；若默认 Chromium 不可用，设置 `CHROMIUM_PATH` 为 Chromium 可执行文件。运行：

```powershell
node scripts/verify_inline_translation.mjs
```

仅验证通用图片／canvas 可设置 `INLINE_SITE_ONLY=generic`；`INLINE_SITE_ONLY=prefetch` 检查长图页内 1/3、短图提前补位、五页上限和暂停恢复；`INLINE_SITE_ONLY=feedback` 专门延迟模拟后台响应，检查即时准备提示、暂停／原图隐藏、真实状态接管、配置切换、关闭与位置保持；`INLINE_SITE_ONLY=window` 检查双页切片、非连续 DOM、五张批次补位、慢任务和反向翻页。后者可另设 `INLINE_LIVE_URL` 为公开的右向左双页阅读地址，验证左方向键前进、右方向键返回及缓存恢复。`INLINE_SITE_ONLY=comicwalker` 配合 `RUN_LIVE_COMICWALKER=1` 读取 ComicWalker 公开阅读页，核对专用适配的屏外预翻、双页／竖向覆盖、SPA 切章与原图恢复。真实来源模式只将原图发给本机模拟 API，不调用真实翻译模型。合成回归覆盖空白／跨域污染画布、同尺寸重绘、延迟绘制、并排页面、缓存恢复、点击和几何位置，并记录缩略采样次数与耗时。

产物写入已忽略的 `artifacts/inline-validation/<run-id>/`。验收在独立 Chromium 配置的真实 MV3 扩展内执行实际注册的菜单回调，不覆盖操作系统原生右键菜单、浏览器实际安装授权及手动限制网站访问和恢复。模拟 API 验证请求、SHA-256 上传、状态和 UI，不代表真实图片模型效果或公开部署验收。

划图使用同一环境运行 `node scripts/verify_region_translation.mjs`，产物写入 `artifacts/region-validation/`。它读取真实 `captureVisibleTab` 截图并逐像素核对裁片、局部覆盖与原图恢复，检查拖动取消与松手自动提交、原图预览按需读取、选区记录写入次数、后台中断后同 UUID 重试、滚动降级、CSS 换图、切标签竞态及关闭清理。模拟 MTU 服务覆盖零缓存预算、宿主与后台重启后的缓存缺失及显式重译；这段用例在隔离内容脚本中模拟隐藏／恢复，不代表真实标签页可见性验收。无头测试不能触发浏览器原生 action／菜单的 `activeTab` 授权手势，因此仅隔离副本临时增加 `<all_urls>`；正式权限不改变，真实安装授权仍需手动验收。`REGION_DPR` 是浏览器仿真值，报告中的实际截图比例以返回位图为准，不能替代操作系统高 DPI 验收。
