# Node Comics 产品设计

面向公开用户的桌面浏览器漫画阅读与翻译插件。一本漫画绑定一个来源，选择文件或打开已适配网站后直接阅读原图，用户选择译图与目标语言后随读随译。插件保持轻量，翻译计算与任务持久化在后端。

## 界面与阅读

| 入口 | 职责 |
| --- | --- |
| 插件弹窗 | 目标语言、标签页自动翻译、翻译当前网页、已适配漫画开始阅读、打开书架与设置 |
| 我的漫画 | 单来源卡片、最近阅读、搜索、寻找其他语言、直接导入、批量移除；点卡片续读 |
| 远程书库 | 多个独立 OPDS 连接、只读目录／搜索；首次打开加入书架，必要时确认完整下载 |
| 发现 | [AniList 作品资料](DISCOVERY.md)、榜单与筛选、详情；衔接网站搜索查找可读来源 |
| 搜索漫画 | 独立整页按名称搜索或翻译名称后跨站搜索；原漫画入口打开等宽底部面板，结果可独立导入阅读 |
| 漫画网站 | 适配器声明的网站入口、链接导入、匿名适配申请 |
| 阅读器 | 图片与 EPUB 共用工具栏、抽屉、视觉令牌及阅读设置；图片提供缩略图、跳页、缩放与翻译对照，EPUB 提供原文排版、目录、字号、文档位置及内嵌图片翻译 |
| 我的账户 | 登录、会员／额度、订阅、反馈进展；常规翻译额度仅在此展示 |
| 设置 | 外观、语言、阅读偏好、独立缓存与来源连接 |
| 运营后台 | 供应商、节点、权益、支付与反馈管理；插件无运营配置或服务地址输入 |

界面使用二次元漫画风：清晰文字、大封面、描边、纸面、硬阴影，六种强调色与亮暗主题共用[视觉令牌](POPUP_AND_THEME.md)。桌面与手机布局共用业务逻辑；手机交互约束见同一界面规范，浏览器模拟与真机兼容分别验证。

单来源身份、导入、卡片、更新提示与已读判定统一见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md)。不支持散图导入、跨来源合并、资料／归属编辑或版本管理；本地支持未加密 MOBI、CBZ/ZIP、CBR/RAR、PDF、EPUB，Google Drive 支持 CBZ/ZIP、未加密 MOBI，网站须专门适配。

EPUB 按章节直接阅读原文，只翻译包内图片，正文文字不翻译，也不截图送译。OPDS EPUB 在支持可靠 Range 时按需加载，不要求先保存整本，不支持时才明确确认完整下载。正文的脚本、表单和文档自行发起的远程请求禁用，DRM 与字体混淆不支持。图片与文字阅读都复用书架、来源授权和本地位置；来源支持服务端位置时，打开读取其位置，实际阅读后合并提交变化。预取和下载不主动上报进度，服务端进度失败保留本地续读。具体协议与隔离规则见[来源架构](COMIC_SOURCE_ARCHITECTURE.md)。

## 翻译体验

- 新漫画默认原图，查看方式按漫画在本机保存。手动选择译图或明确打开译本后才自动翻译当前图片与后三张；无需登录可看原图。
- 插件只提供原图与常规译图。切换、登录、失败恢复及译图加载保持页锚点与页内位置；逐页完成与失败互不阻塞。
- 常规模式使用检测／OCR、文本 LLM、抹字、嵌字；当前计算实现为 [classic-engine](../services/classic-engine/README.md)，模型与许可见其文档。官方正文模型选择见[模型选择规范](TRANSLATION_MODEL_SELECTION_DESIGN.md)，不能将本地实现写成已部署。
- 失败显示可操作原因。未知结果先核实原 UUID；下载失败重读已有结果。文本调用在统一次数和时限内重试及格式修复，全部子调用计量，成本不作为调用上限。
- 部分完成、无文字、识别失败与完整成功分别表达；不能可靠处理的区域保留原文。译图反馈与重新翻译不引入漫画正文编辑器。
- 客户端不显示翻译队列或批量预存，不查询队列作准入预判。额度不足在图内提供升级入口，分钟限制按服务端回执恢复。计数与结算以[会员规则](MEMBERSHIP_AND_QUOTAS.md)、[翻译接口契约](READING_TRANSLATION_CONTRACT.md)为准。

网页原位翻译使用[专门流程](IN_PAGE_TRANSLATION.md)，支持通用已加载图片；它不把未适配网页变成可导入漫画。

## 账户与数据

官网导航和页脚提供独立图片翻译入口：17 语 `/translate/` 工作台支持选择／拖放／粘贴 JPG、PNG、WebP，每次最多 10 张，预处理后上传，合成完整译图并提供本地历史、逐张下载与已完成结果打包。工作台不提供图片预览、缩放或原译对照，不建立书架条目、不接收漫画容器或远程 URL，不改变插件单来源及不支持散图导入的边界。匿名体验与登录账户额度见[会员额度](MEMBERSHIP_AND_QUOTAS.md#官网匿名体验)。

未登录账户页仅提供登录入口；登录后展示实际权益和订阅管理。订阅与一次性额度包只在官网定价页购买，插件和账户页提供定价入口。套餐、周期与额度以当前公开目录及账单 API 为准，在途订单固定原价格与渠道；支付返回页不发放权益。具体规则见[会员额度](MEMBERSHIP_AND_QUOTAS.md)和[支付契约](STRIPE_BILLING.md)。

身份、翻译资产和操作记录按服务 origin 与账户隔离。供应商密钥留后端，源站 Cookie／登录令牌不上送；只有用户明确翻译的页面上传。服务端原图仅保留到任务终态；翻译结果保存在中心文件卷，撤销最后有效 UUID 引用后回收；完整本地源文件、缓存和主动下载分别管理。

## 范围与验收

整本离线缓存的入口、语言多选、目录范围、进度与失败反馈见[整本离线缓存](OFFLINE_CACHE_DESIGN.md)。整本覆盖来源的所有目录、所有话；多语言可选择缓存语言，默认全选，不跟随阅读器当前序列或阅读语言偏好缩小范围。

运行入口见[插件 README](../apps/extension/README.md)和[脚本说明](../scripts/README.md)。阅读交互需要真实桌面浏览器操作、截图及加载／失败／位置恢复检查；隔离接口和合成图片验证交互，真实模型样本验证翻译效果，两者分别报告。发布状态以实际部署验证为准。

不提供云书架、跨条目批量导出或 OPDS 之外的远程书库协议；文件与云盘支持范围见[导入格式与缓存](IMPORT_FORMATS_AND_CACHE.md)。[跨语言漫画搜索](COMIC_SEARCH_DESIGN.md)通过网站、书架与阅读器共用入口，取得目标语言的名称后按名称逐站搜索；语言只在网站提供时展示，不过滤网站或候选。新来源独立导入，不合并作品。官网语言提示、手动偏好和路由见[官网语言选择](WEBSITE_LANGUAGE_DESIGN.md)。
