# Node Comics 产品设计

面向公开用户的桌面浏览器漫画阅读与翻译插件。一本漫画绑定一个来源，选择文件或打开已适配网站后直接阅读原图，用户选择常规／AI 与目标语言后随读随译。插件保持轻量，翻译计算与任务持久化在后端。

## 界面与阅读

| 入口 | 职责 |
| --- | --- |
| 插件弹窗 | 目标语言、标签页自动翻译、翻译当前网页、已适配漫画开始阅读、打开书架与设置 |
| 我的漫画 | 单来源卡片、最近阅读、搜索、直接导入、批量移除；点卡片续读 |
| 漫画网站 | 适配器声明的网站入口、链接导入、匿名适配申请 |
| 阅读器 | 有限图片窗口、来源只读目录、缩略图、跳页、方向、缩放、全屏、翻译与原图对照 |
| 我的账户 | 登录、会员／额度、订阅、反馈进展；常规翻译额度仅在此展示 |
| 设置 | 外观、语言、阅读偏好、独立缓存与云盘账户 |
| 运营后台 | 供应商、节点、权益、支付与反馈管理；插件无运营配置或服务地址输入 |

界面使用二次元漫画风：清晰文字、大封面、描边、纸面、硬阴影，六种强调色与亮暗主题共用[视觉令牌](POPUP_AND_THEME.md)。插件兼容与交互验收以桌面浏览器为目标，不新增窄屏适配要求。

单来源身份、导入、卡片、更新提示与已读判定统一见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md)。不支持散图导入、跨来源合并、资料／归属编辑或版本管理；本地支持未加密 MOBI、CBZ/ZIP、CBR/RAR、PDF，Google Drive 支持 CBZ/ZIP、未加密 MOBI，网站须专门适配。

## 翻译体验

- 新漫画默认原图，查看方式按漫画在本机保存。手动选择常规／AI 或明确打开译本后才自动翻译当前图片与后三张；无需登录可看原图。
- 原图、常规译图与 AI 译图按模式、目标语言和有效配置分别标识。切换、登录、失败恢复及译图加载保持页锚点与页内位置；逐页完成与失败互不阻塞。
- 常规模式使用检测／OCR、文本 LLM、抹字、嵌字；当前计算实现为 [classic-engine](../services/classic-engine/README.md)。LaMa 已获准使用，实际引擎的模型与许可见其文档，不能将候选方案写成已部署。
- AI 重绘基础输入只有图片与目标语言，无前置 OCR。后端构造提示词，使用兼容 `POST /v1/images/edits` 的配置化供应商。
- 失败显示可操作原因。未知重绘结果先核实原操作；下载失败重读已有结果。文本调用在统一次数和时限内重试及格式修复，全部子调用计量，成本不作为调用上限。
- 部分完成、无文字、识别失败与完整成功分别表达；不能可靠处理的区域保留原文，不自动升级为付费重绘。译图反馈与重新翻译不引入漫画正文编辑器。
- 客户端不显示翻译队列或批量预存，不查询队列作准入预判。额度不足在图内提供升级入口，分钟限制按服务端回执恢复。计数与结算以[会员规则](MEMBERSHIP_AND_QUOTAS.md)、[翻译接口契约](READING_TRANSLATION_CONTRACT.md)为准。

网页原位翻译使用[专门流程](IN_PAGE_TRANSLATION.md)，支持通用已加载图片；它不把未适配网页变成可导入漫画。

## 账户与数据

未登录账户页仅提供登录入口；登录后用“我的账户／订阅”子标签展示账户与 PLUS。月付／年付使用后台唯一默认支付渠道，在途订单固定原价格与渠道。价格、试用和周期额度以[支付契约](STRIPE_BILLING.md)为准；支付返回页不发放权益。

身份、翻译资产和操作记录按服务 origin 与账户隔离。供应商密钥留后端，源站 Cookie／登录令牌不上送；只有用户明确翻译的页面上传。原图及最终译图保存在私有 R2，删除访问记录不删除共享字节；完整本地源文件、缓存和主动下载分别管理。

## 验收与后续范围

运行入口见[插件 README](../apps/extension/README.md)和[脚本说明](../scripts/README.md)。阅读交互需要真实桌面浏览器操作、截图及加载／失败／位置恢复检查；隔离接口和合成图片验证交互，真实模型样本验证翻译效果，两者分别报告。发布状态以实际部署验证为准。

云书架、跨条目批量导出、远程分发适配器、更多云盘和电子书格式仍属后续范围。官网语言偏好方案见[待实现设计](WEBSITE_LANGUAGE_DESIGN.md)。
