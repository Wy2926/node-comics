## 常规模式

2026-09-14 已实现本轮交互改造：支持自动翻译与自动显示译图，明确区分当前画面和任务状态；同一页、同一种模式与目标语言只展示最新效果，读者不再选择历史版本；支持反馈与重新翻译；目录在 2026-09-15 拆为作品目录与本话缩略图；作品详情新增按副本／模式／语言汇总的插件译本入口，复用已有结果并保留阅读位置，详见[阅读目录与插件译本](READER_DIRECTORY_AND_EDITIONS.md)。具体交互和预算规则见[翻译交互细化](READING_TRANSLATION_CONTRACT.md)，版本资产仍按现有保留策略管理。

用户保留模式、目标语言与原图／译图切换。常规模式走 OCR、文本翻译、抹字与嵌字；AI 重绘走图片模型。两类译图独立保存，翻译与切换均保持阅读位置。AI 重绘等待或失败时保留有效常规译图。

LaMa 已获用户同意，常规链路成本分为自部署计算资源和文本 token，见调研文档第 6 节。文本 LLM 允许在次数和金额上限内自动重试、修复格式，无需每次确认；读者同一页只结算一次，图片重绘仍保留严格的未知结果保护。复杂背景不能可靠处理时保留相关原文并说明，不自动转成重绘或宣称完整翻译。抹字、OCR、LLM 和嵌字分别报告阶段失败；真正无字与识别失败分开。首批源语言、复杂页降级体验和是否提供人工文本编辑待样本验证后确定。

以下内容描述流程与验收基线。部分低置信 OCR 区域保留原文，输出明确标为部分完成并释放额度预占；整体 OCR、译文或排版失败时保留整页原图。

## 产品与主流程

产品是带独立阅读器的 Chrome / Edge MV3 插件，面向公开用户，后续考虑收费。插件轻量，翻译任务在后端持久化执行。

网页发现图片／导入本地文件 → 阅读原图 → 选择页面与语言 → 确认预计额度 → 所选模式逐页完成 → 原图对照、查看最新效果、反馈和保存译图。

AI 重绘只要求图片和目标语言，无 OCR 前置步骤。后端生成版本化提示词调用 OpenAI 兼容 `POST /v1/images/edits`；供应商、模型与参数由运营方配置。Key 不进入插件。

## 图片来源与本地导入

MangaCopy作为来源之一，已实现详情页整部可选范围导入、目录归属预览和原图断点采集；来源映射、网页 JS 图片清单及顺序采集见[MangaCopy来源设计](MANGACOPY_LIBRARY_DESIGN.md)。话、卷、番外真实样本均已完整采集；具体权限与来源验收边界见实现记录。

网页发现与字节获取分离。通用适配读取当前 DOM 和懒加载来源，按当前已知顺序建立清单；只有确知完整页数时才标记整章完成。失败保留可操作原因，支持滚动来源后重新发现。

网站与 CDN 权限按需申请；不索取 Cookie API 权限，不上传源站 Cookie、令牌、历史。后端不代理抓取任意漫画 URL。

支持 PNG、JPEG、WebP 多图导入／拖放，可排序与排除误图。根据用户追加样本，首版增加未加密 MOBI6／MOBI6+KF8 漫画导入：按正文 recindex 确定顺序，不重复导入缩略图和其他版本。最大512 MB、1500页；拒绝 DRM、损坏记录、不支持压缩。嵌入GIF可阅读，翻译时规范化PNG首帧。2026-09-14 已扩展 CBZ/ZIP、CBR/RAR、PDF；完整支持范围、资源限制和顺序规则见[格式与缓存说明](IMPORT_FORMATS_AND_CACHE.md)。独立 KF8/AZW3、EPUB 仍未实现。

本地文件、提取图片和书架默认留本机，只有明确翻译的页面上传。私有测试漫画不能发布为产品示例。

本地导入使用可收起的预检与进度面板，提前标出重复和待补齐原图的文件；批量选择、逐份保存、暂停／继续、停止剩余及失败重试已实现。结果分别说明新增、补齐、跳过和失败，保留已有归属与阅读位置。见[本地导入流程及验收](LOCAL_IMPORT_FLOW.md)。

## 连续阅读规则

- 连续纵向滚动、单页、左右方向、适宽／适窗、缩放、键盘翻页、全屏。
- 阅读器仅保留左右侧工具，取消顶部与底部通栏；工具位于图片画布外侧。翻译方式与目标语言使用紧凑设置气泡，支持点击外部或 Esc 关闭，不改变阅读位置；目录和阅读设置保留抽屉。
- 图片左上角的翻译失败提示可点击重新生成，并立即进入等待／处理状态；旧译图继续保留。结果尚待核实不提供重发入口，译图下载失败提供重新加载入口。
- 连续阅读到话尾自动接上同来源、同版本的相邻下一话，靠近话首自动加载相邻上一话，支持跳转指定话后双向连读并保持页面位置；滚过完整话尾后自动记为已读，末话读到底部后记为已读。单页模式末页继续翻页或滚到底部时进入下一话。阅读器不再展示上一条目、下一条目、标记已读按钮。
- 缺少相邻章节／兼容副本时停止连读，不跳话；清单未采集完整时等待补齐。空话显示采集状态，缺原图的章节保持未读。
- “发现图片”手动选定并导入的图片构成固定页数的阅读副本：选中 4 张即共 4 页，4 张原图齐全即显示可阅读；来源网页仍可发现更多图片不使已导入副本显示未知页数。后台目录采集仍按已确认的章节总数与清单状态展示。
- 原始尺寸占位，有限窗口和像素预算控制解码，不同时解码全卷。
- 保存页面 ID + 页内相对位置，重开、切换语言／译图与对照保持锚点。
- 无需登录可看原图；翻译登录后保留当前章节和范围。
- 缺少当前语言译图时显示原图和状态；单页失败不阻塞其余页。
- 原图与不同模式、语言、版本的译图分别保存；新版读者界面对同一模式／语言只展示最新效果，切换已有结果不创建任务或重复扣费。常规模式已接入同一套结果管理；本轮界面与新增接口已接入，验证边界见[UI 实现说明](../apps/extension/README.md)。
- 并排对照保留双方宽高比，不拉伸掩盖变化。
- 输入控件编辑时不拦截翻页；按钮有名称、状态不只靠颜色、焦点可见。
- 最近阅读不代表全卷离线可用；清理缓存后保留位置和缺图提示。

翻译范围随当前阅读位置更新，离开的未提交图片不继续上传；已经受理的请求持续执行。账户总容量由服务端原子约束，额度不足只在图内提示升级。原图与译图长期保留，用户主动删除仍立即撤销新访问。

## 状态与费用

| 状态 | 含义／动作 |
| --- | --- |
| 原图待获取 | 回来源重取或重新导入 |
| 未翻译 | 默认显示原图，手动选择常规或 AI 后才随读翻译 |
| 上传／排队 | 准备处理，可取消未开始任务 |
| 处理中 | 模型调用／验证／保存，不编造百分比 |
| 完成 | 可解码图片已私有保存，可以对照／导出 |
| 失败 | 显示尺寸、额度、供应商等可操作原因 |
| 结果待核实 | 现有图片重绘可能已受理，禁止自动重发或换供应商；常规文本 LLM 在预算与次数内自动重试，耗尽后普通失败 |
| 过期／删除 | 访问撤销，需重新上传，不返回失效缓存 |

同一操作ID绑定图片与参数，重复点击返回原任务，参数变化返回冲突。主动重新生成使用新ID并提示新消耗。本人相同内容、模式、语言与有效配置可以缓存复用。同一账户换电脑后重新导入相同文件，通过文件 SHA-256＋原始页索引恢复有效译图和进行中任务，不再次收费；重排页面不影响匹配。新导入页增加原图 SHA-256 查找，换压缩包或文件名也能免上传恢复同账户结果；PDF 标识包含渲染配置和输出页字节。原图与译图默认长期保留，受主动删除与后续清理政策约束，阅读位置与书架仍为本地数据，不兼容旧文件映射。

页数额度按成功交付版本扣除：受理时预占、完成结算，明确失败／未执行取消释放。供应商消耗与用户账本分开，无 usage 保持未知。未知结果到核实期限释放后，不因后到结果静默补扣。

前端原图上传并发固定为 5，不提供设置入口；下载按有限阅读窗口加载，不设该上传池的并发上限。浏览器资源限制独立于普通 30／PLUS 100 张每滚动 60 秒准入额度。服务端保留实时优先、公平调度与幂等结算，不再以用户在途任务数限制受理。

## 权限、数据与验收

图片、任务、批次按用户隔离，以Bearer授权网关访问。暂存默认7天可配置。删除先撤销访问，进行中任务不能重新挂回被删图片。公开模式OIDC+PKCE，本地测试登录只用于环回地址。凭据、图片正文、签名地址不进入默认日志。

分别验证插件构建、目标浏览器截图、真实MOBI顺序、100页以上有限窗口、恢复、对照、真实模型译图、幂等额度、跨用户隔离、任务恢复、删除和到期。HTTP200不代表交付完成；格式检查与翻译质量分别验收，记录漏译、错译、背景文字、字体、画面变化、比例和裁切。

双页、术语上下文、长图分段回拼、整卷译图打包、更多格式／站点和公开发布属于后续范围；支付采用 [Stripe／Creem 托管结账与客户门户](STRIPE_BILLING.md)。
