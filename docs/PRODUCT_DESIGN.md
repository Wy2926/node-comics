# Node Comics 产品设计 v0.3

2026-09-14 范围更新：保留 **AI 图片重绘翻译**，增加 **常规漫画翻译**，文本可由 LLM 翻译，允许 LaMa 局部背景修复，再通过字体渲染嵌字。视觉采用专业二次元风的大封面和清晰文字层级，支持四种强调色与亮暗外观。常规模式已基于[调研设计](CLASSIC_TRANSLATION_RESEARCH.md)实现；运行及验证边界见[常规翻译说明](CLASSIC_IMPLEMENTATION.md)，浏览器验收交由用户。

## 常规模式

2026-09-14 已实现本轮交互改造：支持自动翻译与自动显示译图，明确区分当前画面和任务状态；同一页、同一种模式与目标语言只展示最新效果，读者不再选择历史版本；支持反馈与重新翻译；目录采用缩略图列表。具体交互和预算规则见[翻译交互细化](TRANSLATION_UX_PROPOSAL.md)，版本资产仍按现有保留策略管理。

用户选择页面、目标语言和翻译方式后确认预算。常规模式走文字检测／OCR、LLM 文本翻译、纯色填充或 LaMa 抹字与嵌字；AI 重绘继续走图片模型。两类译图按模式、语言和版本独立保存，切换保持阅读位置。 阅读器保留紧凑的当前页信息栏，可直接切换原图、常规翻译和 AI 重绘；常规效果不佳时，点击「AI 重绘本页」为当前单页准备报价，不改变自动／批量翻译的默认模式。等待重绘、读取结果或重绘失败时优先显示本页已有有效常规译图；没有常规译图才显示原图。重绘就绪后显示所选结果；用户主动切回原图或常规译图时保持该选择。批量与“边读边译”的预算必须绑定用户所选模式。

LaMa 已获用户同意，常规链路成本分为自部署计算资源和文本 token，见调研文档第 6 节。文本 LLM 允许在次数和金额上限内自动重试、修复格式，无需每次确认；读者同一页只结算一次，图片重绘仍保留严格的未知结果保护。复杂背景不能可靠处理时保留相关原文并说明，不自动转成重绘或宣称完整翻译。抹字、OCR、LLM 和嵌字分别报告阶段失败；真正无字与识别失败分开。首批源语言、复杂页降级体验和是否提供人工文本编辑待样本验证后确定。

以下内容描述流程与验收基线。部分低置信 OCR 区域保留原文，输出明确标为部分完成并释放点数；整体 OCR、译文或排版失败时保留整页原图。

## 产品与主流程

产品是带独立阅读器的 Chrome / Edge MV3 插件，面向公开用户，后续考虑收费。插件轻量，翻译任务在后端持久化执行。

网页发现图片／导入本地文件 → 阅读原图 → 选择页面与语言 → 确认预计额度 → 所选模式逐页完成 → 原图对照、查看最新效果、反馈和保存译图。

AI 重绘只要求图片和目标语言，无 OCR 前置步骤。后端生成版本化提示词调用 OpenAI 兼容 `POST /v1/images/edits`；供应商、模型与参数由运营方配置。Key 不进入插件。

## 作品管理

2026-09-14 用户已确认并授权实现：漫画管理采用来源无关的行业抽象，区分作品、章节内容、出版套系、卷册、收录关系与可读副本。番外是内容角色，单行本是出版形式；网站分组只是来源信息，不定义核心模型。已使用全新数据库实现首轮功能，清理原扁平书架逻辑，没有旧数据兼容代码。管理和交互见[通用设计](COMIC_LIBRARY_DESIGN.md)，操作及验收见[实现记录](COMIC_LIBRARY_IMPLEMENTATION.md)。

## 图片来源与本地导入

MangaCopy作为来源之一，已实现详情页整部可选范围导入、目录归属预览和原图断点采集；来源映射及data-src采集见[MangaCopy来源设计](MANGACOPY_LIBRARY_DESIGN.md)。话、卷、番外真实样本均已完整采集；具体权限与来源验收边界见实现记录。

网页发现与字节获取分离。通用适配读取当前 DOM 和懒加载来源，按当前已知顺序建立清单；只有确知完整页数时才标记整章完成。失败保留可操作原因，支持滚动来源后重新发现。

网站与 CDN 权限按需申请；不索取 Cookie API 权限，不上传源站 Cookie、令牌、历史。后端不代理抓取任意漫画 URL。

支持 PNG、JPEG、WebP 多图导入／拖放，可排序与排除误图。根据用户追加样本，首版增加未加密 MOBI6／MOBI6+KF8 漫画导入：按正文 recindex 确定顺序，不重复导入缩略图和其他版本。最大512 MB、1500页；拒绝 DRM、损坏记录、不支持压缩。嵌入GIF可阅读，翻译时规范化PNG首帧。2026-09-14 已扩展 CBZ/ZIP、CBR/RAR、PDF；完整支持范围、资源限制和顺序规则见[格式与缓存说明](IMPORT_FORMATS_AND_CACHE.md)。独立 KF8/AZW3、EPUB 仍未实现。

本地文件、提取图片和书架默认留本机，只有明确翻译的页面上传。私有测试漫画不能发布为产品示例。

## 连续阅读规则

- 连续纵向滚动、单页、左右方向、适宽／适窗、缩放、键盘翻页、全屏。
- 原始尺寸占位，有限窗口和像素预算控制解码，不同时解码全卷。
- 保存页面 ID + 页内相对位置，重开、切换语言／译图与对照保持锚点。
- 无需登录可看原图；翻译登录后保留当前章节和范围。
- 缺少当前语言译图时显示原图和状态；单页失败不阻塞其余页。
- 原图与不同模式、语言、版本的译图分别保存；新版读者界面对同一模式／语言只展示最新效果，切换已有结果不创建任务或重复扣费。常规模式已接入同一套结果管理；本轮界面与新增接口已接入，验证边界见[UI 实现说明](UI_IMPLEMENTATION.md)。
- 并排对照保留双方宽高比，不拉伸掩盖变化。
- 输入控件编辑时不拦截翻页；按钮有名称、状态不只靠颜色、焦点可见。
- 最近阅读不代表全卷离线可用；清理缓存后保留位置和缺图提示。

翻译由用户明确触发，自动翻译首次默认关闭；确认后在本机按账户、服务、模式、语言记住选择，刷新、换漫画和返回阅读自动继续。2026-09-14 更新：开启时说明模式、每页点数及持续使用账户额度；按当前页和后 10 页跟随阅读，提前量可设 0–50 页，不限制本次翻译总页数。关闭开关或离开阅读器后停止新建任务，已提交任务继续；报价单价改变时保留开关并显示暂停原因，确认新价格后继续；同价内部配置变化不打断阅读。临时准备故障与明确拒绝的额度不足自动等待重试；提交结果未知时保留原请求待核实。手动翻译本页不关闭自动翻译。批量仍先确认范围与预算，未上传页面不能声称后台继续获取。

## 状态与费用

| 状态 | 含义／动作 |
| --- | --- |
| 原图待获取 | 回来源重取或重新导入 |
| 未翻译 | 原图可读，选择范围启动AI翻译 |
| 上传／排队 | 准备处理，可取消未开始任务 |
| 处理中 | 模型调用／验证／保存，不编造百分比 |
| 完成 | 可解码图片已私有保存，可以对照／导出 |
| 失败 | 显示尺寸、额度、供应商等可操作原因 |
| 结果待核实 | 现有图片重绘可能已受理，禁止自动重发或换供应商；常规文本 LLM 在预算与次数内自动重试，耗尽后普通失败 |
| 过期／删除 | 访问撤销，需重新上传，不返回失效缓存 |

同一操作ID绑定图片与参数，重复点击返回原任务，参数变化返回冲突。主动重新生成使用新ID并提示新消耗。本人相同内容、模式、语言与有效配置可以缓存复用。同一账户换电脑后重新导入相同文件，通过文件 SHA-256＋原始页索引恢复有效译图和进行中任务，不再次收费；重排页面不影响匹配。新导入页增加原图 SHA-256 查找，换压缩包或文件名也能免上传恢复同账户结果；PDF 标识包含渲染配置和输出页字节。原图与译图仍受保留期限制，阅读位置与书架仍为本地数据，不兼容旧文件映射。

测试点数按成功交付版本扣除：启动预占、完成结算，明确失败／未执行取消释放。供应商消耗与用户账本分开，无usage保持未知。未知结果到核实期限释放后，不因后到结果静默补扣。

前端上传／下载并发默认 2，用户可设 1–10。后端任务仍排队，按用户轮转；每用户队列并发默认 2，可在服务端上限内配置，所有批次及翻译模式共享名额，避免单用户多个批次占满队列。批次限制页数和预算；报价过期／配置变化拒绝创建，不静默加价。测试点数不是人民币价格；支付与正式价格待成本验证。

## 权限、数据与验收

图片、任务、批次按用户隔离，以Bearer授权网关访问。暂存默认7天可配置。删除先撤销访问，进行中任务不能重新挂回被删图片。公开模式OIDC+PKCE，本地测试登录只用于环回地址。凭据、图片正文、签名地址不进入默认日志。

分别验证插件构建、目标浏览器截图、真实MOBI顺序、100页以上有限窗口、恢复、对照、真实模型译图、幂等额度、跨用户隔离、任务恢复、删除和到期。HTTP200不代表交付完成；格式检查与翻译质量分别验收，记录漏译、错译、背景文字、字体、画面变化、比例和裁切。

双页、术语上下文、长图分段回拼、整卷译图打包、更多格式／站点、支付和公开发布属于后续范围。
