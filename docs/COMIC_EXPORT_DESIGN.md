# 漫画导出

2026-09-15。**用户已确认规则；已完成代码与本地 Chrome 验收，未提交、推送或公开部署。**

## 使用与已确认规则

漫画作品详情页，在「采集中心」右侧点击「导出漫画」，按「选择内容 → 检查与导出」两步操作。检查清单后点击「开始导出」，生成后点击「下载文件」。可重新检查、返回选择、取消或关闭。

| 项目 | 本次实现 |
| --- | --- |
| 文件组织 | 每个实际副本独立成文件，多文件打包下载；可勾选副本，同内容的不同来源分别保留 |
| 图片 | 可选仅原图、仅译图、原图与译图；两者分别成册 |
| 译图 | 选择目标语言、常规翻译或 AI 重绘；每页取最新成功结果，缺少译图时使用原图并列明 |
| 格式 | CBZ、图片 ZIP、PDF |

一轮导出选择一种语言与模式；需要其他组合时分别导出。原图导出不要求登录，译图使用当前账户与当前服务的已有记录。

## 复杂内容如何处理

- 从当前作品关联的 `ReadingCopy` 构建清单，同一副本即使有多条归属也只导出一次。按章节、番外、卷册套系、整部与未分类分组，可搜索、全选当前组及逐项勾选。
- 一份副本是最小导出单位，保留其完整页面清单。收录、合订和再版关系不用于猜测页范围或拼出没有实际副本的卷册。
- 单话与收录该话的整卷分别展示，不按名称、收录关系或图像相似度自动删页。同名副本由导出序号区分。
- 副本通过归属、卷册关联作品或已知收录关系涉及其他作品时，默认不勾选。选中后须明确勾选「按整份副本导出」，界面列出包含的其他作品；本次不按已有起止页范围拆页。
- 使用 `ReadingCopy.pages` 当前顺序，输出文件名为补零页序号。原始 `pageIndex` 继续用于恢复匹配，不因导出修改。
- **检查清单时**冻结副本修订、页序和结果身份。新完成的采集／翻译可重新检查后加入，不在生成中悄悄更换图片。

## 译图与缺页规则

| 情况 | 行为 |
| --- | --- |
| 新翻译处理中 | 继续使用之前最新成功的结果 |
| 最新成功译图仍在本机 | 优先本机；即使远端到期仍可使用 |
| 本机没有译图，远端记录有效 | 生成时通过已有授权 API 下载最终译图并解码验证 |
| 最新成功结果失效 | 不回退更早版本，按缺译图处理 |
| 未翻译、失败、处理中或失效 | 用本机原图补齐，清单逐页标注原因 |
| `no_text` 且没有成功译图 | 保留原图，单独统计无文字页 |
| 原图也不存在 | 标注缺页；默认禁止导出，明确允许不完整内容后才跳过 |
| 清单未完成 | 标注不完整；总数未知显示 `?`，不声称已采集全章 |
| 某个输出没有任何可用页 | 禁止生成，提示调整所选副本或原图／译图选项 |
| 检查后图片被清理、下载或编码失败 | 停止生成，显示文件与页码；可重试、重新检查或调整选择，不静默替换 |
| 导出时切换账户或服务 | 停止导出，撤销下载入口，不混入其他账户数据 |

有链接、任务或页清单不代表保存了字节。检查阶段读取 IndexedDB 核实 Blob，只保存大小与引用，不持有整部原图；不探测远端对象。生成阶段复用 `Api.image` 的签名／同源授权及解码验证，并传递取消信号。

导出不提交报价、翻译、OCR 或上传，不自动采集原图，不更新副本、阅读位置或缓存记录。

## 文件与画质

| 格式 | 内容 |
| --- | --- |
| CBZ | 每个副本及图片类型一个 CBZ，包内依序保存图片和 `导出说明.json` |
| 图片 ZIP | 一个 ZIP，按原图／译图和副本分目录保存图片，根目录有 `导出说明.json`；不嵌套 CBZ |
| PDF | 每个副本及图片类型一份 PDF，一页一图、保持比例；95% 质量 JPEG 编码，透明背景铺白，内附 `export-manifest.json` |

CBZ／ZIP 中 JPEG、PNG、WebP 保留原始图片字节，其他浏览器可解码格式转 PNG。PDF 有重编码，需保留原始字节时选 CBZ 或图片 ZIP。

单个 CBZ／PDF 直接下载，多结果以一个外层 ZIP 打包，避免浏览器多文件下载权限。例如：

```text
漫画名-导出.zip
  原图/
    0001-第01话-修订1.cbz
    0002-第02话-修订1.cbz
  简体中文-常规翻译/
    0001-第01话-修订1.cbz
    0002-第02话-修订1.cbz
  导出说明.json
```

不完整文件／目录及外层文件名追加 `-不完整`。缺页在图片文件序号中留空；PDF 的连续物理页可通过附件清单中的原页序号与 `missing` 条目对应。

说明采用字段白名单，保存名称、归属、副本 ID／修订、图片类型、页序、任务／版本和缺页原因等信息，不直接序列化数据库、页面对象、源地址、账户 ID、令牌、Blob 键或签名地址。首期不承诺整个漫画库的备份还原、历史整本译图快照或 ComicInfo 元数据导出。

## 容量与实现

- 图片逐页获取、解码和写入，已有后台采集和翻译继续独立运行。
- 每次所选图片累计与最终下载文件均限制为 **512 MiB**，同图在两套输出中分别计入；远端大小在下载后计入。大部作品请分批选择。
- 单份 PDF 重编码图片累计限制为 **128 MiB**；单页解码后限制为 **3200 万像素**。
- 当前输出为 Blob，仍占用本机内存，尚无磁盘流式输出或跨会话续传。取消、关闭和更改选项释放下载 URL，临时输出不写入漫画库。
- zip.js 使用本地 native streams 构建；PDF 写入器和依赖按需加载，不在扩展 service worker 中生成文件。
