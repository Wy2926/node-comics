# 漫画与章节目录导出

导出面向当前漫画的单一来源：图片内容可导出当前章节或整个章节目录，EPUB 仅保存完整原包；入口在漫画卡片菜单。不跨漫画批量导出，不另设章节勾选、来源或版本管理。当前模型见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md)。

## 用户流程

图片内容打开导出面板，选择 CBZ、图片 ZIP 或 PDF，以及原图／当前目标语言和模式的已有译图。多章节漫画提供“当前章节／整个章节目录”，默认保留当前章节范围；单文件内容不展示多余的范围选择。面板复用共享 `Modal`、主题令牌、内容提示卡和固定底部操作区，正文独立滚动；显示准备章节、当前章节及页面进度，支持取消、关闭和失败后重试。

整目录导出沿用阅读目录顺序及每话当前语言／发布版本选择，一话只导出一个版本；不修改阅读选择、已读状态或位置。打开面板仅查询本地目录元数据。点击导出后，目录不完整时复用来源服务补齐并核验完整性，再串行建立未读章节的页面索引；任一章节不可读、发现失败或页面不完整时停止并说明章节，不静默跳过或输出假完整文件。目录和页面计划冻结当前内容身份，执行期间不自动加入后来的更新。

已保存完整容器的本地或远程内容可在当前章节范围逐字节保存源文件；EPUB 仅提供此方式，原包不可用时提示重新获取。当前章节尚未建立可读索引或没有页面时明确失败。

页面导出会主动读取所选范围全部页面，可能从云盘或来源网站下载图片；不会创建翻译任务。仅当前章节允许显式选择导出已发现页面，文件名与清单说明不完整状态；整目录不提供不完整导出选项。

## 结果与权限

- 原图通过页面服务取得并验证当前内容身份；不同图片逐页读取、释放。
- 官方已有译图优先直接读取完整译图缓存；缓存缺失时通过统一 `materializeResult(result, original)` 校验原图与覆盖文件，在原生尺寸用 `source-atop` 合成并缓存整页；MTU 保持完整图读取。需要合成时原图缺失或摘要不符明确失败，不能导出裸覆盖文件。缓存规则见[翻译契约](READING_TRANSLATION_CONTRACT.md#4-状态与结果)。
- 已有译图按当前账户、API、模式、语言选择有效结果。缺少译图时保留原图并在清单注明；失效访问不能通过旧记录恢复。
- 切换账户、内容身份变化、取消或生成失败会停止输出并撤销下载入口，不能混入其他账户或旧内容。
- 导出清单采用字段白名单，保存当前内容标识、页序和结果说明；不包含来源凭据、源站 Cookie、签名地址或完整数据库记录。

## 文件与资源

CBZ／ZIP 依页序保存可用原始图片字节并包含 `export-manifest.json`。整目录在同一个归档内使用“章节序号－安全章节名”文件夹，章内页码独立编号；清单额外记录章节标题、起始页和页数，不包含来源地址。PDF 按章节顺序合并页面并附带相同清单，按页绘制且可能重编码，需要原始字节时使用 CBZ 或完整源文件导出。

支持文件选择器的浏览器可将 CBZ／ZIP 逐页写入文件。其他浏览器及 PDF 使用有界缓冲，整份导出上限 128 MiB，跨章节累计而非每章重置；单页图片不另设字节、像素或边长上限。元数据计划最多 10000 页，逐页只持有一个图片租约；整目录会增加所选章节的索引与图片请求，当前章节导出是较轻的替代方式。关闭面板会取消当前操作并释放资源，不保存临时漫画副本，也不修改阅读位置。

实现：[导出服务](../apps/extension/src/comics/application/export-service.ts)、[目录计划](../apps/extension/src/comics/application/export-directory.ts)、[页面计划](../apps/extension/src/export/plan.ts)、[导出面板](../apps/extension/src/ui/DocumentExport.tsx)。依赖版本与许可证见[格式说明](IMPORT_FORMATS_AND_CACHE.md)。

浏览器验证运行 `node scripts/verify_source_export.mjs`，使用自制 CBZ 检查完整源文件字节、导出页面与清单，以及 PDF 重新解析。`node --test apps/extension/tests/directory-export.browser.mjs` 验证整目录三种格式、按需索引、版本去重、串行取图、取消／失败重试、位置保持和 16 语窄屏提示框；采用合成来源与真实 Chromium，不代表真实网站可用性。环境见[脚本说明](../scripts/README.md#来源与阅读验收)。
