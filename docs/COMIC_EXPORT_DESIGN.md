# 当前漫画内容导出

2026-09-23。导出仅面向当前来源条目的页面；入口在阅读设置或漫画卡片更多菜单。没有作品归属、章节勾选、来源选择和版本选择。当前模型见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md)。

## 用户流程

打开导出面板，选择 CBZ、图片 ZIP 或 PDF，以及原图／当前目标语言和模式的已有译图，然后导出全部页面。本地文件还可逐字节保存完整源文件。尚未建立可读索引或没有页面时明确失败。

导出会主动读取当前内容全部页面，可能从云盘或来源网站下载图片；不会创建翻译任务。来源清单不完整时须明确选择只导出已发现页面，文件名与清单说明不完整状态，不能声称整本已保存。

## 结果与权限

- 原图通过页面服务取得并验证当前内容身份；不同图片逐页读取、释放。
- 已有译图按当前账户、API、模式、语言选择有效结果。缺少译图时保留原图并在清单注明；失效访问不能通过旧记录恢复。
- 切换账户、内容身份变化、取消或生成失败会停止输出并撤销下载入口，不能混入其他账户或旧内容。
- 导出清单采用字段白名单，保存当前内容标识、页序和结果说明；不包含来源凭据、源站 Cookie、签名地址或完整数据库记录。

## 文件与资源

CBZ／ZIP 依页序保存可用原始图片字节并包含 `export-manifest.json`。PDF 按页绘制且可能重编码，需要原始字节时使用 CBZ 或完整源文件导出。

支持文件选择器的浏览器可将 CBZ／ZIP 逐页写入文件。其他浏览器及 PDF 使用有界缓冲，当前上限 128 MiB。关闭面板会取消当前操作并释放资源，不保存临时漫画副本，也不修改阅读位置。

实现：[导出服务](../apps/extension/src/comics/application/export-service.ts)、[页面计划](../apps/extension/src/export/plan.ts)、[导出面板](../apps/extension/src/ui/DocumentExport.tsx)。依赖版本与许可证见[格式说明](IMPORT_FORMATS_AND_CACHE.md)。

浏览器验证使用自制 CBZ：完整源文件逐字节一致、导出 CBZ 包含三页和清单、PDF 三页可重新解析。命令为 `node scripts/verify_source_export.mjs`，环境和复验方法见[脚本说明](../scripts/README.md#来源与阅读验收)。
