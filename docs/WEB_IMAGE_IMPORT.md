# 网页图片发现与加入漫画

2026-09-15 已实现网页导入；2026-09-20 Popup 改为手动发现并新增网页翻译入口，见 [Popup 与共享视觉令牌](POPUP_AND_THEME.md)。沿用现有作品、章节、卷册和阅读副本模型。

## 站点权限与镜像

- 安装时声明 `https://*.mangacopy.com/*`、`https://*.copy4000.com/*`，覆盖根域与子域。两站使用相同详情目录、章节 `data-src` 与懒加载逻辑，详情入口由清单中的内容脚本自动注入。
- 来源目录仍按作品路径标识，来源条目按章节 UUID 标识；镜像域名不生成另一套作品身份。网络请求保留实际来源域名，两个域名之间只有同一作品／章节的跳转可继续采集。
- 通用网页在用户打开工具栏弹窗并点击“发现网页图片”后利用 `activeTab` 发现，不在打开弹框时发起永久授权弹窗；浏览器限制访问时显示授权重试入口。下载原图仍在点击加入后按需申请图片域名权限。

## 弹框

- 沿用阅读器的主题色、亮暗外观与文字大小，并与登录模态框共用漫画视觉令牌。默认语言与翻译当前标签页为主操作，手动发现、刷新与加入入口保留。
- 打开时不发现图片；点击“发现网页图片”后开始，支持再次刷新。页面身份不变时保留勾选、手动排序和过滤图片的显式选择；移除已消失的来源项，把新图追加到末尾。关闭后再打开同一网页，仅在再次点击发现后恢复选择并刷新。
- 每张图片显示预览、原始分辨率和选中后的阅读序号；支持逐张勾选、全选当前、清空、拖动、上移／下移、倒序与恢复网页顺序。预览加载失败仍可选择原图。
- 通用来源默认过滤宽或高不足 300 px、总像素不足 180,000、宽高比大于 2.8 的图片。长条漫画和尺寸待确认的懒加载原图保留；“显示已过滤图片”可恢复候选。专用漫画适配器不套用通用阈值。
- 单次最多发现 1000 张 HTTP(S) 图片；优先使用懒加载原图地址，不把占位图尺寸当作原图尺寸。通用网页始终说明清单可能不完整。

## 加入漫画

点击“加入漫画”后在阅读器中确认归属，图片还可再次选择与排序：

| 方式 | 行为 |
| --- | --- |
| 新增阅读副本 | 选择新建或已有作品，归入章节、番外、卷册、完整作品或待整理材料；支持关联已有章节／卷册，保留为另一份副本。单独编辑副本／新条目名称。 |
| 插入已有副本 | 选择作品与阅读副本，追加到末尾、插入到开头，或插在指定页面之后。保留原页 ID、原图、译图、内容归属及页内阅读位置。 |

记住上次实际加入的作品；相同来源可建议已有归属，不按同名作品自动合并。插入时若目标采集仍在排队或运行，需要先在采集中心暂停；尚未补齐目录的来源副本需先完成图片清单。

## 数据与恢复

- 后台只接受当前清单中的图片 ID，校验非空、无重复和范围，再保存按用户顺序排列的选择快照；下载前继续校验来源标签页和导航身份，不接受调用方自行传入的图片地址。
- 精确网页来源与所选 URL 顺序确定新增副本身份。已有 MangaCopy 网页副本也能通过镜像来源识别；重试保持原归属。
- 插入在同一 IndexedDB 事务中更新副本并保存批次记录。同一来源清单在同一插入位置重复提交只补齐失败原图，不再次插页；原页序改变或插入锚点被移除时给出重新选择提示。
- 页清单修订递增并携带原阅读锚点；旧阅读器保存不能覆盖插入后的清单。各页原始文件摘要和文件页序不随阅读顺序变化。
- 手动扩充的来源副本标记为已整理页序，后续补图使用保存的每页地址，避免按源站顺序覆盖插入页。重新解析来源修订会创建独立清单，清除其手动整理标记。
- 下载逐页完成，失败页保存具体原因；再次加入同一来源可补回首次未获取的原图，不创建重复作品，也不把已变更的图片字节绑定到原译图。下载插入页时保护目标副本的缓存。
- 导入只获取并保存原图。已开启的自动翻译仍按现有授权在进入阅读器后生效。

## 验证与复现

在 `apps/extension` 执行 `npm run check`、`npm test`、`npm run build`、`npm run build:web`。本轮类型与模块检查通过，19 个测试文件、181 项测试通过，两种构建通过。

浏览器验收入口：[verify_web_import.mjs](../scripts/verify_web_import.mjs)。先构建 MV3，再在仓库根目录运行：

```powershell
# 环境中能直接找到 Playwright 和其 Chromium 时，无需设置下面两个变量。
$env:PLAYWRIGHT_MODULE = '已安装的 Playwright 模块路径'
$env:TEST_CHROMIUM = '支持加载未打包扩展的 Chromium 可执行文件路径'
node scripts/verify_web_import.mjs
```

脚本使用全新的隔离扩展配置和生产权限清单，不修改日常浏览器数据。图片来自仓库原创样本和合成尺寸样本；网站 HTML 与错误响应为隔离夹具，不需要后端、账户或翻译供应商。
