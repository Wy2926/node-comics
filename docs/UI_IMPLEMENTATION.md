# 客户端 UI 与翻译交互实现

2026-09-14。已替换阅读器客户端主界面，并接入实际接口；[整体设计](UI_REDESIGN_PROPOSAL.md)与[翻译交互细化](TRANSLATION_UX_PROPOSAL.md)保留设计依据，当前实现与验证以本文为准。

## 已实现

- 我的漫画：横向主导航、大封面网格／横向卡片、搜索、排序、继续阅读、名称和封面编辑、移除、本地图片、MOBI、CBZ/ZIP、CBR/RAR、PDF 导入。重新导入相同漫画时恢复原图，保留原书架条目、目录顺序、翻译记录和阅读位置。
- 阅读器：独立全宽画布，顶部放置目录与自动翻译入口，当前页信息区放置翻译按钮，底部为精简页码与拖动进度条；目录是全宽缩略图、下方文字的可变高度虚拟列表。支持连续／单页、方向、缩放、背景、全屏、沉浸、并排对照、导出、页码跳转和范围选择。原图按阅读窗口解码，缩略图限制并发与内存缓存。
- 翻译：当前模式与语言只展示最新成功交付的结果；新任务进行中或失败时保留已有译图。最新结果过期时不回退到更旧版本，同一最新结果的有效本地副本仍可阅读。显示身份在图片解码完成后更新。
- 自动翻译：首次使用默认关闭；本机记住已确认的账户、服务、模式和语言选择，刷新、换漫画和返回阅读自动继续；开启时说明每页点数和持续使用账户额度，默认按当前页及后 10 页准备任务，提前量可设 0–50 页，不设本次总页数上限。窗口随阅读位置移动并按单批上限拆分，页级失败不阻塞其他页；关闭或离开阅读器停止新增；换漫画使旧窗口失效，按新阅读位置继续。账户、服务、模式和语言只复用各自确认过的选择。手动翻译本页不关闭开关，报价确认期间暂让出提交队列。单价变化显示暂停原因并待确认；同价内部配置变化继续。准备阶段临时故障及明确拒绝的过期报价、配置变化和额度不足每 15 秒重试；未知提交保留原幂等记录、停止新增，用户核实后恢复。暂停不把开关变成关闭，也不自动弹窗打断阅读。完成后自动显示可独立设置，用户手动选择原图时保持原图。
- 反馈与重译：反馈免费，问题类型与说明至少填写一项；绑定用户实际查看的结果，保留草稿与幂等提交标识。重译重新报价；处理或结果待核实的页面在客户端禁用重译，提交前再次匹配确认。服务器支持将重新导入的同内容原图用于重译。
- 翻译记录：按提交批次分组，显示逐页完成、部分完成、失败、待核实和过期状态。费用区分结算、预占与复用；可展开逐页详情并回到本地漫画。未关联本地书架的记录仍可查询，保存操作获取当前模式最新译图。
- 用量统计：按 7／30／90 天汇总真实结算，按本地时区划分日期；包含每日趋势、翻译方式分布、交付数量及可展开的分页账本。当前可用与预占额度独立显示。
- 外观：晴空蓝、樱花粉、薄荷绿、鸢尾紫；亮暗外观、阅读背景与文字大小独立设置。账户页可查看反馈；管理员可查看并更新反馈处理状态。

单页翻译当前采用“翻译本页 → 获取报价 → 确认提交”，点数以服务端有效报价为准。自动翻译确认单价及连续使用额度后，无需逐页确认。设计稿中的示例书名、点数和图片均未用作真实账户数据。

## 服务端接口

完整类型见 [OpenAPI](../contracts/openapi.json)。

| 接口 | 用途 |
| --- | --- |
| `GET /v1/translation-history` | 分页获取分组记录，统计覆盖完整批次 |
| `GET /v1/me/usage/summary?days=7&timezone=Asia/Shanghai` | 完整时间区间的结算与交付统计 |
| `POST /v1/jobs/{id}/feedback` | 按 `Idempotency-Key` 保存当前结果反馈 |
| `GET /v1/me/feedback` | 当前用户反馈列表 |
| `GET /v1/admin/feedback` | 管理员反馈列表 |
| `PATCH /v1/admin/feedback/{id}` | 更新为已收到、查看中或已处理 |
| `GET /v1/jobs/{id}/latest-result` | 同内容、模式及语言的最新任务与最新交付结果 |
| `POST /v1/file-pages/match` | 可选 `include_display` 返回独立于当前供应商配置的显示结果及过期记录；旧调用保持兼容 |
| `POST /v1/jobs/{id}/rerun` | 可选 `input_asset_id` 绑定重新导入的同内容原图，校验所有权与内容哈希 |

批次任务回执新增 `reused`，避免把跨批次复用误记为本次扣费。数据库迁移 `0007` 新增反馈表及账本查询索引，不删除原有业务数据。

## 本地更新

本地 Compose 挂载源码，但运行中的 Python 进程不会自动加载新路由。只改前端后看到新页面，并不代表 API 已更新；新增接口返回通用 404 时需更新 API 服务。

```powershell
docker compose --env-file .env --env-file deploy/.env.local up -d --build --no-deps api
```

API 启动时自动迁移。此次已更新本地 18088 API，实际 PostgreSQL 上的记录、统计、反馈查询与最新结果查询均返回 200。操作未重启翻译 worker。
