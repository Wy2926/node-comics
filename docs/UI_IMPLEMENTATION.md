## 已实现

- 我的漫画：横向主导航、大封面网格／横向卡片、搜索、排序、继续阅读、名称和封面编辑、移除、本地图片、MOBI、CBZ/ZIP、CBR/RAR、PDF 导入。重新导入相同漫画时恢复原图，保留原书架条目、目录顺序、翻译记录和阅读位置。
- 阅读器：独立全宽画布，顶部放置目录、翻译面板与队列入口，当前页信息区放置翻译按钮，底部为精简页码与拖动进度条；目录是全宽缩略图、下方文字的可变高度虚拟列表。支持连续／单页、方向、缩放、背景、全屏、沉浸、并排对照、导出、页码跳转和范围选择。原图按阅读窗口解码，缩略图限制并发与内存缓存。
- 翻译：当前模式与语言只展示最新成功交付的结果；新任务进行中或失败时保留已有译图。最新结果过期时不回退到更旧版本，同一最新结果的有效本地副本仍可阅读。显示身份在图片解码完成后更新。
- 图片保留：原图与最终译图当前无限期存于私有 R2，`retention_days=0`、图片 `expires_at=null` 表示未设自动清理。客户端显示长期保留，不承诺资源永不删除；用户删除或未来长期未访问清理策略仍可使资源失效。上传授权与下载签名继续有独立的短有效期。
- 上传清单与队列：每次明确确认单页、本章或选定范围及额度上限，原始请求与幂等键先保存至 IndexedDB，再提交服务器。可选择有空位时持续补充本次范围。常规与重绘分别显示队列，普通每模式 10 页在途／2 页实时，PLUS 500 页／10 页实时。当前页及最近章节由客户端插序，服务端验证版本、会话、名额和所有权；不同账户同级按权重公平消费，资源空闲时可借用。原图上传并校验后关闭页面也继续翻译；本机补充暂停和服务器队列暂停分别控制。未知提交按原请求恢复，逐页上传失败独立保留原因。完成后自动显示可独立设置，用户手动选择原图时保持原图。
- 反馈与重译：反馈免费，问题类型与说明至少填写一项；绑定用户实际查看的结果，保留草稿与幂等提交标识。重译重新确认页数权益，使用新提交协议指定原任务；处理或结果待核实的页面禁用重译。核实期限结束后再次重绘需要明确确认未知费用风险。服务器支持将重新导入的同内容原图用于重译。
- 翻译记录：按提交批次分组，显示逐页完成、部分完成、失败、待核实和过期状态。费用区分结算、预占与复用；可展开逐页详情并回到本地漫画。未关联本地书架的记录仍可查询，保存操作获取当前模式最新译图。
- 用量统计：按 7／30／90 天分别汇总实际交付与有限额度结算，包含 PLUS 无限常规的实际交付，按本地时区划分日期；包含每日趋势、翻译方式分布、交付数量及可展开的分页账本。当前可用与预占额度独立显示。
- 外观：晴空蓝、樱花粉、薄荷绿、鸢尾紫；亮暗外观、阅读背景与文字大小独立设置。账户页可查看反馈；管理员可查看并更新反馈处理状态。

所有新增任务先确认所选页数和权益上限，已受理或已完成页面直接复用。开启持续补充只授权当前清单，阅读插序不会扩大已同意范围。设计稿中的示例书名与图片均未用作真实账户数据。

## 服务端接口

完整类型见 [OpenAPI](../contracts/openapi.json)。

| 接口 | 用途 |
| --- | --- |
| `POST /v1/translation-submissions` | 按幂等编号受理选定图片与页数上限，返回逐项任务和上传回执 |
| `PUT /v1/uploads/{id}/content`、`POST /v1/uploads/{id}/complete` | 上传缺失原图并进入异步校验 |
| `GET /v1/translation-submissions`、`GET /v1/translation-submissions/{id}` | 分页清单摘要及完整逐项回执 |
| `GET /v1/me/queues`、`POST /v1/me/queues/{mode}/pause` | 两种模式独立容量、状态与暂停 |
| `POST /v1/me/queues/{mode}/priority` | 有版本、序号与有效期的本人插序和实时申请 |
| `GET /v1/me/translation-changes` | 按持久化游标同步账户任务变化 |
| `GET /v1/me/usage/summary?days=7&timezone=Asia/Shanghai` | 完整时间区间的结算与交付统计 |
| `POST /v1/jobs/{id}/feedback` | 按 `Idempotency-Key` 保存当前结果反馈 |
| `GET /v1/me/feedback` | 当前用户反馈列表 |
| `GET /v1/admin/feedback` | 管理员反馈列表 |
| `PATCH /v1/admin/feedback/{id}` | 更新为已收到、查看中或已处理 |
| `GET /v1/jobs/{id}/latest-result` | 同内容、模式及语言的最新任务与最新交付结果 |
| `POST /v1/file-pages/match` | 按文件／图片身份查询任务，可用 `include_display` 读取最新显示结果及过期记录 |

清单每项的 `reused` 与原任务结算记录分别读取，避免把复用误记为本次扣费。当前数据库基线 `shared_0001`；旧接口、数据结构与调度消息不兼容。

### 2026-09-15 记录查询与对象存储减负

- 记录列表只查数据库：分页选出提交清单，再一次性读取 `SubmissionItem` 对应状态、费用与图片有效期字段，不加载任务配置 JSON。查询次数不随本页清单数量增长，仍统计完整清单并按任务去重计费。
- 任务状态、缓存匹配及下载签名不请求 R2 HEAD；客户端真正下载时才检查对象是否存在。数据库过期、删除、物理清理状态继续立即生效。存储范围和取舍见[对象存储说明](OBJECT_STORAGE.md)。
- 记录列表及展开的逐页详情在有等待上传／校验／排队／运行任务时每 15 秒刷新；待核实每 60 秒刷新；完成后停止。记录页隐藏后暂停查询，恢复可见时刷新。账户级增量同步另有独立生命周期。出错按 30/60/120 秒退避，保留手动刷新与重试入口；删除译图成功后主动刷新。
- 不增加旧数据迁移、兼容或进程内结果缓存；账户隔离、完整页数和复用费用通过新提交契约验证。

集群重构前的历史只读测量（首页 12 组、53 页）：原查询 **13.079 秒、112 次 SQL、49 次 R2 HEAD**，其中 R2 用时 12.826 秒；当时优化后连续 3 次为 **14.8 / 9.5 / 6.7 毫秒、3 次 SQL、零存储访问**。这是旧基线查询函数耗时，不代表当前集群、公网延迟或大规模并发压测。

新增后端用例验证 SQL 次数不随组数增加、数据库有效期、重复引用不重复计费、用户隔离、禁止中间图片上传、查询/签名零 R2 请求，以及本地检查点恢复只上传一次最终译图。前端验证完成后停止、隐藏页暂停、退避和慢请求不重叠。Chrome 隔离验收命令：

```powershell
npm --prefix apps/extension run dev -- --port 5174
# 另一终端；PLAYWRIGHT_MODULE 可指向已安装的 playwright 模块
node scripts/verify_history.mjs
```

脚本复用隔离阅读器样本和模拟接口，不调用真实后端、R2 或供应商。检查加载、列表/详情完成后停止、分页、失败重试、页面可见性和删除后即时刷新；截图与结果写入 `artifacts/history-validation/`。

本轮验证：后端 189 项通过、14 项需专用 PostgreSQL 并发环境的用例跳过；前端 209 项通过，类型/模块检查和两种构建通过，Chrome 上述 5 组交互通过。最终对象存储/历史接口改动另以 35 项专项用例复核。确认本地没有排队或运行任务后，已重载 API、dispatcher、两种 worker；API 容器内实际 HTTP 查询均返回 200，首次 **87.3 毫秒**，随后 **16.7 / 14.3 毫秒**（含认证与 HTTP，不含公网传输）。未调用真实翻译供应商，未上传测试图片，未公开部署。

只读核查已有资产记录：R2 上登记 216 张 `classic_stage`（159,813,024 字节，约 152 MiB）、54 张最终 `classic`，没有原图。按本轮要求不迁移、不清理旧数据，仅阻止新中间产物上传；数据库记录核查不等于逐对象核验。

## 本地更新

本地 Compose 挂载源码，但运行中的 Python 进程不会自动加载新路由。只改前端后看到新页面，并不代表 API 已更新；新增接口返回通用 404 时需更新 API 服务。

```powershell
docker compose --env-file .env --env-file deploy/.env.local up -d --build --no-deps api
```

当前集群基线需使用新数据库并配套更新 API、控制 worker 和计算节点。上面的 API 单服务重建命令适用于已配置好新基线后的日常更新，不能把旧数据库自动升级为兼容系统。实际部署状态见[集群验收](CLUSTER_VALIDATION.md)。

## 2026-09-15 连读与导入页数

- 连续阅读到话尾附近时追加下一话，靠近已加载区域的话首时前置同来源、同版本的相邻上一话，支持从目录跳转后向上连读；前置时补偿滚动位置，保持当前页面的屏幕位置。已展示章节保留用于回看，预加载不会标记已读，只有实际向下跨过话尾才完成该话。标题、当前页操作和本人任务插序跟随当前话；整个连读区域仍共用附近最多 5 页、3200 万像素的解码窗口。
