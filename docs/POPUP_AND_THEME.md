# Popup 与共享视觉令牌

## 当前行为

- 打开 Popup 读取当前标签页和偏好，并通知后台检查到期目录；不发起图片发现、缩略图加载或翻译。浏览器内部页禁用网页操作，漫画管理器与设置仍可用。
- 目标语言与设置页共用 `TargetLanguage` 控件、`Settings.language` 字段及持久存储。切换语言保留其他偏好，翻译方式固定为常规翻译。已打开的设置页和 Popup 双向同步。
- Popup 与设置页提供“标签页自动翻译”，共用 `AutoTranslateTabs` 控件与 `Settings.autoTranslateTabs`，默认关闭。开启时检查浏览器当前网站访问权限；访问受限时不保存开启状态，提示在扩展设置中允许访问所有网站。开启后，后台在当前网页、标签页激活和导航完成时启动现有网页内翻译，使用默认翻译方式与目标语言；懒加载图片由原有观察器持续识别。候选按显示尺寸筛选，可能包括非漫画大图。
- 关闭自动翻译会停止自动启动的网页并恢复原图，已提交的服务端任务继续执行；手动启动的翻译保留。网页控件的暂停、恢复原图和关闭选择不会被再次切换到该标签页覆盖；刷新或进入新页面按全局开关重新启动。权限被撤销时开关同步关闭。后台通过标签页事件恢复，不依赖 Popup 常驻，也不批量提交隐藏标签页的图片。
- 点击“翻译当前标签页”时检查与右键入口相同的网站访问权限，等待设置同步，再向后台发送 `NC_TRANSLATE_TAB`。网站访问在安装配置中统一声明，遵循[公共权限规则](SITE_ADAPTERS.md#必须保持的约束)，使用时不再申请。后台只接受可信扩展页面消息，校验标签页及原 URL 后调用现有 `activateInline`。启动成功关闭 Popup；访问受限和启动失败留在 Popup 提示，可重试。图片翻译进度、登录和额度状态仍在原网页展示。
- 顶栏只保留品牌与简短说明，不展示当前标签页的名称和地址。专用适配器认领的网站显示带文字的“已适配”标志，包括网站首页与仅支持网页翻译的站点；允许导入的漫画页另提供“开始阅读”和“寻找其他语言”，经公共来源服务导入并直接打开。已适配网站的非漫画页提示进入详情页或章节页；未适配网页不提供图片选择或导入。
- “申请适配网站”使用翻译区标题旁的小文字入口，打开 `reader.html#sites/request`，定位并聚焦现有匿名申请表单，不自动填写或提交；此入口暂缓自动更新说明弹框，避免遮住申请表单。
- 窗口宽 420px、高不超过 600px；顶栏紧凑固定，正文按需滚动。划图翻译、我的漫画、设置与键盘快捷键使用两列功能卡片，不在底部另排一行工具。主操作、卡片、适配标志与按键提示复用共享描边、圆角和硬阴影令牌，沿用亮暗外观、六种强调色和文字大小设置。
- 有快捷键的入口同时显示当前组合键；翻译、我的漫画、设置和快捷键面板读取用户保存的覆盖项，停用或冲突键不显示，Popup 中的提示键可执行对应操作。划图翻译读取浏览器实际分配的原生命令，未分配时不显示建议键；每次打开只读取一次，不轮询。

## 共享样式的接入方式

`src/ui/theme/tokens.css` 集中现有语义颜色、主题覆盖和 `--comic-*` 视觉令牌；`src/redesign.css` 统一引入。令牌包含描边、输入边框、控件／面板／卡片／徽标圆角、硬阴影、网点和虚线分隔，随主题变化，不在页面复制颜色值。`--page-max-width` 与 `--page-gutter` 统一桌面主页面和导航对齐，底部搜索面板使用同一宽度及共享遮罩令牌。

硬阴影与文字颜色分离：`--comic-shadow-color` 在浅色下沿用墨色，深色下使用墨黑色；`--comic-stroke` 在深色下使用灰蓝描边。保留悬停与按下的偏移反馈，禁用阴影单独降弱，弹框同样使用阴影色；文字、强调色和焦点状态继续使用各自的语义令牌。

封面上的文字与渐变遮罩使用 `--cover-overlay-ink`、`--cover-overlay-base`；它们独立于页面亮暗外观，保证真实封面上始终有稳定对比，不在作品卡片里复制颜色值。

`src/ui/theme/comic.css` 提供显式采用的公共样式：

- `nc-comic-paper`：强调色浅底与网点纸面。
- `nc-comic-tag`：统一标签描边、字号与圆角；默认描边与 `is-soft` 浅底变体共用主题色。
- `button primary nc-comic-action`：描边主按钮，包含悬停、按下、禁用和减少动态效果状态。

插件页面共用视觉令牌。`src/ui/theme/surfaces.css` 在页面布局 CSS 之后由阅读器入口引入，统一主导航、页面标题、表单、漫画卡片、设置、账户统计、目录、导入／导出与采集弹框、阅读工具栏和图内状态。搜索页复用 `nc-page-heading`、`segmented`、`button` 与 Select；名称面板、网站选择与结果卡片读取相同描边、圆角、阴影和分隔令牌，不另行覆盖公共按钮的悬停、按下或禁用样式。Popup 保留现有 `comic.css` 和布局，不引入全页面样式。页面布局和文案仍归各页面；漫画本身和阅读画布不使用纸纹或颜色滤镜。

输入框和下拉触发器只保留单层边框，聚焦时改为强调色，不叠加外围描边或硬阴影。搜索框由外层容器绘制边框。导航栏账户入口只显示 SVG：访客使用头像，登录后的普通用户使用蓝绿身份徽章，付费会员使用金色会员徽章，Lite 身份提示为 Lite 会员，服务端其他有效会员身份提示为会员；身份取自当前登录状态与服务端权益，悬停提示显示身份，按钮保留“我的账户”的可访问名称与当前页面状态。卡片更多菜单使用相同圆角、描边和虚线分隔。

图片和 EPUB 阅读器共用 `ReaderChrome`、`ReaderSettings`、`PageTranslationBar` 与 `useReaderControls`，保持两侧工具栏、目录／设置抽屉、翻译浮层、沉浸和全屏操作一致，不复制第二套页面皮肤。图片窗口与 EPUB 重排引擎分别管理内容和位置；格式差异通过控件内容接入，EPUB 用章节／百分比与字号替代图片页码／缩放，连续模式的翻页先移动一个视口，至边界才换章。画布与 EPUB 文档都读取 `--reader-*` 背景／正文／链接令牌；EPUB 专属 CSS 只定义渲染容器几何。

沉浸阅读在无面板、无阻挡弹层时空闲 1.2 秒收起工具，淡出保留 0.2 秒；点击空白或显示工具按钮、移至阅读区左右边缘可唤回。鼠标操作留下的按钮焦点不阻止收起，键盘焦点与输入框编辑按 `:focus-visible` 保持工具可用，失焦后重新计时。关闭面板恢复入口焦点但不滚动阅读位置；仅保留一个隐藏定时器，面板、阻挡状态变化或卸载时清理，不轮询焦点。

右侧操作栏以阅读区中央的分隔线为基准，等大按钮分别向上、向下排列，容器高度随实际按钮数量伸缩，不预留隐藏按钮的空位。重新翻译仅在可执行时显示，翻译状态诊断不放入阅读工具栏；左侧返回、目录和翻页区保留位置。窄窗口缩小按钮，矮窗口将容器限制在阅读区内并允许栏内滚动，采用悬浮滚动条避免挤窄按钮。图片适应方式、缩放与原译图选择按漫画保存，首次默认与记忆规则见[单来源阅读](SIMPLE_COMIC_READING_DESIGN.md#阅读与恢复)。

通用 `Modal` 使用独立的固定关闭区与 `.nc-modal-body` 滚动正文；标题、说明和业务内容可滚动，关闭按钮始终位于滚动区外。该结构仅作用于 `.nc-generic-modal`，不改变登录、更新说明等独立弹框的布局。关闭与 Escape 沿用调用方的关闭守卫，关闭后恢复入口焦点且不移动背景页面；滚动条由已有 `Scrollbars` 接管。

功能图标统一使用 `src/icons.tsx` 的 `Icon` 与 `src/assets/icons.svg`，覆盖导航、书架、阅读器、设置、账户、弹框、更新标记与 Popup：24 单位画布、墨线轮廓、撞色填充与轻量硬阴影。`tokens.css` 的 `--icon-comic-*` 集中定义墨色、纸白和五种彩色，亮暗外观与主题切换保留图标原色；导航显示为 28px，一般操作为 18–20px，16px 及以下去掉阴影以保持清晰。`src/icons.css` 通过 `--icon-stroke` 与调色板覆盖保留危险操作及错误提示的语义色，禁用图标降低饱和度与透明度。纯装饰图标隐藏于辅助技术，按钮和菜单保留文字或可访问名称。搜索、翻译、网站、云盘等入口按语义选择图标，不用书本图标代替搜索，不把星芒、勾选或排序箭头写进翻译文案。品牌标识、站点图标、国旗与漫画封面保留原有素材；GitHub 贴纸沿用现有标识轮廓。

主导航吸附在页面顶部，保留自身布局高度。主界面和 Popup 各挂载一次 `Scrollbars`，自动接管自身 DOM 中 `overflow: auto/scroll` 的区域，包括文档、阅读画布与工具栏、目录与缩略图、设置抽屉、搜索与详情面板、导入列表、弹框、下拉与右键菜单、文本框，以及横向滚动区。`scrollbar-controller.ts` 保留原滚动容器，在浏览器顶层绘制自定义滚动条，随内容、窗口和弹层变化更新并清理，不处理来源网站的 DOM。

支持 `overlay` 悬浮和 `reserved` 占位两种模式。“我的漫画、发现、搜索漫画、漫画网站”四个主导航页面的文档滚动使用悬浮模式；设置与账户页面及内部滚动区域默认使用占位模式，为轨道预留独立空间，避免遮挡文字和按钮。发现详情的简介滚动区使用悬浮模式，并固定预留轨道空间，使展开和翻译状态变化不改变工具行宽度。文档轨道从主导航下方开始，占位仅作用于 `.nc-workspace` 正文区域，主导航保持完整宽度。用 `Scrollbars.pageMode` 配置文档模式，内部容器默认占位，也可用 `data-scrollbar-mode` 显式指定。占位区域在内容缩短后保留已分配的轨道空间，避免滚动条显隐时反复改变内容宽度；动态尺寸变化重新读取原有内边距，不叠加占位。

滑块共用主题色、描边与硬阴影，支持拖动、轨道点击、滚轮和方向键／Page Up／Page Down／Home／End；内容不足时隐藏，被弹框遮挡或已移出父容器时不接收操作。下拉、菜单和文本框拖动保留原焦点；书架虚拟列表、发现页和阅读器继续使用原来的滚动位置与恢复规则。阅读进度仍使用原生 range 的数值与键盘行为，轨道和滑块采用相同视觉令牌。

`--text-caption`、`--text-small`、`--text-body`、`--text-title` 定义辅助文字、小正文、正文和小标题梯度，随全局字号缩放；大标题继续使用 `--comic-heading-size`。发现页的榜单、搜索输入、作品统计、详情正文与标签使用这组共享字号。

`src/ui/Select.tsx` 与 `select.css` 提供所有插件页面共用的自定义下拉菜单，包括 Popup 的语言选择。通过浏览器 Popover 顶层显示选项，避免被弹框与滚动容器裁切；支持方向键、Home／End、输入检索、Enter／Tab 确认、Escape 取消和禁用选项。控件使用 combobox／listbox 语义，选择后保留焦点；亮暗主题与强调色均读取共享令牌。

下拉项可使用 `SelectOption` 的 `icon` 提供装饰图标，触发器与选项同步展示；普通 `option` 保持兼容，键盘检索与可访问名称仍使用文字。`FlagIcon` 只接收国家／地区代码，读取 `public/flags/` 中完整的本地 SVG 集合；来源、版本、摘要记录在该目录的 `SOURCE.json`，许可随构建保留在 `public/licenses/flag-icons.txt`。`LanguageFlag` 在 UI 层单独解析标准语言代码：优先显式地区，否则使用 `Intl.Locale.maximize()` 的地区；未知语言、自动选择与跨地区语言显示地球图标。来源平台的私有语言代码仍由各自适配器规范化，公共 UI 不引入站点分支。

目录主项按标题、语言和阅读状态分层展示；多条发布选项显示数量与展开箭头，下级选项缩进并保留独立语言、标签、页数、失败提示和选中标记。未读、阅读中、已读同时使用文字、图形与主题语义色区分；样式不改变章节选择、阅读进度或目录定位规则。

`src/inline/shadow.ts` 将同一份令牌的 `:root` 定位到隔离 Shadow DOM 的内部主题容器，网页翻译浮层与来源网站的导入按钮复用该样式。`inline/theme.ts` 只通过后台消息传递外观、强调色和文字大小，跟随系统主题变化；不放宽扩展存储访问权限。滚动时复用状态按钮，保留键盘重试焦点。

独立翻译队列／翻译记录页面、入口和专用轮询已删除，旧 hash 回到书架；逐图状态、重试、任务恢复与服务端队列仍保留。

全局登录过期、操作错误和成功反馈复用 `src/ui/Notification.tsx`，在右下角紧凑堆叠，不占正文布局；阅读时避开底部工具栏。全部可手动关闭，登录过期和操作错误在 12 秒后收起，成功反馈在 6 秒后收起；鼠标悬停、键盘焦点进入或页面隐藏时暂停，恢复后重新计时。登录过期提示在当前页面运行期间只显示一次，切换视图不重复弹出；新的登录再次失效后恢复提示。关闭提示只改变展示，登录入口、原图、阅读位置和服务端任务保持原规则。阅读器逐图的登录、额度和错误标签，以及仍有旧图可看的图片加载失败卡，可以收成小图标，保留登录、升级或重试入口；没有图片时保留故障空状态。表单和局部内容错误留在所属操作区域。

## 快捷键

阅读器设置里的“键盘快捷键”和主界面设置里的“自定义快捷键”打开同一个面板，按通用、首页、阅读器、网页翻译分组。`Shift + /` 可在插件页面打开面板；网页使用 `Alt + Shift + K` 打开设置中的网页快捷键组。面板支持每个操作最多两个替代组合键、移除停用、单项恢复与确认恢复全部。按键按物理位置识别，支持 Ctrl／Alt／Shift／Command 组合；相同生效范围中的冲突和常用浏览器保留键不能保存。阅读器与首页互斥，网页与插件页面分离。

快捷键使用专用原生弹框布局：标题、关闭按钮和反馈底栏固定，左侧分类只定位，右侧四组内容始终在同一滚动区连续展示；从阅读器或网页入口打开时定位到对应分组。分类选中、分组纸面和组合键控件沿用共享描边、硬阴影、网点、圆角及悬停／按压令牌，不引入另一套视觉风格。每行以功能名称和组合键编辑器分栏，编辑与移除在同一控件内，替代键使用带可访问名称的添加入口。滚动定位每帧只检查四个分组，不扫描命令行、不轮询；打开时等待尺寸稳定，用户操作后不再强制跳回初始分组。

开始划图使用浏览器原生命令 `nc-translate-region`（建议键 `Alt + Shift + R`），由浏览器提供截图所需的 `activeTab` 用户手势授权，不增加网站权限。面板读取实际分配的组合键，并提供浏览器快捷键管理入口；浏览器没有分配该键时显示未设置。原生划图键不受面板“恢复全部默认”影响。其他网页操作使用页面内快捷键：开始标签页翻译、暂停／继续、切换原译图、关闭翻译；只有已有运行态才能暂停、切换或关闭。仅授权的 HTTP(S) 顶层网页可启动，受限页面不执行。

`src/shortcuts/catalog.ts` 是命令、作用范围、默认按键和可重复策略的唯一来源；`keys.ts`／`model.ts`／`runtime.ts` 只负责按键规范化、冲突和事件匹配，不依赖业务实现。React 页面通过 `useShortcuts` 注册现有按钮的回调，网页通过独立配置桥与后台路由复用原有翻译／划图入口。阅读器的翻页、缩放、布局和原译对照沿用位置恢复；选择译图仍走现有随读翻译，不直接创建、重试或重新生成任务。

偏好独立存入本机 `nc-shortcuts` 的版本化覆盖项，不混入阅读设置或账号数据。扩展页使用 `chrome.storage.local` 并接收变化；网页只通过后台取得消毒后的网页快捷键，不开放受信任存储。网页预览使用独立 localStorage。首次读取失败不执行默认键；保存成功后才更新生效状态，失败保留可重试草稿。已打开的上下文同步变化，未知命令／非法按键被丢弃，同范围冲突配置不执行。

输入、IME／AltGraph、菜单、选择器、弹窗与录制状态保留原生键盘行为。Popover 只有 `menu`／`listbox`／`dialog` 等交互语义才阻挡背景快捷键，滚动条等被动顶层元素不阻挡；嵌套浮层优先处理 Escape，关闭后再取消外层。Escape 固定用于取消，不允许改绑；翻译和切换操作忽略按住重复，翻页与缩放允许重复。常驻网页脚本仅监听按键和精简配置，不扫描图片、不轮询、不启动翻译；只有匹配按键才检查弹层并触发现有业务。页面卸载时清理监听。面板跟随共享主题，关闭恢复入口焦点。

## 版本更新

主导航右上角提供版本更新图标入口，与其他导航工具共用 44px 图标按钮和 28px SVG、描边、背景与交互样式；悬停提示和更新面板内显示当前版本号，点击可随时打开本版更新内容。版本号与浏览器 manifest 共用 `apps/extension/package.json`；更新条目写在 `src/ui/release-notes/content.ts`，文案随 16 种界面语言打包，不请求远程更新接口。重点更新使用独立 SVG 漫画画框、编号徽章和功能插画，其余更新使用紧凑标题与站点标签。装饰隐藏于辅助技术，标题保留可换行的 HTML 文字；配色、描边、网点与阴影读取共享视觉令牌，内容区按需滚动，关闭操作始终可见。

首次使用当前版本时，在主界面空闲后自动打开一次；导入、搜索弹层、登录和阅读期间延后。面板成功打开后将版本号写入本地 `nc-release-notes-version`，刷新与重新打开不重复弹出，升级版本后再次提示。存储失败不阻断操作，当前页面仍避免重复提示；关闭按钮与 Escape 均恢复版本入口焦点并保留页面位置。

## 本地验证

在 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。在仓库根目录运行：

```powershell
$env:PLAYWRIGHT_MODULE = '<本机 playwright 或 playwright-core 包的绝对路径>'
$env:CHROMIUM_PATH = '<支持加载 MV3 扩展的 Chromium 可执行文件>'
node scripts/verify_popup.mjs
```

脚本使用构建产物的临时副本、独立 Chromium 配置和生成的示例图片。覆盖顶栏与功能卡片布局、网站适配状态和申请表单定位、当前快捷键提示、无自动发现、语言双向同步与重新打开、模式回退、模拟网站访问受限、启动失败、Popup／右键实际激活、阅读位置保持、未知网站拒绝导入、导航变化、受限页、六种主题亮暗外观、大字体和登录公共令牌回归，并断言全流程不申请网站访问权限。站点状态使用模拟页面，不代表真实网站导入验收；专用网站导入另见[网站适配验收](SITE_ADAPTERS.md#验收与交付)。截图和报告写入已忽略的 `artifacts/popup-validation/<run-id>/`。

浏览器检查使用临时 profile 与模拟 API；浏览器实际安装授权、手动限制网站访问和恢复、真实模型效果及公开部署需要分别验收。

全页面视觉验收以桌面为准；`verify_extension_theme.mjs` 检查共享主题、书架与阅读器，环境见[脚本入口](../scripts/README.md)。`verify_history_removal.mjs` 检查旧地址回退与无历史轮询。

自定义下拉另有 8 项桌面 Chromium 交互测试；保持端口 5176 运行后，在 `apps/extension` 执行 `node --test tests/select.keyboard.mjs`。该测试覆盖精确标签名称、键盘和焦点、禁用与受控值、弹框内菜单、长列表滚动及主题，沿用上述环境变量。

同一环境执行 `node --test tests/scrollbars.browser.mjs`，覆盖下拉拖动与焦点、嵌套双轴滚动、弹框与文本框隔离、RTL 横向端点、动态内容与清理，并检查没有原生滚动条占位；两组测试均可用 `SELECT_TEST_ORIGIN` 指定预览地址。
