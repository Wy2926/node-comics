# Popup 与共享视觉令牌

## 当前行为

- 打开 Popup 只查询当前标签页和偏好，不发起图片发现、缩略图加载或翻译；浏览器内部页禁用网页操作，漫画管理器与设置仍可用。
- 目标语言与设置页共用 `TargetLanguage` 控件、`Settings.language` 字段及持久存储。切换语言保留其他偏好；语言不支持当前 AI 重绘模式时切回常规翻译。已打开的设置页和 Popup 双向同步。
- Popup 与设置页新增“标签页自动翻译”，共用 `AutoTranslateTabs` 控件与 `Settings.autoTranslateTabs`，默认关闭。开启需授予 HTTP／HTTPS 网站权限，权限拒绝不保存开启状态。开启后，后台在当前网页、标签页激活和导航完成时启动现有网页内翻译，使用默认翻译方式与目标语言；懒加载图片由原有观察器持续识别。候选按显示尺寸筛选，可能包括非漫画大图。
- 关闭自动翻译会停止自动启动的网页并恢复原图，已提交的服务端任务继续执行；手动启动的翻译保留。网页控件的暂停、恢复原图和关闭选择不会被再次切换到该标签页覆盖；刷新或进入新页面按全局开关重新启动。权限被撤销时开关同步关闭。后台通过标签页事件恢复，不依赖 Popup 常驻，也不批量提交隐藏标签页的图片。
- 点击“翻译当前标签页”时申请与右键入口相同的网站／图片权限，等待设置同步，再向后台发送 `NC_TRANSLATE_TAB`。后台只接受可信扩展页面消息，校验标签页及原 URL 后调用现有 `activateInline`。启动成功关闭 Popup；授权拒绝和启动失败留在 Popup 提示，可重试。图片翻译进度、登录和额度状态仍在原网页展示。
- 专用适配器认领且允许导入的漫画页可“开始阅读”，经公共来源服务导入并直接打开；未适配网页不提供图片选择或导入。
- 窗口宽 420px、高不超过 600px；中部按需滚动，漫画管理器入口固定在底部。沿用亮暗外观、四种强调色和文字大小设置。

## 共享样式的接入方式

`src/ui/theme/tokens.css` 集中现有语义颜色、主题覆盖和 `--comic-*` 视觉令牌；`src/redesign.css` 统一引入。令牌包含描边、控件圆角、面板圆角、硬阴影、网点和虚线分隔，随主题变化，不在页面复制颜色值。

`src/ui/theme/comic.css` 提供显式采用的公共样式：

- `nc-comic-paper`：强调色浅底与网点纸面。
- `button primary nc-comic-action`：描边主按钮，包含悬停、按下、禁用和减少动态效果状态。

2026-09-20：登录模态框与 Popup 的视觉语言已应用于其余插件页面。`src/ui/theme/surfaces.css` 在页面布局 CSS 之后由阅读器入口引入，统一主导航、页面标题、表单、漫画卡片、设置、账户统计、目录、导入／导出与采集弹框、阅读工具栏和图内状态。Popup 保留现有 `comic.css` 和布局，不引入全页面样式。页面布局和文案仍归各页面；漫画本身和阅读画布不使用纸纹或颜色滤镜。

输入框和下拉触发器只保留单层边框，聚焦时改为强调色，不叠加外围描边或硬阴影。搜索框由外层容器绘制边框；账户入口使用头像与文字，不显示常驻黑框。卡片更多菜单使用相同圆角、描边和虚线分隔。

`src/ui/Select.tsx` 与 `select.css` 提供所有插件页面共用的自定义下拉菜单，包括 Popup 的语言选择。通过浏览器 Popover 顶层显示选项，避免被弹框与滚动容器裁切；支持方向键、Home／End、输入检索、Enter／Tab 确认、Escape 取消和禁用选项。控件使用 combobox／listbox 语义，选择后保留焦点；亮暗主题与强调色均读取共享令牌。

`src/inline/shadow.ts` 将同一份令牌的 `:root` 定位到隔离 Shadow DOM 的内部主题容器，网页翻译浮层与来源网站的导入按钮复用该样式。`inline/theme.ts` 只通过后台消息传递外观、强调色和文字大小，跟随系统主题变化；不放宽扩展存储访问权限。滚动时复用状态按钮，保留键盘重试焦点。

独立翻译队列／翻译记录页面、入口和专用轮询已删除，旧 hash 回到书架；逐图状态、重试、任务恢复与服务端队列仍保留。

## 本地验证

在 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。在仓库根目录运行：

```powershell
$env:PLAYWRIGHT_MODULE = '<本机 playwright 或 playwright-core 包的绝对路径>'
$env:CHROMIUM_PATH = '<支持加载 MV3 扩展的 Chromium 可执行文件>'
node scripts/verify_popup.mjs
```

脚本使用构建产物的临时副本、独立 Chromium 配置和生成的示例图片。覆盖无自动发现、语言双向同步与重新打开、模式回退、权限拒绝、启动失败、Popup／右键实际激活、阅读位置保持、专用网站直接阅读与未知网站拒绝、导航变化、受限页、四种主题亮暗外观、大字体和登录公共令牌回归。截图和报告写入已忽略的 `artifacts/popup-validation/<run-id>/`。

浏览器检查使用临时 profile、预授权来源与模拟 API，不代表原生权限弹窗、真实模型效果或公开部署。

全页面视觉验收以桌面为准；`verify_extension_theme.mjs` 检查共享主题、书架与阅读器，环境见[脚本入口](../scripts/README.md)。`verify_history_removal.mjs` 检查旧地址回退与无历史轮询。

自定义下拉另有 8 项桌面 Chromium 交互测试；保持端口 5176 运行后，在 `apps/extension` 执行 `node --test tests/select.keyboard.mjs`。该测试覆盖精确标签名称、键盘和焦点、禁用与受控值、弹框内菜单、长列表滚动及主题，沿用上述环境变量。
