# Popup 与共享视觉令牌

## 当前行为

- 打开 Popup 只查询当前标签页和偏好，不发起图片发现、缩略图加载或翻译；浏览器内部页禁用网页操作，漫画管理器与设置仍可用。
- 目标语言与设置页共用 `TargetLanguage` 控件、`Settings.language` 字段及持久存储。切换语言保留其他偏好；语言不支持当前 AI 重绘模式时切回常规翻译。已打开的设置页和 Popup 双向同步。
- 点击“翻译当前标签页”时申请与右键入口相同的网站／图片权限，等待设置同步，再向后台发送 `NC_TRANSLATE_TAB`。后台只接受可信扩展页面消息，校验标签页及原 URL 后调用现有 `activateInline`。启动成功关闭 Popup；授权拒绝和启动失败留在 Popup 提示，可重试。图片翻译进度、登录和额度状态仍在原网页展示。
- “发现网页图片”保留手动发现、过滤、选择、排序和导入。仅在用户点击后恢复同一来源的选择草稿，并根据导航实例决定是否保留选择；关闭再打开不会自动恢复缩略图。
- 窗口宽 420px、高不超过 600px；中部按需滚动，漫画管理器入口固定在底部。沿用亮暗外观、四种强调色和文字大小设置。

## 共享样式的接入方式

`src/ui/theme/tokens.css` 集中现有语义颜色、主题覆盖和 `--comic-*` 视觉令牌；`src/redesign.css` 统一引入。令牌包含描边、控件圆角、面板圆角、硬阴影、网点和虚线分隔，随主题变化，不在页面复制颜色值。

`src/ui/theme/comic.css` 提供显式采用的公共样式：

- `nc-comic-paper`：强调色浅底与网点纸面。
- `button primary nc-comic-action`：描边主按钮，包含悬停、按下、禁用和减少动态效果状态。

登录模态框与 Popup 已共同使用这些令牌和样式。页面布局、文案及装饰编排仍归各页面；其他页面后续逐步接入，尚未完成全站视觉迁移。抽取独立令牌包时可从上述两份文件开始，避免依赖登录组件。

## 本地验证

在 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。在仓库根目录运行：

```powershell
$env:PLAYWRIGHT_MODULE = '<本机 playwright 或 playwright-core 包的绝对路径>'
$env:CHROMIUM_PATH = '<支持加载 MV3 扩展的 Chromium 可执行文件>'
node scripts/verify_popup.mjs
```

脚本使用构建产物的临时副本、独立 Chromium 配置和生成的示例图片。覆盖无自动发现、语言双向同步与重新打开、模式回退、权限拒绝、启动失败、Popup／右键实际激活、阅读位置保持、手动发现与选择恢复、导航变化、受限页、四种主题亮暗外观、大字体和登录公共令牌回归。截图和报告写入已忽略的 `artifacts/popup-validation/<run-id>/`。

本轮类型／模块检查、304 项现有测试与 MV3 构建通过。浏览器验收使用预授予的网站权限及模拟拒绝／注入失败，不覆盖浏览器原生权限弹窗或工具栏弹出容器；运行的是实际构建的 Popup 页面、设置页、后台与网页内脚本。没有调用真实翻译供应商，未做翻译效果验收或公开部署。
