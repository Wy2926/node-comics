# 插件国际化覆盖审计（2026-09-24）

本次为字典覆盖排查与未使用条目清理；主要页面的直接漏接已修复。键覆盖通过不代表全部译文已本地化，下面明确保留未完成项。未发布插件。

## 范围与结果

扫描 src 与 entrypoints 的 229 个生产 TS/TSX 模块，排除测试和类型声明；追踪 882 个 msg() 调用、有限字符串联合类型动态键，以及品牌、文档标题和商店元数据。16 个语言文件均被语言选择和加载流程使用，因此不删除任何语言。

- 原每种语言 1384 键；删除 690 个未被翻译调用或元数据使用的键，新增 11 键后剩余 705 键。合计删除 11040 条旧译文。
- 16 个语种当前均为 705/705 键；缺键、未使用键、空值、占位符差异、调用参数缺失均为 0。
- 字典紧凑 JSON 合计从 1824073 字节降到 889886 字节，减少 51.2%。这是字典字节数，不是整个插件大小。
- 删除内容主要属于旧副本、版本、归属编辑、采集中心、旧导出与旧文件导入流程。仅测试引用不算生产使用；源码中同名硬编码也不等于使用字典。
- 保留 8 个来源诊断映射键和 2 个导入进度键。导入进度改为有限联合类型，避免任意字符串强制转为 MessageKey 掩盖未使用条目。
- 网站链接导入与缓存预算的 11 个键补齐 16 份译文；书架和登录页的 2 处英文标语接回已有字典。译文未完成全部语种母语校对。

## 尚未完成的覆盖

1. **63 个常用键在另外 14 个语种中整批复制英文。** 涉及导入、书架、目录、下载、导出和缓存管理。它们仍在使用，不能作为废弃字典删除。繁中也受影响。本轮保留并列出，未声称完成全语种翻译。
2. **底层模块仍存在硬编码提示。** 包括来源账户、Google Drive、文件解析 Worker、存储、导出和站点适配。静态扫描发现 438 个候选位置；候选包含已覆盖动态键、协议码、品牌等，不可把该数直接当作缺失翻译数。逐项分类见末节。
3. **历史文档的 15 语种与完整翻译表述已过时。** 实际包含韩语，共 16 种；键完整与语言完整需分开验收。

底层错误建议在用户可见边界映射稳定诊断码和参数，尤其 Worker 与后台不能直接假定阅读器的当前语言。站点原文、用户标题、语言自称、来源名称、协议标记和供应商原始诊断不应盲目改写。

## 检查与复现

在 `apps/extension` 执行：

```powershell
npm run check:i18n
npm run audit:i18n
npm run check
npm test
npm run build
```

`check:i18n` 已加入 `check`：追踪翻译函数实际符号（包括别名）、动态联合键、嵌套调用、每语种键和参数，并阻止 TSX 新增硬编码中文。`audit:i18n` 输出 JSON，附带全量硬编码候选和各语种与英文一致的键。语义译文质量、外部返回文案与任意字符串拼装仍需人工审查。

验证记录见 [国际化维护说明](UI_INTERNATIONALIZATION.md)。浏览器确认德语设置和网站导入文案已接入，同时可复现缓存区域英文占位、非法来源链接中文错误提示。
