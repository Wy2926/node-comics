# 阅读目录与插件译本

2026-09-15，代码实现与本地浏览器验收记录。

## 阅读目录

- 左侧目录分为「作品目录」和「本话页面」。顶部显示作品、当前内容和阅读页码。
- 作品目录依据章节／卷册归属展示，按章节、番外和出版套系分组；支持搜索与正倒序。来源、内容版本只用于选择阅读副本，不会把其他章节过滤掉。
- 每项显示可读页数、清单总数（未知时显示 `?`）、阅读状态以及采集／失败原因。未添加副本的条目不可打开；有副本但尚未取得图片时可以进入等待页，等待页也能继续使用目录。
- 跨章节切换保留各自阅读位置；明确的副本覆盖起始页可作为章节入口。本话页面保留有限窗口缩略图、跳页、排序、移除与翻译范围选择。
- 只有单话时明确显示当前仅添加一份内容。有来源目录记录，或单话地址属于已支持的 MangaCopy 地址格式时，提供「查看来源目录 · 添加章节」。没有已核实的目录关系时不猜测其余章节。

## 版本与副本

作品详情的「版本与副本」包含两部分：

1. **插件译本**：从当前账户、当前服务的原始副本任务与本地译图实时汇总。
2. **原始副本**：保留网站采集、本地导入、副本修订和用户标注的内容版本。

插件译本身份为 `原始副本 ID + 翻译模式 + 目标语言`。它是已有图片的阅读视图，不复制原图、不创建第二份页面清单，也不伪装成出版版本。每页沿用最新成功结果的选择规则；新任务处理中可保留已有结果，最新成功结果失效后不回退更早的成功版本。

每张卡显示已获得译图的页数、本地页数、待恢复页数、无文字页数，以及进行中／待核实、失败和失效数量。已获得译图与处理中可能重叠（例如重译），这些数字不相加作为总页数。清单未完成且总页数未知时不声称完整译本。

点击「阅读此译本」选择相应模式与语言并保留原始副本的页码和相对位置，当前会话暂停自动翻译，即使该账户此前记住了自动翻译偏好。未译页显示原图；显式打开 AI 重绘译本时也不混入常规译图。用户仍可切换查看方式、主动翻译单页或再次确认开启自动翻译。全部结果失效／仍在处理时，提供「查看进度与原图」。

译图文件与原始副本共用已有缓存引用和保留规则。远端到期后本机仍存在的结果可继续阅读；本机缓存清理后只能恢复仍可授权访问的服务器资源。切换账户或服务时不展示其他账户／服务的译本标题、语言和计数。源副本移除后，其派生阅读视图自然消失。

首轮不提供独立的整本译图历史快照、云端译本书架或跨版本页码自动对齐。历史任务与资产继续遵循现有保留规则。

## 来源图片与采集顺序

2026-09-15 按最新确认取消所有自动滚动。MangaCopy 页面先用 `cct` 解密 `contentKey` 中的完整图片数组，再按滚动事件把部分槽位加入 DOM。插件使用浏览器 Web Crypto 读取相同数据，核对总页数与已显示槽位的顺序，直接得到完整清单。数据缺失时只保留当前 DOM 的部分状态；格式错误或顺序冲突有明确原因，不执行页面提供的 JS。协议与真实证据见 [MangaCopy 来源设计](MANGACOPY_LIBRARY_DESIGN.md)。

采集任务和采集中心均按来源目录、分组及条目顺序排列；更新时间、点击先后和页面加载时机不改变待执行章节顺序。正在运行的章节不被新任务打断。每话内逐页下载，图片发现与下载同时进行，获得链接即可开始获取字节，不等待余下清单。缺页失败不阻塞其他页面或后续章节；暂停恢复保留已保存页的身份，只补未完成部分。

采集中心和离线导入在开始按钮启用前预读代表章节的图片域名，从按钮点击直接调用浏览器授权，再入队。后续发现额外未授权域名时，保存链接并等待授权，不记为采集失败。按需阅读无用户手势时也保留授权待办；不会后台自动弹出权限窗口。

真实 Chromium 扩展分别在约 1.4–1.5 秒读出第 73 话 **43 / 43**、第 1 卷 **166 / 166**、番外 **27 / 27** 个链接。三页都只有 3 个 DOM 图片节点，滚动位置均为 0。记录位于 `artifacts/mangacopy-validation/discovery-results.json`。本轮真实来源证据覆盖 JS 清单读取，不代表这些原图都重新完成插件下载。

隔离扩展验证了事前图片域名探测、从点击发起权限请求、拒绝授权不入队、按 1→2→3 话执行、仅发现 1 页时即下载、暂停后恢复页身份、缺页重试及全程零滚动。使用合成来源和原创图片；原生拒绝决定被模拟，允许的 CDN 由安装权限覆盖，未验收原生权限对话框。截图与结果位于 `artifacts/acquisition-order/`。

在仓库根运行 `node scripts/verify_acquisition_order.mjs` 可重复隔离验收；运行环境变量沿用下述真实验收脚本的 `PLAYWRIGHT_MODULE` 与 `TEST_CHROMIUM`。真实 JS 清单验收使用 `RUN_LIVE_MANGACOPY=1`、`MANGACOPY_DISCOVERY_ONLY=1` 运行 `scripts/verify_mangacopy.mjs`，命令见 [实现记录](COMIC_LIBRARY_IMPLEMENTATION.md)。本轮类型／模块检查、205 项测试与 MV3 构建通过。

## 可重复验证

在 `apps/extension` 执行：

```powershell
npm run check
npm test
npm run build
npm run build:web
npm run dev -- --port 5174
```

Chrome 打开 `http://127.0.0.1:5174/tests/reader-fixture.html?directory=1&empty=1`。此页面仅允许隔离的 5174 来源，使用原创示例图片与模拟 API；不连接真实供应商。包含跨来源章节、长标题、部分原图、采集失败、未添加副本、空章节、不同语言与失效译图。

浏览器核对目录搜索、正倒序、跨章节续读、本话页跳转、390px 布局、已有译图与原图切换，以及已记住自动翻译时重新打开译本的行为。验收计数显示模拟新增翻译页数及报价次数；截图保存到被 Git 忽略的 `artifacts/directory-validation/`。模拟译图用于验证交互，不代表实际翻译效果。

本轮结果：类型与模块检查通过（62 个模块），17 个测试文件、150 项测试通过，Chrome MV3 与网页构建通过。Chrome 桌面／390px 实测无页面横向溢出；跨章节返回保留第 4 页，空章节返回保留第 30 页。已记住自动翻译偏好后，从译本入口进入并跳到未译页面，开关保持关闭，隔离接口新增翻译 0 页、报价 0 次。
