# 图像引擎

## 组成

| 阶段 | 直接使用的上游实现 |
| --- | --- |
| 检测与文字像素 | MTU DBNet `DefaultDetector`，PyTorch CUDA；一次检测同时提供文字行四边形与原始文字蒙版 |
| 段落与顺序 | BallonsTranslator 原生 `group_output` 合并 DBNet 文字行；不加载 CTD 检测模型 |
| 语言分流 | Comic Translate 最大文字行选择规则与 MTU 裁图；三路 PP-OCRv5 试读，Manga-Overlay-Translator 原生文字类别加权评分，逐段选择中日韩英，不重复检测 |
| OCR | 中／韩／英各自 PP-OCRv5 mobile、日文 Manga OCR。Paddle 使用 MTU 裁图／CTC 解码与 RapidOCR 等比组批；全部 CUDA |
| 字色与描边色 | 文字区域无明显彩色直接使用黑字白边；其余每段最大有效行使用 MTU 48px 权重与颜色头，CUDA；不替换 OCR 结果 |
| 气泡 | MangaLens／Ultralytics 分割，CUDA，输入边长 768、置信度 0.25、NMS IoU 0.7；蒙版跟随单张图片，用于抹字和排版 |
| 文字蒙版 | MTU mask refinement／DenseCRF、膨胀、气泡边界限制 |
| 抹字 | MTU 纯色气泡填充；剩余区域使用原生 LaMa Large 512 FP32 CUDA，按连通区域修复 |
| 嵌字 | MTU Qt 渲染器：QTextLayout、QRawFont、QPainter，在 CPU 离屏绘制 |
| 字体 | Bangers、霞鹜漫黑、Jua、Comic Relief Bold、Lalezar；保留 Noto 字体回退，Qt 负责字形塑形 |

`mtu_engine/` 只处理上游加载、阶段调用、输入校验和协议数据映射。MTU、BallonsTranslator、Comic Translate 源码按 [upstream.lock.json](mtu_engine/upstream.lock.json) 的提交和归档 SHA-256 下载到准备目录；MTU 的局部计算、重复准备精简和完整单词气泡字号适配补丁，在同一锁文件按文件记录有序的替换前后内容，准备时各严格匹配一次并记录修改后的文件摘要。修改范围见 [THIRD_PARTY.md](THIRD_PARTY.md)，其余上游文件保持原样；RapidOCR 包按 `uv.lock` 固定版本与摘要。`classic_node/` 管理租约、检查点、网络和覆盖文件。不维护自研排版、气泡推测、修复、文字分类算法或模型转换链路。

## 排版配置

字芯色与单层描边色从抹字前原图确定，描边比例保持 0.1，最终字号比例 0.96。仅处理通过 OCR／源语言筛选的段落。整段所有有效原生行裁图均无明显彩色时，直接使用黑字白边，不调用 48px 模型；不要求气泡包围、白底比例或黑色笔画比例，灰字、灰底、反白字和轻微色偏都可走默认配色。该简化不保留原来的灰度、黑白反转及特殊无彩色字体样式。

彩色判断复用上游 `check_color`：像素 RGB 与亮度的平方色差超过 100，且这样的像素超过 10 个才判为明显彩色。每条有效裁图按最多 512×512 的原像素窗口检查，任一窗口命中就保留该段模型取色；窗口只限制临时数组大小，不限制大图免取色资格、不下采样。各窗口允许少量彩色噪点，微小／分散彩色细节可能被忽略。不用整页灰度、气泡底色或一条代表行推断整段无彩色，不增加检测模型或气泡前置依赖。

需要模型取色的段落只选一条最大有效行：优先已有非空、行对齐 OCR 的有效裁图，再使用 Comic Translate 原生 `_line_area` 排序；同面积保留首行，无可对齐文字时选最大有效裁图并沿用原生颜色回退。日文整段文字不硬配给其中一行。保留 MTU 原生裁图、`ModelPaddleOCR._estimate_colors_batch` 的预处理／逐字符汇总和 48px 权重，代表行预测直接通过 `TextBlock.set_font_colors` 设为整段颜色；不裁剪完整 OCR 文字、抹字范围、段落或排版几何。无有效裁图及上游预测异常仍用黑字白边。已有文字的复用边界见下文“资源与验证”。代表行取色不保证还原多色段落。

确定的颜色与 `adjust_bg_color=False` 一起进入检查点；最终绘字时按整数 sRGB 的线性相对亮度检查字芯与描边，对比度低于 3:1 就保留字芯色、将描边换为黑白中对比度更高的一种，足够清晰的原配色不变。首次执行与检查点恢复共用这一保护，并关闭上游额外的灰色修正，保持单层描边。保护只计算每段两个 RGB，不重新取色、不扫描背景、不增加模型调用。

颜色预测不是原字体重建，不估计描边粗细；代表行内多字色会汇总，渐变、多层轮廓和阴影不保证还原。描边对比保护不纠正字芯预测，也不保证与复杂背景处处有反差，实际漫画须逐类验收。检测文字行来自 DBNet，段落来自 BallonsTranslator 原生分组。MangaLens 蒙版通过上游 `erode_bubble_mask` 按连通区域内缩 2%，使用上游完整包围检查区分框内文字与自由文字；文字框不作为气泡边界。

框内段落使用 MTU `balloon_fill`，传入原图和气泡蒙版，保留上游字号搜索、锚点与同框段落避让。非中日目标启用 `balloon_fill_mask_layout`；中日保留上游按原文字框分列，再通过同一气泡蒙版约束字号，避免额外的全图内接矩形搜索。长译文通过缩字适配，完整绘制文本，不裁剪越框字形。

未被有效蒙版完整包围的段落使用 MTU `smart_scaling`。整页边缘作为输出边界：适配层把上游渲染矩形映射到画布可用空间，再调用 MTU `calc_font_from_box` 的字形测量和字号搜索，防止译文被图片边缘裁掉。气泡模型仍可能漏检或误检；气泡内约束以有效分割为前提。

横排的非中日语言使用 MTU 现有的 Manga2Eng 按词断行接口，关闭单词断词。框内段落先由上游气泡字号搜索得到实际可用字号，再以该字号对原始译文重新断行一次，最后重新检查蒙版与同框段落碰撞并绘制。这样避免把原文大字号、窄文字框产生的固定换行一直保留到缩字后；不修改文字框或气泡边界。预排阶段字号比例保持 1，0.96 仅应用于最终输出。有限重排增加一次框内排版计算，不进行无界搜索；长单词、共享容器与长译文仍可能需要小字号。中日保留原方向和上游标点禁则。阿拉伯语由 Qt 原生处理双向排版、连写和组合音标，逻辑字符串不反转、不预转换为显示字形。不维护本地换行、连写或字形算法。

单词通过上游富文本文档路径保留完整字形，不插入词内换行。有效气泡中的单词不以原 OCR 窄框字号为上限：参考蒙版包围矩形只提供字号搜索上界，实际字号仍由上游字形测量与完整蒙版二分检查决定，保留孔洞和原锚点；未找到有效布局时沿用原文字框适配结果。单词复用上游碰撞检查，避让已排版段落并为后续段落保留原文字框空间，再登记本段结果；共享气泡仍可能需要小字号。无有效气泡仍按原文字框／画布约束缩字，不增加全局最小字号、OCR 或模型调用。

字号二分搜索先将本次不变的纯文本归一为上游富文本文档，各候选字号复用同一只读文档；不把段落的排版类型强制改为富文本，不跨页缓存。样式复制只复制包含标量的样式值对象及其可变子对象，保留独立所有权。自由文本成功应用原生自动断行时，仅准备断行，省去随后会被丢弃的首次矩形测量；富文本、显式换行、未成功自动断行及框内段落保留原生预排版。最终字号比例、画布限制、气泡适配和碰撞检查不变。

蒙版包围检查及参考蒙版的相交标签选择只栅格化裁切后多边形的紧包围矩形，保留原有整数转换、画布裁切和边缘包含规则。参考蒙版仍覆盖所有相交的完整连通区域及孔洞，不裁成文字框、不改变字号与碰撞规则；首次构造只扫描所选连通区域的统计包围框，不再为每段对整页标签图执行 `isin`。抹字与嵌字共享该页只读的 2% 内缩蒙版、int32 标签图和原生统计表，属于预留的页工作数据，不挤占可选参考蒙版缓存。相交气泡集合相同的不同段落共享完整参考蒙版，预算按唯一非空集合数计算，每份占 `宽 × 高` 字节；缓存不足仅重算未保留的参考蒙版，不反复标记整页连通区域。缓存跨该页各次字号搜索复用，正常、失败或取消退出后释放，不跨页保留。收益取决于页尺寸、气泡数及可用预算。

纯色气泡填充复用同一内缩蒙版的连通区域统计，只在各区域外接矩形内构造气泡掩码、扣除文字并采样背景；文本框重叠率仍按完整文本框面积计算，保留孔洞、越界裁切、中位色、方差阈值及修复蒙版交集规则。填充后返回的剩余蒙版独占内存，直接交给原生逐块 LaMa 清零，省去一次整页复制。LaMa 窗口仍按原顺序读取和贴回，不能因窗口重叠而任意并行或合并修复块。

文字蒙版精修的直径 17 双边滤波只处理各 CRF 输入区域及其 8 像素邻域，图像边缘仍使用原生边界规则；CRF、膨胀、气泡裁剪和文字行保护不变。文字行多边形面积在块内计算一次，距离只在原生重叠率备用分支实际需要时求值，保留浮点精度和择优顺序。裁剪输出独占内存，输入不复制、不修改；已为 uint8 的蒙版直接用于连通区域标记，日志关闭时不计算仅供日志使用的全图像素统计。抹字跳过同尺寸缩放及反射补边前的重复裁图复制，但不跳过修复、恢复检查点或输出校验。

所有语言共用的气泡最大内接矩形搜索仅去掉参考蒙版外围全空的行列，保留上游直方图／栈算法、全部连通区域、孔洞与同面积择优顺序，并将结果坐标还原到整页。已缓存的蒙版直接使用连通区域统计包围框，避免再次扫描整页找边界。非中日目标继续使用该结果进行完整单词排版，不关闭气泡适配。仅对本页预算已保留的只读参考蒙版缓存四个矩形坐标；不额外持有蒙版，不增加整页缓存预算，换页或退出时一起清除。未缓存蒙版也使用紧包围范围搜索，长图不会因为缓存不足退回逐像素扫描空白页边。

漫画字体按目标文字体系选择：拉丁字母（包括越南语）使用 Bangers，俄／乌使用 Comic Relief Bold，中／日使用霞鹜漫黑，韩文使用 Jua，阿拉伯文使用 Lalezar。Noto Sans、Noto Sans CJK 和完整 Noto Sans Arabic 保留缺字回退；不通过人工加粗或改写字形制造漫画字体。字体文件、原始声明与摘要统一记录在 [assets.json](../compute-node/assets.json)。

`keep_lang` 默认为 `null`，处理所有识别段落。显式配置 ISO 639-1 源语言（例如 `zh`）时，使用上游 TextBlock／py3langid 语言判断筛选段落，其余原文保留。接收任意源语言的公共节点不得设置此筛选值。

当前配置不能保证封面艺术字、跨列长文或复杂背景与人工／其他平台结果一致。分组、OCR 遗漏和 LaMa 修复痕迹需要用实图判断。文本模型仍由中心提供，与节点图像算法独立。

## 支持范围

来源语言限定中、日、韩、英。每段按 Comic Translate 原生 `_line_area` 选择最大文字行，面积相同时保留首行；试读与正式识别共用 MTU 四边形裁图及旋转规则。英语、韩语、中日共用三路 PP-OCRv5 都试读一次；中日共用试读结果分别参与两种候选评分。使用 Manga-Overlay-Translator 原生字符类别、权重、置信度乘积及择优规则，英语复用其拉丁类别权重；不训练分类器，不改写评分算法，不按文件名、目标语言或整页主语言锁定段落。置信度不足 0.5 的试读不参与评分；全部无文字类别证据时返回未知，不沿用上游默认英语，不抹除该段。

选定后，中韩英使用各自同一 PP-OCRv5 会话识别完整段落的文字行。仅复用等效宽度不超过 320 的代表行结果：它在试读与正式阶段均补边到 320，按已选模型和原行索引写回，其他行正常识别。长代表行仍重新识别，避免试读批次与正式批次补边宽度不同却直接复用结果。日文将完整段落原方向裁图交给 Manga OCR，保留全部行几何，不复用中文试读文本。Paddle 正式结果保留 0.5 门槛；Manga OCR 不提供可比较的置信度，不伪造分数、不用该门槛过滤。没有“首次高置信度即停止试读”或“正式识别失败再换模型”的逻辑，也没有云端兜底。短字、艺术字、无假名的汉字段落仍可能误分；检测遗漏不会被识别模型补回。目标嵌字语言仍由 Qt 字形覆盖探测，支持 17 种（包括 `ar`），不代表同样支持这些语言的原稿识别。非中日目标强制横排。

同一原生分组内允许部分文字行识别失败；只要段落的已有识别结果通过最小文本长度、有意义文本与可选源语言筛选，就继续翻译和抹字，不因空行或单行低置信度否决整段。保留原分组几何和阅读顺序，不自行补字、拆行或复识别；因此未识别行也可能随整段被抹除，译文可能缺失对应内容。整段无有效文本时不生成修复区域；OCR 异常仍按页面失败处理，不生成抹字结果。

DBNet 同样可能漏检艺术字和小字，不能把目标语言覆盖视为所有源语言识别质量通过。真实 CUDA 测试分别检查中日英已知裁图 OCR、贴底文字、跨页批次、不同页面位置的长正文，以及空行／低置信度故障注入后的部分文本继续处理和整页无有效文本时跳过抹字；固定译文的实图对照检查分组、阅读顺序和排版。

## 上游能力与接入边界

采用上游模型不等于已选出每种漫画的最优组合。气泡输入尺寸和置信度须在实际版面上校验，不能消除非气泡物体的高置信度误检。气泡蒙版提供容器，DBNet 提供文字范围，Qt 再计算换行、字号与位置，三者的质量分别验收。

DBNet 默认输入边长 1280、文字阈值 0.5、框阈值 0.7、扩张比例 2.3。它同时提供识别框和抹字蒙版，避免重复运行检测网络。分组直接传入原生 `group_output`，保留长段落与阅读顺序，不增加分镜检测或本地分组算法。改变检测器须同时回归裁图完整性、段落合并、阅读顺序和代表性图片，不能仅凭单条 OCR 结果替换。

超长或超宽图继续使用 MTU 原生方块重排、等比缩放和按距切边距离加权的热图回拼。切片最大步长限制为片长减去其 20%（向下取整），避免原生均分在页长接近整倍数时仅重叠数像素、把整行文字切断。首尾覆盖、横图转置、末批补齐和回拼均由上游处理；先回拼热图再统一提框、分组和 OCR，不逐片重复翻译。普通页不触发重排，行为不变；重叠增加长图推理方块数，具体开销受尺寸及每块打包条带数影响，不能用 20% 直接当作耗时增幅。

切片不是段落边界，文字行可以跨接缝归组；但 BallonsTranslator 仍按文字几何分段，MangaLens 气泡蒙版仅提供修复与排版容器，不强制“一个气泡对应一个翻译段落”。同气泡多段文字可能保持多个翻译单元；重叠修复不改变该分组规则。

模型选型使用固定漫画样本、统一归一化规则和目标机器延迟评估；裁图 OCR 评测不等于整页检测与翻译质量，不能跨数据集按一个分数宣称最优。源语言识别与目标嵌字语言分开，其他文字体系需要独立漫画样本验收。

## 资源与验证

中韩英逐行 OCR、日文单行段落的已有文字可直接作为 48px 解码器输入（teacher forcing）：保留图像编码、原生解码层与颜色头，按层并行处理整行 token，跳过字符分类、字典 softmax、top-k 和 beam 搜索，不再为了取色重新识字。因果遮罩阻止读取后续字符；只读注意力适配器保留逐步交叉注意力的 XPOS 查询尺度，其余仍调用原生注意力，不修改共享模型，不保留另一套逐字符循环／缓存。仍按所有已有字符汇总颜色，不用首字符颜色替代整行；普通空格映射为原字典 `<SP>`，不规范化、删字或替换未知字符。空行、超出 255 字符、字典外字符、行数不匹配、缺少已选 OCR 路由及多行日文段落沿用原生 beam 取色，不能把日文首行保存的整段文本硬配给单行图像。条件文字与原 48px 自行识别的文字不同，颜色可能变化，不宣称结果逐像素等价；实际漫画与目标 CUDA 机器仍需验收。

每批使用轻量请求局部适配器传入已知 token，不修改共享模型或 OCR 文本；混合已知／未知行在原生补边之后按行选择推理，保留同批画布宽度并恢复原顺序。张量集中移到 CPU 后继续使用原生逐字符颜色汇总，避免逐字符 CUDA 标量读取；异常沿用原生黑字白边兜底，不追加一次 OCR 重试。检查点字段不变，恢复与嵌字不重新取色。

默认检测边长 1280、修复边长 512，CPU 算子线程与嵌字进程数自动按启动时可用 CPU 预算分配，规则见[节点配置](../../docs/NODE_CONFIGURATION.md)。仅接受非负 CUDA 设备索引。ONNX Runtime 固定 CUDA 12 兼容版 1.23.2，Paddle 必须成功启用 CUDAExecutionProvider；中文和日文必须使用指定 CUDA 设备，初始化失败不接受 CPU 降级。ORT 辅助线程使用解析后的 `threads` 上限并关闭空转等待，启动时通过 MTU 原生工厂创建会话，逐页阶段不重复创建。

DBNet、LaMa 和 MangaLens 各复用一个模型实例；三个 Paddle 会话、Manga OCR 和用于取色的 48px 各常驻一份。中韩英试读与正式识别共用会话，短代表行结果仅在当前页分流与识别之间复用，不跨页保留。按模型分批并恢复原段落顺序；Manga OCR 按段调用上游完整生成接口。取色每批最多 6 行，沿用 48 高度等效宽度 3200 的输入边界，不强压超宽行；已知文字只补齐到该批最长 token 序列，不扩张 beam。整行并行消除逐字符重复投影与模型调度，但临时注意力矩阵比单字符查询更大，受每批 6 行、每行 255 token 与输入宽度上限约束，不新增跨请求缓存。48px 视觉编码、颜色计算和未对齐行的完整搜索仍有成本；浮点误差、目标机器双并发耗时及显存峰值需分别验收。

三个 Paddle 会话分别在原生推理调用处加锁，试读与正式识别共享对应会话的锁；裁图、排序、补边、CTC 解码与结果汇总不持锁。Manga OCR 只保护单段生成，48px 只保护单批条件颜色计算／原生回退及返回张量向 CPU 的完整回收；不同模型不共用 OCR 大锁。语言评分临时替换上游读取函数，只在替换、同步评分与清理之间持有独立 CPU 短锁，避免跨页混用候选文本。各次等待累加到已有 `ocr_lock_wait`，包含在 `analyze` 内，不代表 GPU 推理时间，不新增中心协议字段。DBNet 和 MangaLens 仍分别加锁；已预热的 FP32 LaMa eval 路径只读模型状态，允许计算池内并发。不同模型与 CPU 蒙版细化可以交错；预热在接单前完成，退出时先等待计算池结束，再卸载模型，不支持卸载与推理并行。使用框架默认 CUDA 流，不额外复制模型或创建用户流，不保证 GPU 内核同时执行；双页计算池与内存预算保持不变，吞吐和显存峰值须在目标机器实测。网络与 Qt 嵌字池独立；多渲染位使用预热的 CPU-only spawn 子进程，各自持有字体和断词缓存，进程内串行、跨进程并行。单渲染位直接在主进程绘制，不增加进程与图像复制开销。

同一 CPU worker 完成绘字和输出，只返回有界覆盖文件与元数据，不回传整页 RGB。共享输入包含原图、抹字图、内缩气泡蒙版、原图 alpha 及已准备的标签／统计表，分配与预算规则见[节点配置](../../docs/NODE_CONFIGURATION.md)。Qt 仍整页排版；已协商分块、超过 2048×4096 像素或任一边超过 WebP 限制的页面，在差分前划分不相交的最多 2048×4096 区块，各自差分、裁剪、无损 WebP 编码并解码校验。一次只提交一个并发窗口，按画布顺序组装原有覆盖包；编码参数不变。输出可非阻塞借用池内空闲 CPU 配额，完成即归还，合计不超过已分配的渲染 CPU 预算，不另加可配置线程数。单渲染位和内存不足的本地回退调用同一函数、串行输出。小图／未协商分块沿用单覆盖层；透明度、无变化原图、一次冻结交付与恢复语义不变。

单页分析产生的原始蒙版受在途内存预算约束，与持久化 PNG 检查点并存；抹字后改为保留气泡内缩蒙版、标签和统计表，绘字完成／取消后释放。统计表大于一张 uint8 蒙版时仅保留内缩蒙版，避免病态碎片扩大持久缓存。分析期间另在既有工作缓冲内、最多占一张 RGB 原图大小，复用相同四边形的原生裁图、RGB/BGR 转换和完全相同补边参数的 Paddle 预处理；数组只读、紧凑，引用输入也计入额度，分析退出即清除。长行批次补边不同不能命中，不改变 OCR、颜色模型或识别次数。恢复任务按需从兼容检查点解码，不跨页缓存。参考蒙版缓存只按有效气泡和非空译文需求分配；缓存命中与进程并行共用内存预算，不能仅用更多并行路数判断吞吐收益。

三个 Paddle 会话共用一套批处理边界：先按高 48 时的等效宽度，分开不超过 320 的短行与超过 320 的长行，再分别调用 RapidOCR 3.9.2 的原生排序、每批最多 6 行、等比缩放和顺序恢复。短行补边到 320，长行仍按各批最长行补边，不做精确宽度细分桶。320 不是长行压缩上限；3200 仍是等效宽度资源边界，超限行为空，不强压或截断，不否决同段其他有效文本。此规则隔离短行与长行的补边干扰，不保证任意长行混批结果与单独识别完全相同。日文生成沿用上游最多 300 token。三路代表行试读与日文自回归生成仍有成本；短行结果复用减少重复识别，但新增分组可能增加推理批数，净收益取决于页面行数和宽度分布，须结合识别完整性与目标机器双并发耗时、RSS、显存验收。

CUDA 固定使用 ORT 的 `cudnn_conv_algo_search=HEURISTIC`，不允许 CPU 降级；以已有权重选择卷积执行算法，不改变识别模型或精度格式。动态等比输入的性能必须在相同裁图、批次、设备与会话参数下比较，不能使用固定 320 强压长行的耗时作为等价加速。固定加宽所有行也会改变识别结果，不作为替代方案；模型替换和调用次数减少不等于整页延迟已得到验证。

OpenCV 线程数在上游模型导入完成后设为节点的 `threads`，覆盖 Ultralytics 导入时关闭多线程的全局设置。DBNet 和蒙版细化保留上游双边滤波与 DenseCRF；这些 CPU 步骤也计入分析阶段，调整 CPU 线程须用目标机器实测。

模型、CUDA 工作空间及各进程解释器／字体常驻内存在 `resident_bytes` 页缓冲预算之外。选机器和并发前实测初始化、逐阶段耗时、吞吐、RSS 与显存峰值；Windows 桌面测量不代表 Linux 服务或其他显卡性能。

资产准备、真实样本对照和测试命令见 [README](README.md#验证)。`tools.validate_pipeline_pressure` 保留有界流水线的模拟恢复／慢交付测试，`--models` 可接入实际 CUDA 引擎；模拟中心和固定译文不能证明公网或文本供应商质量。CPU 输出阶段使用 `tools.validate_render_output` 验证，命令与计时边界见[节点运行与恢复](docs/NODE_OPERATIONS.md#本地-cpu-输出验证)；不加载图像模型，不能替代目标机器的完整流水线验收。
