在 Safari 中使用 NodeLane

  1. 在 Safari 的页面菜单中打开“管理扩展”，启用 NodeLane。
  2. 在“设置 → App → Safari → 扩展 → NodeLane”中允许访问所有网站。阅读页面、图片 CDN 和登录服务可能使用不同域名。
  3. 返回 Safari，通过 NodeLane 菜单打开阅读器，或翻译当前网页。

Mac 可在“Safari → 设置 → 扩展”中启用扩展和调整网站访问权限。

打开阅读器 / Open reader

Enable NodeLane in Safari

  1. Open Manage Extensions from Safari’s page menu and enable NodeLane.
  2. In Settings → Apps → Safari → Extensions → NodeLane, allow access to all websites. Pages, images and sign-in services may use different domains.
  3. Return to Safari and use the NodeLane menu to open the reader or translate the current page.

On Mac, use Safari → Settings → Extensions.
