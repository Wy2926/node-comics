# MangaBall

独立 HTTP 适配，URL 及协议规则仅存在本站目录。接入遵循[网站适配契约](../../../../../../docs/SITE_ADAPTERS.md)。

## 支持范围

- `https://mangaball.com/title-detail/<24 位小写十六进制 ID>` 及源站的 `-slug` 后缀：名称搜索、公开目录分批读取并核实完整性、专门封面、12 小时目录同步。
- `https://mangaball.com/chapter-detail/<章节 ID>?chapter=<显示话号>`：HTTP 元数据核对章节及作品归属；裸章节导入先解析作品。目录生成的本机片段绑定再次由 HTTP 数据核对。
- GET 目录请求 `language=all&group_by=chapter&sort_order=asc`，完整分页，交叉检查每批话组／发布条目及作品的话组总数。保留源站同话的全部语言／发布组，不把来源外链误当成本地正文外链。
- 源站显式话组对应共享阅读位置；没有话号的条目独立阅读，不按标题推断对应关系。
- 章节 API 的完整有序 `pages` 数组提供独立稳定页槽；重复图片 URL 保留，空正文和章节／作品元数据归属错乱明确失败。
- 作品及章节页面显示公共浮动导入入口。已加载的源站正文 `<img>` 可原位翻译，通过正文 `alt` 和公共图像读取函数识别；封面、广告及未加载图像不作为正文。

## 长目录加载

每次目录读取的作品信息与分页请求按开始时间至少间隔 500 毫秒，首请求立即执行。正文及搜索请求不等待目录队列，已核实且可读的首批目录先保存并打开阅读器，其余分页继续获取；目录显示加载状态，正文仍可翻页。首批和最终目录分别保留不完整／完整标记，最终仍检查所有分页、作品话组总数和发布条目归属，最多接受 10000 个话组或发布条目。

目录请求遇到 HTTP 429 时只重试当前 URL。每个 URL 最多重试 3 次，默认等待 1／2／4 秒；若有效 `Retry-After` 更长，则按该值等待。一次目录读取累计限流等待最多 30 秒，超过等待预算或重试次数即保留原错误，取消会结束等待。已保存的部分目录和正文不丢失，重开漫画仍可阅读；目录提供“继续加载目录”，继续时合并同一本书，保留已读位置和正文内容身份。继续获取可能重读首批目录，但单次 429 恢复不会重新请求已成功分页。

500 毫秒节奏会增加长目录的最低完成时间；例如 1000 个话组需 10 次分页请求，连同作品信息的请求开始时间跨度至少约 5 秒。首批通常只需作品信息和一次分页请求，之后的目录耗时不阻塞当前章节阅读。

正文直接采用章节 API 提供的完整图片地址，原位直接采用已加载正文的图片地址，交由[公共图片访问规则](../../../../../../docs/IMAGE_ACCESS.md)处理 HTTP(S) 地址安全、浏览器权限、请求头、图片读取和解码。本站允许任意公开图片服务器和路径，包括章节 ID 前缀及数字序号文件名；章节与作品仍通过 API 元数据核对归属。

专门封面优先使用 API 明确提供的 `image.cdn_mangadex` 公共图片地址；字段无有效值时解析作品 `image.cover.path`，相对路径以本站封面服务器为基准。封面同样遵循公共图片访问规则。

## 协议来源

协议由源站当前页面与随包前端请求代码核对：`https://api.mangaball.com/api/v1/title/search-advanced`、`title/detail/<ID>`、`title/chapter-listing`、`chapter-detail?chapter_id=<ID>`。解析器只消费 JSON，不执行下载脚本，不读取或转发源站本地账号、Cookie／令牌。

同话关系来自 API `grouped_data[].releases`；话组总数来自分页和作品的 `chapters_count`（该字段并非发布数），每批发布条目集合与 `data` 交叉核对，不使用爬虫同步统计推算完整性。图片正文无源站内容摘要，故不声明 `contentKey`。

## 验证入口

从仓库根目录执行公开只读 HTTP 验证：

```powershell
node apps/extension/src/sources/sites/mangaball/tests/verify-http.mjs
```

可追加作品 URL 覆盖不同作品。验证名称搜索及下一页、空搜索、完整多语言目录、章节归属、完整图片清单、数字序号文件名正文及目录请求节奏。目录记录耗时、429 次数和每页请求次数；首张正文和封面分别记录为 `rawNodeImageProbe`／`rawNodeCoverProbe`，包含 HTTP 状态、内容类型和 Cloudflare 验证标记。Node 的请求环境与浏览器不同，不能据此判断插件能否显示图片。接口失败保留 `status` 和 `Retry-After`，供本站限速恢复使用。仅保存公有作品 ID、计数、字节数量及响应元信息到忽略的 `artifacts/mangaball/http/`；不保存图文、下载地址、凭据。HTTP 下载不等同于浏览器图片解码、整本阅读恢复或真实模型翻译。

在 `apps/extension` 执行 `npx vitest run src/sources/sites/mangaball/tests`：脱敏夹具检查 URL／伪造主机、话组和完整性、重复页槽、资源归属、搜索游标、取消及页面导航失效。

构建插件后从仓库根目录运行 `node apps/extension/src/sources/sites/mangaball/tests/verify-browser.mjs`，环境同[公共浏览器验证](../../../../../../scripts/README.md)。默认隔离 API／图片检查真实 MV3 搜索导入、搜索及书架封面解码、任意第三方 HTTPS 域名／路径／查询参数的正文读取解码、重开位置、目录更新失败保留、重复更新及裸章节选中语言；长目录夹具检查第二页仍在等待时可读第 3 页、后台完成保留位置、429 重试不重复首批，以及加载中断后重开阅读和继续加载。`RUN_LIVE_MANGABALL=1` 读取公开小作品，检查同一插件图片读取链的真实封面、搜索导入、正文解码和重开位置。封面不能成功解码即验证失败，响应只记录脱敏元信息。源码探针只写入隔离扩展副本，不修改构建产物。

浏览器[公共原位验证入口](../../../../../../scripts/README.md)自动发现 `tests/verify-inline.mjs`，使用隔离图片与本机翻译夹具检查译图、恢复、懒加载、广告排除、资源更换和几何位置。此入口不调用真实模型，不将隔离结果视为真实站点验收。桌面浏览器完整阅读、安装权限／撤权及真实模型效果需要单独验证。
