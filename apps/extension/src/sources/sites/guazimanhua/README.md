# 瓜子漫画

- 作品：`https://www.guazimanhua.com/comic.php?id=<作品 ID>`。
- 章节：`https://www.guazimanhua.com/chapter.php?id=<章节 ID>`。
- HTTP 读取完整目录、正文页清单与专门封面；每 12 小时通过公共调度更新目录。授权后在作品页、章节页嵌入 `NodeLane Comics · 导入/管理漫画`。导入、阅读、目录同步不创建来源采集标签页。
- 章节 URL 不含作品 ID。弹窗、章节页按钮和粘贴链接统一通过 `Article.isPartOf` 解析作品，再核对完整目录包含当前章节。目录内链接以 `#nodelane-guazimanhua=<作品 ID>` 保存本地绑定，片段不发送到源站；取图时再次校验作品与章节归属。归属解析的章节 HTML 可通过公共短期会话交接复用，不重复请求。
- 使用服务器输出的 `.all-chapter-grid`，将源站倒序目录转为阅读顺序，不按章节 ID 数值排序。读取数量必须等于源站章节总数，重复、截断或失败响应不能替换已接受目录。
- 正文取自 `.reader-images`，按 `data-page` 和 `page-N` 核对页序及总数。JSON-LD `ItemList` 只列前 20 张，`numberOfItems` 是全章数量；逐项核对前 20 张后读取完整正文，不能把 SEO 预览当成全章。远程脚本仅作为 JSON 数据解析，不执行。
- 封面来自已验证作品的 `ComicStory.image`，不从推荐或正文图片选取。`img.guazicdn.com` 与 `api.guaziapp.com` 为可选图片权限，图片经过公共 HTTP 管线，无专用防盗链头或图片还原。
- 本次不声明网页原位翻译能力；章节正文采集完全通过 HTTP。源站未提供正文或结构不完整时明确失败，登录／付费限制以源站为准。

## 验证

在 `apps/extension` 运行 `npm run check`、`npm test`、`npm run build`。

真实浏览器验收从仓库根目录执行，环境变量见[脚本入口](../../../../../../scripts/README.md)：

```powershell
node apps/extension/src/sources/sites/guazimanhua/tests/verify-browser.mjs
```

脚本使用隔离、预授权的 Chromium MV3 配置和公开漫画样本，不使用用户浏览器资料，不调用产品 API 或翻译模型。覆盖网站入口、裸章节弹窗导入、跨后台和阅读器的 HTML 复用、粘贴章节／作品链接、站内按钮重复导入、完整取图、书架封面、关闭来源页后的目录同步和重开页码。报告和截图位于被忽略的 `artifacts/guazimanhua/browser/`。原生授权弹窗、Firefox 和登录／付费章节不在此验收范围。

2026-09-25 HTTP 核验：作品 26470 为 812 章、作品 18741 为 87 章、作品 37583 为明确的空目录；章节 1977711 为 18 页，章节 955039 为 59 页且结构化预览仅有前 20 项。目录、封面与正文解析均使用实际返回内容核实。新增章节、重复同步及失败保留旧目录由合成夹具验证，不把未发生的真实更新当作已验证。

同日 Chromium MV3 实测通过：站内按钮导入 812 章，首章 18 页全部解码，关闭阅读页后恢复第 10 页，书架显示独立封面；关闭源站页后自动目录同步成功，未创建采集标签页。59 页样本末页实际解码为 1200 × 1680。裸章节 URL 的站内按钮通过 HTTP 找到作品，并复用已有漫画。检查过书架与阅读恢复截图，扩展页面无未处理异常。

同日导入一致性回归通过：先从裸章节弹窗导入，再使用粘贴章节／作品链接及两处站内按钮，书架始终只有同一部作品；粘贴链接恢复原有第 10 页位置。首次导入的章节 HTML 在后台归属解析和阅读器正文发现之间只请求一次。合成回归另覆盖并发重复导入、未知归属拒绝、权限撤销、交接过期／容量限制以及会话存储不可用时正常 HTTP 读取。
