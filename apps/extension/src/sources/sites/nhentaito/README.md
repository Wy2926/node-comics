# nHentai.to

仅适配 `nhentai.to`，与 `.com`、`.net` 使用独立身份，不认领其他同名域名。支持 HTTP／HTTPS 的 `/g/<画廊编号>/` 和 `/g/<画廊编号>/<页码>/`，读取统一使用 HTTPS。未知查询参数、片段和其他路径不用于导入。

整本画廊导入为一本漫画、一个阅读条目，提供完整原图清单、专门封面、浮动导入和 12 小时目录同步。所有页码链接属于同一条目；首次从整本起点阅读，重复导入和重开沿用插件保存的位置。原位翻译复用 `inlineRecognition: 'generic'` 的已加载大图识别。按需求不声明或实现名称搜索；不支持站内下载、账号收藏或评论操作。

依据[源站首页](https://nhentai.to/)对成人漫画与免费阅读的说明，声明 `isAdult: true`、`pricing: 'free'`，分类与卡片标签遵循[成人属性契约](../../../../../../docs/SITE_ADAPTERS.md#成人属性契约)。站内账号的下载／收藏功能不作为阅读收费或登录门槛；不推断其他同名站点的规则。本地图标是项目自制的字形标记，不分发源站图标。

## 协议与边界

- 目录请求第 1 页的 HTML，正文请求对应阅读页 HTML，每次操作各一次请求。阅读器 `new N.reader` 的静态 `gallery` 对象提供公开画廊编号、媒体编号、完整有序页数组、页数、标题、封面类型及内容语言。详情页 `new N.gallery` 使用不同的内部编号，且页表可能是带偏移键的对象，因此不用于拼接正文清单。
- 仅解析已验证初始化结构内的 JSON 数据，允许源站对象末尾的单个逗号，不执行下载脚本。校验 canonical、公开画廊编号、当前页码、完整页数和当前 DOM 正文图片；缺页、未知类型、重复配置或归属不符时失败，不保留部分数组后重编号。
- 原图按源站阅读器协议使用 `media_url + galleries/<media_id>/<页码>.<类型>`，类型来自逐页数据（JPEG／PNG／GIF／WebP）。当前仅接受实际核验的 `https://supercdn.site/`；封面使用专门的 `cover.<类型>`，不使用正文第 1 页或缩略图作为封面回退。完整清单最多 1500 页，不逐页爬取网页，不请求缩略图，不另存全量图片缓存。
- 内容语言仅来自明确语言标签；`translated` 不表示一种语言，多个不同语言或未知语言不推断。原图、封面、权限、Referer、取消和缓存沿用公共 HTTP 管线，无站点专用解码或浏览器会话兜底；源站验证失败时保留原资料，用户按提示重试。

协议参考是源站公开阅读器资源 [`combined.1d8cbb9eaccb.js?a=1`](https://nhentai.to/js/combined.1d8cbb9eaccb.js?a=1)，SHA-256：`aeb3536331129ac26ef82e91b8d9ee74741680a5c624a213ec415f4d2390b8d8`。仅核对图片类型、原图路径和页序的协议知识；适配器自行实现，不移植、执行或分发源站脚本。未取得源站脚本的独立代码许可，本适配器代码沿用项目许可证。

## 验证

在 `apps/extension` 执行：

```powershell
npm run check
npm test
npm run build
```

本站单测使用自制中性 HTML／JSON，覆盖 URL 与跨域拒绝、稳定身份、无搜索能力、完整页序、类型和尺寸、封面、静态数据提取、取消及失败保留。通用原位识图回归由注册表自动覆盖。
