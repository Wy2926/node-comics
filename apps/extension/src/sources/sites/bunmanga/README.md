# Bun Manga

- 支持 `https://bunmanga.com/manga/<slug>/` 与其下的章节 URL；章节身份保留 `chap-0`、`chap-1`、小数和后缀，`style=list`／`style=paged` 不改变身份。未确认的域名或镜像不认领。
- 复用 [Madara 共享引擎](../../shared/madara/README.md)：静态完整平铺目录、章节级 canonical 与 `ajax-select` 正文身份、只读 AJAX 名称搜索。本站章节选择容器可在服务端填入完整选择框，全部容器／选中项必须一致，不能把部分加载或站外条目作为完整清单。
- 普通 HTTP 读取目录和列表正文，每次目录／章节各一次 GET；搜索每页一次 POST、显式 12 项，按需翻页、不预取候选详情。封面与正文使用共享图片地址校验和公共读取管线；不打开源站标签页、执行远程脚本或自动切换通道。
- 提供作品／章节浮动导入、「寻找其他语言」和 12 小时目录同步，原位翻译使用通用识图。分卷、付费／受保护正文及未验证的自定义模板不在支持范围。
- 英语译作，以国漫和韩漫为主，不标生肉，默认从左向右阅读。收费类型为 `free`：依据[首页目录](https://bunmanga.com/)与[公开章节](https://bunmanga.com/manga/buried-injustice/chap-27/)的直接阅读方式、未见章节价格或付费解锁入口作出的内容判断，并非源站全站免费承诺；通用条款中的商品交易描述不等于漫画阅读收费。

协议参考来自 [Bun Manga](https://bunmanga.com/) 的公开原始响应及 [Keiyoushi 固定版本文件](../../shared/madara/upstream.json)；许可由共享引擎统一保留。图标由本项目绘制，不复制源站商标。

## 验证入口

在插件目录运行 `npm test -- src/sources/shared/madara src/sources/sites/bunmanga --maxWorkers=2`。自造夹具验证本站 URL、来源归属、静态目录、预填充章节选择器、页槽、取消和请求数量；共享搜索测试验证本站分页与公共契约。

构建后，使用[共享真实浏览器脚本](../../shared/madara/README.md#验证入口)，传入 `bunmanga`、当前可产生两页以上结果的查询，以及同一作品的两个公开短章节 URL。脚本通过实际扩展界面检查搜索／加载更多／空结果和封面解码，另检查导入、章节图片、阅读位置恢复与目录刷新。隔离的无头桌面浏览器验收不代表移动真机、权限撤销或模型翻译效果。
